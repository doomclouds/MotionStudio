# 骑行年报双页

来源：https://github.com/alchaincyf/huashu-design/blob/4fc7bfdbd5ec3fa2d43ce7a6433de60976a5e4b1/assets/style-specimens/east/12-japan-magazine-dense.html

## 内容和品牌
这不是九张统计卡的拼接。左页用一条通勤线路和手写批注回答“骑起来如何”，右页用年度数字与一周热图回答“规模和节奏如何”。中间细线维持杂志双页秩序，左叙事、右证据形成读图路线。Huashu 的日式密排风格样例，并非真实骑行机构年报。

## 构图与字体
54px 极粗宋体标题承担开场，黄色衬底只标出“十八万”；右侧 Archivo Narrow 压缩数字宽度，保证九格密排仍可扫读。Long Cang 手写批注像现场笔记，与规整 Noto 正文形成不同声音。网格、页码、细边都保持硬质编辑感，不套圆角卡片。

## 颜色如何表达
黄/黑承担数字的编辑重点，不是数值大小排行。橙色连接左页路线和右页热度，蓝色只给支路与批注，公园绿和湖水蓝属于地图类别，不作为全页主题。更换内容应先定义这些角色，而不是整页换一个主色。

## 真实实现与沉淀
完整页面、地图路径、网格、文字与热图均为 Canvas 代码重建；没有原图像素层或生成图层。公共 UI 族实际调用 0，不能为了复用把双页强拆成软件卡片。案例内 source-opacity-grid.mjs 从 scene 实际调用一次；它固定 7×24、接收168个0–1透明度、宽度480–600，拒绝错长度/非法数值，不从图片推断真实骑行次数。两套输入渲染与10个拒绝测试已执行，第二套只是合成的反转透明度测试。

## 自检与残差
核对双页分栏、标题与衬底、路线四节点、九格顺序、168格透明度与页码。初版 Long Cang 缺少 ·、→、◎，经字体 cmap 检查后路由到 Noto Sans，未删除原文；符号字形和手写墨迹仍比源 JPEG 更细，小字栅格也更清净。没有为模仿压缩噪声改坏细网格。

## 数据边界
183,600公里、18,420人次、9.6公里等均是源样例；除法约9.97并不等于9.6，统计口径未知，忠实保留而不宣称已勾稽。热图只保留源 CSS 的透明度，不是采集到的出行记录；路线也不是实际骑行导航。固定1200×750静态，无响应式、视频或地图交互。
