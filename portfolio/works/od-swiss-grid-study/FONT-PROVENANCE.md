# External font provenance

The source requested Helvetica Neue / Helvetica / Arial, with no original binaries. Liberation Sans 2.1.5 Regular/Bold (unmodified OFL) and Archivo (OFL) are explicit substitutions, not recovered Helvetica. The two Archivo derivatives were instantiated at wght 200/300 and wdth 100, named SwissArchivo200/300; original names, fixed source Git blob and SHA are retained in font-provenance.json. All four runtime files are exact external snapshots; this package does not claim to regenerate timestamp-identical TTFs. The unused full Archivo input remains in the private backup, not required for rendering. Native geometric percent marks are disclosed.

Font file SHA and byte sizes: font-lock.json. Notices are retained under licenses/.
