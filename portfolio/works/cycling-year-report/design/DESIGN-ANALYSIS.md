# 骑行年报 · Y2K数字主视觉

状态：用户接受并要求保留；作品集工程待统一提交。固定1200×750静态2D。

## 设计判断

内容目标：把年度骑行距离变成值得分享的个人成就，而不是密集的数据报表。本例是演示页样例，不是完整产品UI，也不是用户真实骑行记录。

品牌语言：洋红、亮黄、青与橙的高饱和碰撞，巨大倾斜数字和厚实挤出构成庆祝语气。视觉新意来自数据成为主视觉，而不是给普通表格换皮。

构图：2847抢占最大面积作为唯一第一焦点，公里与解释建立含义，底部最爱路线补充具体故事。右侧弧顶人像槽只占辅助位置。

色彩与层次：黄数字与粉底形成强对比，橙棕挤出给数字厚度；青色斜区与底橙横带稳定高密度大字。白字单位和黑字统计条分担阅读，不让每个元素都使用最亮黄。

图像事实：原作右侧本来就是标明“人像位·双色调”的几何占位。本轮忠实保留，不虚构真人照片，不把占位视为完成的人像美术。

可迁移方法：选择一个最值得记住的指标，用大小、旋转与层叠把数据物体化；其余信息必须从属。适合年度回顾/里程碑，不适合多指标等权比较或严肃财务披露。

## 实现与边界

构图、文案与几何依据 Huashu 原作图片和 HTML 移植，非原创品牌设计。所有文字与几何代码重建，无原图位图层，无 image gen 素材。源码的content为可编辑内容，场景保持原生固定画幅。数字软影使用代码自行绘制文字蒙版并模糊合成，不读取外部图片。使用二维仿射倾斜和字体逐层偏移近似原CSS透视，数字透视和软影仍有残差；原图JPEG噪声、条纹与中文字形栅格化不完全一致。

自检包括时间0与999重复输出一致性、依赖/字体文件、离线报告嵌图一致性。未浏览器显示验证、未交互验证、未Motion视频或响应式验证。像素差图只定位差异，不计算审美分数。
