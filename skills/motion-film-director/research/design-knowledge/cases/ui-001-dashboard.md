# ui-001-dashboard · 固定画幅数据界面

- 版本：1；主分类：data-interfaces；类型：public-method-summary（非实证 Case）。
- 来源：已发布的[固定画幅 UI 研究合同](../../../references/static-ui-reference-study.md)第 1–8 节；此卡只导航通用关系，不复刊私有研究报告或反馈。
- 设计语法：中性容器、指标/标题/辅助文字分层、状态色伴随文字、同口径数据与图形映射。
- 适用：固定状态、固定尺寸的数据 dashboard 复刻；先量可用宽度和 gutter，再确定列数。
- 反例：为时髦擅改列数；把绿色当普遍好；为像素贴合篡改输入；将 tooltip 画面称 hover 功能。
- 复核：数据正确和可见映射分门，文字基线/图标独立核；长页同尺寸分板，不缩小整页掩盖细节。
- 边界：公开卡不携带作品验收证据，不证明任意尺寸、交互、可访问性、视频、音频或生产迁移已通过。
- 视频入口：[制作路径](../MOTIONSTUDIO.md)。将信息层级变成焦点和读时计划；现有布局/揭示/交接仅候选，按本片复测。
