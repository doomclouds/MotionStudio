# Public research interface

This source distribution contains schemas, empty catalogs and reusable validation tools, not the private research corpus or production review history. Start with [the generic workflow](video-knowledge/WORKFLOW.md). Store real case libraries outside the repository and pass `--root` to the knowledge CLI; use `--catalog` for your own SFX metadata. No media is bundled or fetched.

## Design methods

[UI 设计总索引](design-knowledge/INDEX.md) organizes explicitly authorized, de-materialized method summaries by problem category, with a [MotionStudio production map](design-knowledge/MOTIONSTUDIO.md). These are navigation summaries, not private evidence records, media, or video Case/Technique entries. The default video knowledge catalog remains empty.
