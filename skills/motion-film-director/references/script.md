# 选题脚本：让行动承担主张

1. 用一句话写受众、观看理由与结尾变化。风格锚点认可不等于授权直接复刻：区分可迁移的透视、材质、遮挡等原则与原作者独特动作链，依本次原创/复刻目标另作选择。写明当前是原创机制借鉴还是按授权参考忠实复刻；不要用“不要抄外观”的泛则取消复刻目标。
2. 分开研究题材事实与视觉/时间参照。功能事实有出处不等于已观察影片；记录实际访问方法。重要动作选一个相关可观察参照或原创对照，不能借名作声誉代替证据。
3. 对有交互/表演的关键对象记初态→动作→结果→先前出现。若前面已达目标，后面“创造”可能是无意倒退重演。身份可接力、构图可变，不要求同物全程占屏。
4. 先核片型、主张与材料，完整原创或结构调整用低成本全长预演检内容，关键动态短样检实现风险；两者不互相代替。局部修复按影响范围验证。

**按片型选择结构**：同一任务跨工具推进适合证明工作流闭环，不是所有片的模板。成果showreel可由少量代表性真实输出证明质量与范围；解释片按概念依赖，角色故事按选择与后果。多项能力不必杂乱，单一对象也不自动代表新品；取舍看本次主张与证据，不由“更容易画”决定。


## 正向决策单：从一句话排成可拍的顺序

先列最小主张表：“必须知道或相信什么｜为什么值得占用时间｜哪份可见证据支持｜未知/舍弃理由”。产品事实、真实演示、实际生成输出、解释性动画与虚构情节分开；博客能力声明不授权编一个成功结果冒充实测。成果核来源、归属、使用权与人工加工边界。

每拍写视听卡：“ID/版本｜本拍主张或情绪任务｜证据来源/真伪状态｜画面主体、布局、可见动作或变化｜准确屏幕文字｜VO/音乐/SFX/有意静默的职责｜起止/读时｜前后连接｜验收问题”。有交互再补对象初态、触发、结果与身份，不强制同物贯穿、一句一镜或旁白存在。画面不能只写“展示能力”，声音不能只写“史诗”；读时从完整显现后的真实可读停留核算，入场/遮挡时间不自动算阅读。

先检查新品是什么、主张为何可信、材料能否支持、是否偷换主题。角色必要性只在角色驱动目标下验，发布片还核信息层级与证据覆盖。隐藏字幕可诊断局部动作，不能取消有意义的标题、数据或声音信息。独评问题跟随本次目标：工作流可问谁改变了什么，发布片须问记住什么主张、哪份证据使其可信。



## 原创规划：让方案本身接受淘汰

原创且方向未定时，按委托要求数量比较实质不同候选；每案写“为何值得看｜必需材料与条件｜信息/证据组织和视觉机制｜最大失败风险”，说明选择与放弃理由。用户已选方向就沿其推进，重大改变才确认，不为流程重开选项会。先判断观看价值并核材料；虚构故事或合法演员素材可以成立，不冒充真实亲历或产品事实。

完整片用低成本全长animatic检主张、顺序、读时和声画分工，关键短样只检最难动作、材质、转场或吞吐。局部无需解说可读不是所有片的硬门。执行失败修实现；主张/材料/时序失败回改方案，不靠加特效或扩片掩盖。技术通过、单帧认可与复刻逼真不替代内容或用户成片验收。

具体研究优点及局部创新，先填[作品机制卡](reference-mechanism.md)：先定位事实与竞争解释，再定反事实、迁移条件和短试失败信号，不把参考表面或手点精确绑定当作用机制。
