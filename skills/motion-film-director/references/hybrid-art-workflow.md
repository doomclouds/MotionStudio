# 混合美术生产：生成资产，原生编排，按镜头验证

**何时读**：代码造型/材质不足以达到已定美术目标，或场景包含生成图与可动角色/产品物体时。它是可执行制作路线，不是“全部交给imagegen”的风格命令。精确UI/字体/几何继续原生绘制；主生产核心仍离线Canvas。图像生成是上游资产阶段，不是逐帧运行时依赖。


## 1. 按需要的控制选择媒介

|所需结果|优先路线|换路线的信号|
|---|---|---|
|精确排版、真实UI、品牌矢量、图表、规则形变、可交互状态|原生代码/既有可编辑矢量|不是“简单”才用代码；可读字形与功能状态不烘进图里冒充实时UI。|
|复杂造型、材料、氛围、单一/有限视角场景，代码美术达不到目标|imagegen制作可注册资产＋Canvas独立运动|只需一幅海报时可用整图；需要动作/遮挡/接触时必须按下节拆层。|
|跨视角同物一致、绕行露背、强透视、真实体积接触、反射/光源随运动大幅变化|真3D建模/渲染，或经确认改镜头|不要让2D贴图假转面。当前原生核心不自动获得3D能力；缺工具/资产/授权时先提出可执行替代，不私装引擎。|

混合选择到**对象与镜头**，不是全片二选一。比如材料丰富的静态舞台由生成资产承担，按钮形体可生成，按钮符号/文字、状态与角色仍由代码承担。优先沿用获认可资产；不因新工具可用就换掉用户已定样式。

## 2. 先定运动合同，再生成

复制[brief与检查单](hybrid-art/brief-checklist.md)，按实际镜头填：观众要看见的变化、起止姿态、谁碰谁、下一镜入口、景别/镜头范围、必要留白、资产职责。一个最难的动作短试胜过只选漂亮hero。

生成请求至少声明：
- 镜头视角/透视/主光方向、画面尺寸与最终最大放大率；纹理分辨率和输出合成分辨率分别记录，不把低清放大称原生高精。
- clean plate保留静态场景，但移除所有将独立移动的物件及其不应固定的阴影/反射；前景移走后下面也有真实补全内容。
- 独立前景、动态物件用真实透明alpha；需要接触的完整轮廓/背后遮挡区域不能裁掉。透明棋盘画在RGB里不是真透明。
- 角色数量、主体轮廓、材质与配色、空白文案区、接触面、镜头安全框与overscan；背景中不得残留动态物件副本。
- 同一批层共享构图参考与注册坐标。不要分别自由生成四张“差不多”的图，再强拉变形凑接触。

用当前可用且获授权的图像工具；本环境优先内置imagegen，透明资产启用transparent background，编辑前实际看输入，版本化保存。失败不默默切付费API或其他模型。这里只描述所需资产，不承诺生成工具会直接给出准确锚点：**锚点由实际图检查后测量**。

## 3. 资产接入门：先验层，后开长片

以[规划manifest示例](hybrid-art/asset-manifest.example.json)为字段参考；它不是引擎API，也没有真实资产。进入制作时复制到项目，补实测尺寸、hash、alpha、锚点与来源，拒绝把planned/null当ready。

1. **清底/去重**：逐层隐藏角色、按钮、桥、前景，背景仍可独立成立；动态物件原位置不能有第二份轮廓/影子。背景已烘焙的主地形可保留，但必须声明不可独立运动。
2. **alpha**：在亮/暗/棋盘底、原生尺寸和最大预期放大下看毛边/黑晕/白边；实际alpha统计与目视分开。不要为遮边全景模糊。
3. **注册**：记录文件局部原点、局部接触点/支撑线、到世界坐标的变换、层序、相机组与近景额外视差。原点不等于bbox左上或角色中心；实际脚底/钳口要能求到同一世界点。
4. **光照边界**：区分静态烘焙光与需独立重画的接触阴影。物件平移后阴影还留原地、不同层主光矛盾、视差露空都要修；大幅转体改变明暗时转3D或换镜头，不宣称实时照明。
5. **安全框**：把最大推近、震动、移位、前景视差和交接过程都跑一遍；检查露边、裁脚、遮住文字/接触点。安全留量从镜头轨迹推导，不套固定百分比。

**局部材质编辑的遮罩门**：保护区外像素差为0只证明修改被隔离，不证明几何注册。把生成结果与原图的外轮廓、边缘高光/厚度、顶面与侧面的折线、前后遮挡分别在原生尺寸和最终观看尺寸对照；保留原边缘也可能出现双高光或断面。生成形体已移位时，不要把它硬裁进旧遮罩就判通过。先限定一个可验证的修正目标与重试范围；仍不匹配则保留原资产，或经批准缩小修改范围，未覆盖部分明确记录。单个资产失败不推导为生成工具普遍不可用。

一个可审短样须至少经过预备→接触→结果→恢复/交接，不能只有静态合成。资产未过门先停止全长精渲染，定位到层后局部修复/重生；不要反复盲目整图生成。

## 4. Canvas承担动作，而非替整图摇镜头

- 有限视角图集的相同锚点不保证投影宽度连续；姿态交接须检查原生相邻帧的轮廓/宽度跳变，不把离散换图称连续转体。缺中间视角时优先保持稳定角度、调整走位与遮挡，或另行确认所需资产。
- 同一状态同时驱动物件、角色支撑点、界面状态与声音事件；操作结果不能早于接触，抓握期间局部钳口须随物体变换后保持世界接点。
- 世界相机作用于所有世界锚，屏幕UI另列；前景视差是声明的例外。遮挡按真实层序，不能用突然删除物件代替穿越。
- 上一幕行动制造下一幕入口，沿同对象/速度/落点接场；同一贴图在下一页出现不等于动作连续。整图pan可以是建立镜头，但不能冒充物件运动、受力或完整动画。
- 保留已认可独立短样的源与媒体。整片语境确需最小状态适配（如首次踩播放后即时显示暂停）时先确认范围，独立包装并检变化区，不能机械宣称全部像素锁死，也不能借此重做全部美术。
- SFX从实际接触采样帧取事件，音乐按叙事段落/停顿组织；帧时刻与理想半帧点分开。改动作后重核声音事件与有意静默，不以峰值安全、LUFS或音轨存在代替实际合听。

## 5. 证据、回退与完成条件

沿用[分层自审](guided-self-review.md#25d资产接入与动作责任仅在分层图像参与动画时)和[验收](qa.md)，不另设一套艺术自动评分。

|证据|要证明什么|不能推出什么|
|---|---|---|
|原生关键帧＋实际编码帧|造型、alpha、遮挡、接触点与文字在目标尺寸成立|静态hero好看≠整段节奏好|
|关键动作密采样/相邻帧＋正常速观看分别记录|事件先后、钳脚连续、跨幕路径、普通观看理解|密采样不等于常速；暖读改善不等于fresh理解|
|版本/资产hash＋变化区回归|获认可不变项、修复区域外未意外改变|区域可覆盖全屏时不能声称全屏不变|
|新renderer乱序seek＋独立目录clean restore|已冻结源/资产能重绘所声明帧|15帧不等于全片；候选恢复不冒称Git clone；同机不等于跨平台|
|实际合听与用户反馈|听到的职责、明确认可范围|技术绿灯不抵消艺术否决，局部认可不扩成长片|

输出：简短媒介决策brief、实际资产清单/来源与许可边界、按版本绑定的短样/成片、接触/遮挡/相机证据、修复与未验项、可恢复源及必要资产。原片参考/无权分发资产与生成缓存不混入源包，source-only仓库按既有守门；资产单独合法保存，manifest用相对路径与hash，不带私有定位符。

失败回退：身份/层级不成立→先改构图；alpha/重复/接触锚坏→修对应资产；透视/背面不足→换获准镜头或真3D；动作不懂→改后果与交接，不用字幕/相机晃动盖；艺术被否决→停对应精修并重选实质方案。新外部服务、安装或范围扩张须另获授权。达到本次约定的技术、感知及用户审批范围才交付，不凭完成清单宣布艺术成功。
