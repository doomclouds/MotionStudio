# 可重建交接：路径、输入与执行

本页供 UI、Motion、声音导演共用，补充现有交接记录中的恢复说明，不增加 JSON schema、自动执行器或新的艺术验收门。只有用户要求可编辑源码、接续制作或可迁移交付时，才要求相应重建范围；普通成片交付不因此强制附工程包。记录放当前私有项目的 README/交接说明，既有交接记录指向它，不复制多份可独立漂移的配置。

## 生产方必须给接收方什么

- **范围和身份**：明确重建什么（静态资产、声音 stem/master、片段或完整成片）、源码 revision/hash、配置/输入/依赖版本及校验值、已知平台和未锁定部分。列预期输出的相对位置及可核验属性；逐字节一致仅在确有适用环境与证据时承诺。
- **可解析根与路径**：声明项目根、MotionStudio/Skill 根、素材根、输出根各从何处传入；项目内文件优先相对其明确基准定位，例如配置文件目录，而非隐含 shell cwd。不得把作者机器 `/workspace/...` 等绝对路径当可迁移入口。跨仓库/外部素材通过显式参数或环境变量绑定，说明变量含义与合法根，不把外部路径硬编码进 scene import、timeline 或私有脚本。
- **真实输入和获取**：逐项说明 scene、时间线、字体、音频、图像、模块、工具与锁文件的实际来源、版本/hash、恢复/安装步骤及许可边界。受限素材不随包复制，提供用户供应/授权缓存恢复条件；缺少它们时标为条件可重建。能打开旧 master 不等于能重建它。
- **完整命令**：给接收方按序执行的准备→校验输入→渲染/混音→封装→验证命令；明确 shell、起始 cwd、必需参数、变量赋值方式和输出目录要求。命令须对应实际脚本/API，不仅写“见引擎文档”或给一次运行日志；省略号、待填路径、未经核实命令必须标注未完成，不能称一键恢复。引用公共安装说明仍须给本项目真实入口和配置绑定。
- **例外与边界**：只能本机恢复、必须指定现有安装、不能重新获取的素材、平台限制、尚未核验的转码/字体差异逐项说明。校验 hash 不授予文件读取、上传、分发或执行权限；不得用重建脚本绕过允许的素材根或静默安装/联网。

运行时 API 需要绝对路径并不与可迁移交接冲突：入口从接收方显式提供的根解析生成本地绝对路径，校验后传入核心。尤其音频 timeline 不支持 `..`、网络 URL 或任意表达式；不能为追求“相对路径”破坏它的合同。可提供符合合同的接收方配置生成步骤，保留输入声明与生成配置的身份及实际映射。不得直接搜索替换未知私有路径后声称可用。

## 接收方怎样验证

1. 从交接入口定位所需文件和输入，不依赖作者的额外口头补充。检查声明与实际文件/版本/hash是否匹配；输入缺失或权限未决就停止相关执行并记录具体缺项。
2. 在新的授权项目根和新的输出目录，按给出的完整命令执行目标范围。尽可能使用不同于作者路径的目录，避免当前机器已有私有依赖掩盖缺口。无需为验收删除或隐藏作者原文件；共享机器/缓存/安装的限制必须记录，不能因此宣称干净机器或跨平台通过。
3. 对照预期输出属性及受影响证据。分别记录：路径/输入可解析、实际执行、输出身份/技术检查、视觉、听审、声画与用户接受。重建执行成功不等于艺术通过；只重放旧输出不算重建。未运行命令保留 NOT_RUN，不能以文件存在或结构测试代填。
4. 将接收失败的缺失命令、绝对路径、隐式依赖回给生产方修订同一说明；必要时重新执行受影响步骤。仅修文档未在新根重跑，标为“恢复说明已修，迁移待验”。不要把一次同机成功扩大为可分发、可公开或跨机器可移植。

UI 提供静态源码/资产及设计输入，声音提供音源/时间线/混音入口，Motion 提供集成/封装入口与整体依赖；当前主负责人合并完整执行顺序，接收方检查本次委托范围。不要求三人都独立维护一份安装手册，不相互用对方的局部执行结果替代整片恢复。
