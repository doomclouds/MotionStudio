# 动效技术检查工具（独立候选版）

**用途：给任意本地成片生成可离线检查的目录，帮助找到需复看的时间窗。不是完整视频质量验收，不是显著性/注意力热图，不是AI或审美评分。**

> **本图找时间窗，不能证明逐帧无故障。** 默认仅 **4Hz、最大边192像素**，会漏短震动、单帧卡顿、短闪光及细小运动。全量decode没有报错，也不等于画面没有艺术/连续性/内容问题。低运动不等于没内容；静止不自动报错或亮红灯。

这是独立工具候选，不修改、替换或扩写冻结中的RC2。脚本不依赖现有影片工程、Canvas运行时、项目时间线或固定30fps/时长。

## 用法

在已有依赖的环境运行；本工具不联网，不自动安装软件。

```bash
python3 scripts/motion-check/motion_check.py "/path/to/我的成片.mp4" --out "/path/to/检查目录"
```

中文图注可指定**已有、合法可用的本地**中文字体。只读取字体，不把大字体或原生库复制进工具/报告。

```bash
python3 scripts/motion-check/motion_check.py "/path/to/成片.mp4" --out "/path/to/检查目录" \
  --font "/path/to/NotoSansCJKsc-Regular.otf"
```

未传`--font`时：PNG/JPEG图注回退英文，**HTML与报告说明仍为中文**，报告会明确回退。中文字体需自行确认包含中文字形；仅验证文件可被Pillow读取，不能据此证明字体授权或完整字形覆盖。

- 输入必须是非空本地文件；URL不接受。媒体子进程只允许`file,pipe`协议，无网络API或模型。
- 路径通过参数数组传入，不经过shell；支持输入/输出路径空格。
- `--out`必须是新目录或空目录；**拒绝覆盖已有报告**。
- 不改输入；报告记录输入文件名、字节数、SHA-256，不复制输入成片、参考视频或原音。
- HTML只含相对文件链接、内联CSS和静态图片，无JavaScript、CDN、字体请求或localhost服务。可以离线读取；本次仅做静态结构检查，**未用浏览器或localhost渲染**。

## 输出是什么

| 文件 | 含义 |
|---|---|
| `index.html` | 自包含目录入口；中文说明、醒目局限、图和报告链接 |
| `report.json` | 总状态、真实文件元数据、原始逐帧统计、参数、技术发现；键名保留英文便于程序使用 |
| `ffprobe.json` | 容器与全部流的格式、时长、起始时间、时间基、声明帧数、音轨等白名单字段；不保存自由文本标签 |
| `frame-census-errors.txt` | ffprobe逐原始帧读取时的错误日志 |
| `decode-errors.txt` | 请求全部视频/音频流进行完整decode的错误日志，不检查字幕/数据流 |
| `motion-energy.csv` | 相邻采样帧的平均RGB差、超过像素阈值的比例、像素差第95百分位 |
| `motion-and-change-heatmap.png` | 帧差能量曲线 + 时间/垂直位置变化热图 |
| `spatial-mean-change.png` | 全时段平均像素变化空间图 |
| `contact-*.jpg` | 按时间顺序排列的低清采样帧；时间是采样网格时间，不伪称原始帧号 |
| `audio-N-ebur128.txt` | 第N号音轨的整轨EBU测量摘要；不保存容器自由文本元数据或原音 |
| `versions.json` | 本次实际依赖版本，便于迁移后对照 |

坏的非空媒体会留下失败报告/静态入口（能写盘且依赖可用时）。不存在/零字节输入或非法参数退出时不创建结果目录。部分步骤失败会明确标为未完成，不把缺失项视为通过。

### 帧数、起始与时长

- 读取实际成片的容器/视频/音轨时长和起始值，而非设计时长。
- **选定视频流的帧数由ffprobe逐帧解码计数**，不做`时长×标称帧率`估算；支持可变帧率输入。
- 分列首/末`best_effort_timestamp_time`、末帧时长、末帧结束时刻、含末帧的观测跨度。不存在的时间戳保持空值，不编造。
- 容器元数据可能不准；观测跨度仍依赖可用的帧时间戳/末帧时长。损坏文件的计数可能不完整，错误会披露。
- 报告各音轨与视频流的起始时间差。**这只是元数据线索，不是听审、声画落点检测或感知同步证明。**
- 可视化仅选第一个非封面视频流；全量decode请求所有视频和音频流；每个音轨分别测量。

### 帧差、热图、阈值的定义

1. FFmpeg以首个解码视频PTS归零，按均匀网格采样；`fps=...:round=near:eof_action=pass`选择/重复/丢弃源帧，再按显示比例低清缩放、转8位RGB。最后不足一个采样周期仍可有一个样本。
2. 对像素`p`：`d(p) = mean_RGB(abs(F[t,p]-F[t-1,p])) / 255`。
3. 曲线值为全图`mean(d)`；CSV另记`mean(d > 8/255)`和`percentile(d,95)`。首帧无前一帧，仅作零值绘图占位，**不参与比较统计**。
4. 时空热图：横轴时间；纵轴从画面顶部到底部；每行沿画面宽度平均，因此**丢失水平位置**。
5. 空间图：每个像素在全部相邻采样对中的`d`均值。它可能被大幅相机/背景变化主导，**不是人眼注意力、对象追踪或运动向量**。
6. 热图使用固定绝对色标：0%、2%、5%、15%、100%为颜色插值锚点，不对每张图自动增艳。曲线纵轴会按该片最大值自动缩放，并在图内标明。
7. 默认低/高变化边界是`0.003`/`0.10`（归一化平均RGB差），**仅统计有多少采样对落在该范围，不是通过/失败阈值**。像素变化阈值默认`8`（8位通道量级的平均绝对差）。

**切镜、纹理、噪声、闪光、曝光/颜色变化也会产生高能量。静止可能正是留白、阅读时间或有意设计，绝不能单凭这些图判断没有内容。** 普通8位转换不是线性光/HDR/色彩管理感知指标。不同采样率/尺寸/编码条件的结果不可当评分横比。

### 音频

- 对每个音轨执行FFmpeg `ebur128=peak=true`：整轨综合响度（LUFS）、响度范围（LU）、真峰（dBTP）。
- FFmpeg EBU真峰摘要原标签为`dBFS`，这里在“True peak”上下文记录为dBTP；不是普通采样峰值。
- 不归一化、不改音量、不导出原音。无音轨不是错误。
- 不预设平台/风格响度目标，不自动评价音乐或音效是否好听。静音/极短音轨的响度范围/门限可能没有实际意义，必须结合原片听审。
- 所需滤镜或编解码器不可用时报告未测/失败；不能假装通过。

## 参数与资源

```text
--sample-fps 4       0.1–30Hz；升高可帮助定位，但仍非逐帧验收
--sample-size 192    最大边32–640像素，保持显示宽高比
--thumbnail-every 2 请求每2秒一缩略图；长片会按上限自动增大间隔
--max-thumbnails 240 近似上限，可能另加最后一个采样帧
--max-samples 100000 超限明确失败，不静默截断并声称检查全片
--pixel-threshold 8 计算变化像素比例的8位RGB均差阈值
--low-change .003   仅描述性计数，无质量结论
--high-change .10   仅描述性计数，无质量结论
--timeout 1800      每个媒体子进程的秒数上限，不是整个任务总时限
--ffmpeg /path/...  可指定已有可执行文件
--ffprobe /path/...
--font /path/...    可选已有本地中文字体
```

帧读取按流进行，不把全高清视频帧堆在内存；保存低清时空统计/CSV数据及少量接触表页面。超长片、极高采样上限/尺寸和多音轨仍会增加内存及运行时间。高分辨率源仍需完整解码；低清输出不等于解码成本低。遇到超限/超时，请根据目标调整设置后使用**新输出目录**重跑。

退出码：`0`=所请求技术步骤完成且没有decode等技术错误；`1`=技术错误/测量缺失/流程未完成；`2`=输入、参数、依赖路径或初始化错误。**退出0不是视频质量合格证。**

## 已验环境与迁移边界

本次实际环境（版本来自实际Linux运行记录；旅行片示例见下方）：

- Python **3.12.14**
- NumPy **2.3.5**
- Pillow **12.3.0**
- FFmpeg / ffprobe **7.1.5-0+deb13u1**（现成系统工具）
- Linux / x86_64；Pillow绘图，无matplotlib、浏览器、GPU、光流模型或网络服务
- 中文示例仅读取现有项目的`NotoSansCJKsc-Regular.otf`；**包内不带字体**

没有安装任何依赖。代码采用Python标准库+NumPy/Pillow；需要FFmpeg的`fps/scale`滤镜、`ebur128`及其真峰支持，以及输入格式的解码器。没有证明其他OS/FFmpeg/Pillow版本组合已通过；迁移时先运行下面的合成媒体回归测试并检查`versions.json`。`--fps_mode`等选项可能不被旧FFmpeg支持，不要直接把“纯Python”误写成“任意环境零依赖”。

```bash
python3 scripts/motion-check/test_motion_check.py
```

测试自动创建短合成片和正弦音轨，结束后清理；不用外部参考视频、原音、账户、密钥或API。实际自有片示例仅保留低清缩略图/测量和热图，不保留原片。分享报告前仍请自行确认画面缩略图与文件名是否适合分享。

不可信媒体可能触发FFmpeg/解码器自身风险；工具不是安全沙箱。虽然网络协议受限，`file`协议仍可读取本地引用；只处理有权且可信的媒体，不要把未知播放列表当安全输入。


## 本RC的实际样例与测试

变化热图由项目本地技术检查生成，脚本与输入 hash 保存在本地输出报告中；生成热图和样例身份不随源码仓库分发。它是4Hz/192×192采样RGB差，不是独立锚追踪、显著性、光流或美术评分；低谷可为阅读，高峰可为切换。先据图找复看区间，再回到原生帧/正常速观看与实际试听。报告原片不随Skill分发。

当前13项离线故障/边界测试通过；脚本和测试为本次原创抽象代码，不带原工程或音轨。Windows命令可将`python3`换成`py -3`并使用相应路径；Mac/Windows仍未实机验证。运行前检查权限与本地已有依赖，不自动安装。版本锁参考`scripts/motion-check/requirements.txt`；系统FFmpeg/ffprobe另查，不能只装Python包就声称环境完整。
