# 待审字段比较：完整内容、注意力与状态分离

适用于已有静态 UI/校样交接、需要解释少量 before/proposed 差异的影片。是有边界的导演方法候选，不是新的积木 API、配方、自动审批系统或常速视听通过证明。实际影片、来源与复验记录留在授权私有工作区；此页不携带个案媒体。

## 先守住信息，再分配运动

| 决策 | 适用条件与执行 | 可核证据 | 反例/停止条件 |
|---|---|---|---|
| 完整值先于其解释 | 短日期、编号、金额等依靠完整字串判别时，优先整串出现或整块淡入；解释该差异的文字在值完整可辨后进入。读时从完整显现开始算，而非空卡入场开始。 | 编码输出同 PTS 的旧新对照；揭示开始、完整值、解释出现及邻帧；目标观看尺寸核字串。 | 逐字输入是用户指定的真实操作/叙事，或解释本来是先行问题提示时，不强制倒序。半个数字或尚未出现的提议值却配“已改变”解释，须重排。淡入低透明度阶段也不能算完整可读。 |
| 一次只强调当前差异 | 多字段同时有高对比标记且当前镜头只解释一项时，可局部弱化非当前标记，保留对象 ID、字串、版本与归属；复述镜恢复完整对照。将显示处理写入 Motion 接收回执，不改原交接源。 | 当前/非当前/复述三个状态，前后同尺寸观察；核未遮掉状态警告或必读条件。 | 并列比较本身是任务，或弱化会掩盖错误、风险、否决状态时，不做单焦点处理。不能把删字、替换数值或过低对比称为注意力管理。 |
| 阅读状态与业务状态分开 | “聚焦/展示/比较完成”不等于“已审/批准/发布”。从交接读取负责者、计数与状态，按已授权事实变化；只有镜头推进时，待审值不因此升级。 | 开场、每个差异、复述与末帧的状态表；核标签、计数、图标、色彩及声音意图是否暗示未经证实的通过。 | 有真实授权和实际操作证据的状态变化可以展示；不能为保守而隐去真实结果。反之，勾号、成功音意图或自动递增计数也不能替代审批事实。声音是否被误解仍须实际听审。 |
| 语义 cue 单源 | 同一事件由画面与声音共同消费时，项目可使用同一有版本/身份的事件表；消费者按稳定 ID 读取，记录偏移、帧/样本量化与声音职责。改变事件含义或时间后，两端重跑。 | 查实际读取与输出绑定，不只存在一个 JSON；验证重复/缺失 ID、顺序/边界；绑定最终视频及声音身份。 | 事件表只是文档而两个消费者继续手抄时间，不能宣称单源。相同秒数不证明感知同步、可听性或无掩蔽；计划 cue 不冒充已实现通用自动同步器。 |
| 显式声明实际依赖 | 渲染合同依赖显式 `dependencies` 时，将真实读取的本地源、数据、字体、图像和可确定的代码依赖纳入身份核验；解释收集器能覆盖哪些导入形式。 | 渲染报告实际 source/path/hash 清单；修改依赖导致旧身份失效；同机乱序/重建代表帧验证单独报告。 | 正则扫描只能支持受限的静态相对导入；动态导入、条件路径、运行期文件读取、原生依赖不得假定自动涵盖。声明文件未实际消费也不能算复用；事后目录 hash 不能冒充运行期间身份核验。 |

## 最短复验闭环

1. 冻结来源版本/hash、before/proposed 文案、状态、对象映射和发布权限；静态通过不升级为动态通过。
2. 做覆盖完整信息顺序的预演与关键短样；判断是否真有不完整字串、无意义等待、争焦点或状态误读，不为流程故意制造缺陷。
3. 让独立审查先看真实输出与目标，再给作者解释；保留“未发现问题”和不同意见。
4. 针对证据做最小修订；同一 PTS 或显式事件映射复验，并看邻帧与末状态，防修复引入新裁切/隐藏。
5. 分别写技术、限定帧审、常速连续观看、实际听审、声画合看及用户接受。抽帧确认局部改进只支持其采样范围；未做的常速/听审不得改为通过。可交付诚实标注的待审候选，不得借方法文档完成或重复编码提升艺术结论。

没有统一的淡入时长、等待上限、对比比例或音量“合格值”。参数来自目标尺寸、字数与实际复看；本方法不能把某个短串比较的局部改进推广为所有 UI/影片的最佳节奏。

## 数量转移：守恒不等于看得清

当影片用离散对象解释分配、搬运或容量变化时，分别检查：

1. **语义与状态**：给对象稳定 ID；在任务确为守恒转移时，离位、在途、入位集合互斥且总量守恒；有生成/消耗/损耗时按真实合同核数量变化；当前与模拟状态分开。数值恒等只证明数据关系，不证明每件都被画出或观众能追踪。切到汇总表后如不再显示全部对象，明确表示法变化，不声称全片始终可见全部实物。
2. **实际绘制几何**：核移动对象完整扫掠与静态对象、其他移动对象、文字/标签的遮挡，而非只验起终点。需要保持独立身份时，可以试行间通道或分段路径，再复核转弯、速度、交接与入槽；标明几何检查覆盖主体、描边、阴影/光晕中的哪些范围；只检查主体边界不能声称这些外扩部分也无覆盖。离散帧采样或逐编码帧检查只支持所查时刻，不能证明帧间连续扫掠无交叉；要提出连续范围结论，需另有覆盖路径区间的保守边界或连续碰撞证明。几何无相交不证明常速自然或可追踪。遮挡若是有意的真实空间关系，不为机械“零相交”破坏叙事。
3. **编码与感知**：从离位前稳定态到新位置稳定态检查编码邻帧，记录标签何时仍可辨、何时被遮住；同 PTS 前后对照只能支持所查时窗。再做正常速连续观看与真实合听，才能评估追踪、节奏和声画因果；密集静帧也不能代填这些门。

反例：所有 ID 与计数正确，但飞行对象穿过既有对象，视觉上变成一团；或绕行后不再相交，却因急转、太快、标签过小而仍不可读。单项方法纠错仅是有限实现证据，不是优秀作品或已成功迁移。用户否定作品效果时保留作品质量负反馈，不得以数学、几何或局部修复通过改写成艺术认可；未经实际听审，只能列声音验证缺口和待评风险，不能伪造听后结论。
