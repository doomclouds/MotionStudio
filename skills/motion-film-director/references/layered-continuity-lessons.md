# 分层光效与片段接续：四个独立工程合同

适用于有限视角的图像分层、带尾迹的跨镜头对象，以及把已认可短样接入完整影片。以下是实际制作中经源码、原生帧/邻帧和回归记录核对的去素材化经验；不是新 API、通用物理模拟或全片艺术批准。该次制作尚未实际听审或常速连续视听，不能由工程修复推定这两门通过。素材、项目参数与证据保留在私有项目，公开文字不授予原作或音乐复用权。

## 作品质量不由工程合同担保

本页是工程排错指导，不是优质成片范例或默认风格推荐。局部曾获认可、像素一致或边界修复，不能覆盖后续对完整作品的否决。实际委托若被用户否决，须在私有 Case 中明确记录作品质量不通过；不能仍只列未听/未验，也不能把该版本记成艺术成功或成功迁移。保留已完成的技术证据；否决完整作品不等于本页各合同错误，也不意味着永久禁用分层/尾迹技术。

优先从明确的代码 UI/图形动作验证复用价值；若参考质量主要来自细腻光影、材质或运镜，本页不提供驾驭这些效果的能力证明。

## 1. alpha、注册、遮挡分别验证

**适用/做法：** 分层图像先核真实尺寸与 alpha，再记录“文件像素 → 合成平面 → 屏幕”的变换和层序。独立生成的前景可按构图注册，但不能称为背景的精确分割；近远层独立运动也不证明物理深度。接入细则沿用[混合美术生产](hybrid-art-workflow.md)。

不透明窗框遮挡窗外光点时，将窗外景、光核、辉光与尾迹一起画入开口 clip，恢复状态后再以不透明层覆盖窗框。窗口外不得泄漏，窗框后面的光效不可覆盖回来；未被遮挡的尾迹仍应存在。每组绘制用 `save/restore` 隔离 alpha、合成模式和裁切。

**反例：** PNG 扩展名不保证透明；只隐藏光核会留下穿墙辉光；整条尾迹同时消失则把局部遮挡变成对象删除。半透明玻璃、反射或主动发光窗框不适用“窗框像素恒定”的断言，须另立光学/美术合同。

**检查/局限：** 在亮暗底检查 alpha 边缘；在最终合成尺寸核位置、露边和近远层独立锚。穿越前、中、后查原生邻帧和实际编码帧，对无其他变化的不透明遮挡内部做有光/无光像素比较；抗锯齿边缘单独看。实际制作仅核过局部遮挡像素及邻帧，不是全像素自动泄漏扫描，也不是连续观感验收。

## 2. 同一光点的“位置、速度、历史”不是一个合同

**适用/做法：** 同一对象需连续接场时，在同一屏幕坐标系声明三个边界条件：

- **位置：** 两段头部在接点重合；有父层/相机变换时先换到同一坐标系。
- **速度：** 接点切向与速度大小分别匹配。曲线控制点只约束几何方向；弧长路径还需匹配时间进度的导数。屏幕速度包含父层/相机运动，不能只比较局部路径。
- **历史：** 尾迹采样保留上一段已经走过的路径前缀，再接新曲线；不要在镜头切点清空尾长。若需美术交叉淡化，两种尾迹应共享同一头部坐标，不让两个不同位置的光头叠化冒充连续。

**反例：** 头部不跳但尾巴突然缩短/换向；端点与切线一致却因 easing 重启而顿住。真实冲击、有意硬切或消散可允许跳变，但须明确因果，不套连续性合同强行抹平。

**检查/局限：** 每个接点两侧及整个过渡窗检查头部可见性、尾长/方向、层序；用相邻帧位移辅助核速度，再常速观看。该次制作的桥接采用已有 `compilePolyline` / `samplePath` / `sampleTrail`，并以解析关系匹配边界、保留路径历史；尾迹淡化期间两种尾形共存，是有限二维合成，不是物理输运、加速度连续或图像拟合速度的证明。沿用[运动检查](motion.md)，不因这次修复新建 primitive。

## 3. 以整数帧映射保护已认可片段

**适用/做法：** 同帧率、无变速且要逐帧保留短样时，冻结已认可 renderer、资产、字体、依赖与配置。完整片插入起帧为 `N0`，短样长度为 `M`，则仅在 `N0 <= n < N0 + M` 调用原 renderer：`k = n - N0`，局部时间 `k / fps`。保持与原渲染相同的时间计算路径；不要先算完整片浮点秒数，再减一个秒数偏移。早段复用几何可另设适配层，避免顺手改已冻结模块。

**反例：** renderer 文件 hash 没变，但资产/字体或外部状态变了；抽查几帧相同便声称整段锁定。改帧率、变速、裁切或局部改稿时不能声称原帧全等，须明确映射、变更范围和新验收。

**检查/局限：** 对映射范围内**全部**原生 PNG 比较 hash；另在新进程乱序、重复采样边界与内部帧，对照顺序渲染。全段身份回归和抽样确定性是不同证据，分别报覆盖数。实际制作已完成这两类核对，但不证明任意跳时或跨平台确定性。PNG 字节一致证明该配置下绘制保留，不代表有损视频字节相同、上下文/声音不变或完整片获批。见[渲染合同](render-contract.md)。

## 4. 视频帧时钟与音频样本时钟分别量测

**适用/做法：** 恒定帧率视频以 `N / fps` 定义帧覆盖区间；最后一帧起点是 `(N - 1) / fps`，不是视频结束时刻。源容器/AAC 因填充略长时，不为凑容器时长擅自多画一帧。音频目标长度按视频区间与采样率换算；非整数样本长度须声明取整规则和误差，不能声称任意帧率都能精确落样本。

声音事件先冻结对应视频帧及片段映射，再转换为音频样本位置；近似脚本秒数不替代实际遮挡/接触帧。事件可采用有意静默或衰减，穿过遮挡物不必硬配碰撞声。

**反例：** 用较长容器时长规划视频抽帧导致越界；拿 WAV 的响度报告充当最终 AAC 证据；峰值安全便声称听得清或同步正确。变帧率媒体须按真实 PTS/timebase 处理，不套整数帧除固定 fps。

**检查/局限：** 分别核视频帧数、流 timebase/时长与音频解码样本数，最终封装后全量解码并重测响度/真峰值。采样时钟对齐不能证明感知同步；编码器填充、起始偏移也须据实际输出核对。制作中的客观量测与完整解码已执行，实际听审与常速合听仍未执行。按[视听审查规程](audiovisual-review-sop.md)分别保留未验状态。
