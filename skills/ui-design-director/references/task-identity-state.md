# 条件式复核：任务焦点、跨区身份、状态语义

这是从固定画幅任务界面的有限静态修订归纳出的条件式方法；新增检查项不代表已经完成全内容覆盖，也尚未证明跨作品、响应式或 Motion 迁移有效。用于提出要验证的问题，不是固定布局、样式或组件配方。

## 任务焦点

当用户需要快速找出一个关键值/行动，而画面有强烈品牌标题或多个阅读区时，检查主任务答案是否只存在于次要区域。可提高它的层级，或在自然入口给出同源摘要；不要求所有关键数据一律放进 hero，也不默认重复全部信息。

核对实际目标尺寸下能否找到任务答案。摘要与细节若重复，必须使用同一内容源，避免修订一处而另一处过期。仅看到文字更大/更靠前不能宣称查找速度提升。

### 内容承诺的全域检查

当界面承诺“仅 N 项变化”或“其余不变”时，范围应覆盖已修改与声明未修改的内容，而非只核变更数组长度。列出 canonical 内容字段到各显示位置的映射、保持/变化规则及允许的展示格式变换；未获允许的缩写或替换也是偏离，不能因不在变更列表中就视为未变。任务没有这种承诺时，不机械套用固定变更数量。

核最终实际渲染路径，包括调用积木内部的文本，再实看目标输出：源码含正确字符串不证明已经绘制，绘制调用存在不证明最终未裁切/遮挡。只对有覆盖的字段声称通过；局部抽查不升级为全内容一致。转 Motion 时核各字段在相关镜头/状态实际出现时的内容，不要求全部文字每帧同时出现。媒介适配若改变表达，记录依据与未验范围，不能仍称原样不变。

基线恰好正确时，硬编码可能伪装成同源。若作品宣称支持一类输入，用任务相关的合法变体检查：输入改变后，显示值、汇总、几何及假设结果是否一同变化，并核不应变化的内容。将合法变体发现的一致性缺陷、非法输入拒绝和视觉边界容纳分别记录，不凭一次变体通过声称任意输入能力。支持域与边界按 [交接合同](handoff-contract.md#输入支持域与可视边界) 声明，不从历史测试名称推断输入是否合法。

## 跨区身份与顺序

当同一对象出现在地图/空间区与列表/时间区时，提供可辨认的稳定对应关系，例如一致名称、短 ID 或必要的图形标识。不要只依赖颜色或空间位置。只有内容确有顺序/方向语义时才显式编码方向；无向关系不能为了清楚而擅自加箭头。

静态复核应能明确配对对象和说明顺序；Motion 还要核同一对象在聚焦/裁切/过渡后是否保留身份，不把淡入另一张卡片当已证明同一对象。字母徽标仅是一种方案，不是每个项目的规则。

匹配编号还须检查标签与目标字段的邻近关系、唯一性及语义对应；同编号在两处出现不是映射可用的充分证据。编号可能表示审阅顺序而非地理路线，不据此推导箭头或因果。可在隔离夹具交换两个编号的语义对象或改变一个字段，确认映射测试能检出错误；负例不得进入用户交付，恢复 canonical 后重跑。

## 状态语义与责任

当 pending、confirmed、done 等标签可能有不同解释时，拆开：谁/什么对象、哪项事实或安排、当前状态、依据、下一行动及责任方（已知时）。不知道责任人或业务映射就保留未知，不能凭视觉设计补造。

把状态文本/计数/图标与同一数据模型核对。准备项完成不等于操作执行、出席确认或风险/安全许可。示意界面须就近标明假设，不让正常产品语气造成真实执行的错觉。

状态文案明确仍不够：交叉检查外形、色彩角色、位置及反馈是否暗示不存在的操作或更强的状态，例如待审却像已接受。让状态与动作可辨，但不要求全部状态无底色或一律禁绿；没有真实交互时，静态按钮外观不代表动作已实现。Motion 的勾选、庆祝音效或完成转场也不能升级事实状态。样式变更可见不等于误点率或误读率已被证明下降。

展示假设变化时，每个可能单独被看见的结果区、角色标签和摘要都应保持条件语义；只在页脚标演示可能不足。优先精准标签并实核误读，不强制每区重复长免责声明。当前量、局部空位、超额量与假设结果须分清口径，不因总量关系成立就混用指标；仅在任务确有守恒/容量等关系时核对应约束，不给消耗或损耗场景套守恒公式。动画不得把模拟结果演成已发生的业务事件。

## 迁移验证

这些检查仅在任务结构相符时使用。先给独立审阅者任务和真实输出，让其自由陈述答案/对应关系/状态含义，再看作者解释；对状态另问已发生、尚未发生及可执行动作，与真实状态表核对，保留误读原话与反例。静态/影片表达验证不冒充点击可用性测试。换尺寸、换状态或转 Motion 后必须实际复验；结构测试与源码同源性检查只能补充，不能代替理解与观看证据。
