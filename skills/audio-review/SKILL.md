# 音频审核 · 可复用仓库流程

输入为实际音频/最终编码、用途与目标、选定范围，以及可选参考/旧版；输出为源绑定的听觉观察、技术测量、覆盖/未知和待修问题。纯音频任务不强求视频；影片任务必须绑定最终封装中的实际音轨，不以混音前 WAV 冒充最终 AAC。

本页是薄入口，听审和裁决唯一正文为[视听审查规程的听觉部分](../motion-film-director/references/audiovisual-review-sop.md#c-听觉感知与指标分轨)，技术能力归 [Audio Core](../../engine/motion-audio-core/README.md)，模型配置/上限归[适配器合同](../../scripts/AUDIO-REVIEW.md)。定位真实仓库根并记录 commit；可直接读本页执行，不代表宿主自动注册。依赖可由完整仓库或四目录组合包提供；单独复制本目录不够，发现方式、便携根与精确命令见[安装与调用](../MEDIA-SKILLS.md)。

## 实际听审与指标分轨

1. 冻结文件 hash、声道/流选择、范围、编码/采样域及源→影片时间映射。选段标明原片时间、片段相对时间与未覆盖区间，裁剪边界不当原片开头/结尾；分段覆盖也不自动证明跨窗连续性。
2. 先核是否存在真实音频输入/播放能力：真人实际听到，或原生音频模型确实接收到声音，才产生听觉观察。只读转录、提示词、源码、波形、LUFS/onset 时保留 `NOT_LISTENED / NUMERIC_ONLY`。没能力可做技术诊断，不选“更好听”的胜者。
3. 实际听完整委托范围，再回问题窗；按内容查人声可懂度/表演、音乐发展/结束、必要 SFX 的可辨与职责、掩蔽、爆音/硬截/失真/疲劳。不按类别清单编造本来不存在的声音。参考 A/B 核同时间窗与播放条件，避免只因更响判更好。
4. 用[声音制作工艺的质量问题](../motion-film-director/references/sound-craft.md#7-质量标准技术听觉声画分别回答)解释问题，再用实际测量定位；目标 LUFS/真峰由交付需求决定，不设通吃平台的分数。技术通过不消除听觉反证。
5. 模型输出是待核意见，核实际原声、范围与不确定性后裁决。修改或重编码使受影响证据失效；复听上下文和最终混音，不仅 solo。影片同步交[视频审核](../video-review/SKILL.md)的常速合看步骤，本 Skill 不循环启动另一导演。

## 可执行能力与安全配置

- 本地检查：Audio Core 提供实际 `probe`、`inspectEncodedAudio`、解码/测量和资源边界，按其 README 使用。它不播放给审查者，也不自动认定听感。
- 音频模型 dry-run：仓库根执行 `python3 scripts/audio_review.py --audio /authorized/selected.wav`。只核本地 PCM16 WAV 输入与预留费用，不读 `.env`、不联网、不算已审。当前最多三个显式选段，每段 ≤20 秒，限制以 `--help` 与合同为准。
- 从最终视频派生：`audiovisual_review.py prepare` 按[适配器合同](../../scripts/AUDIO-REVIEW.md)在本地绑定原片和真实解码音频，保留 manifest；音频单独回执的时间是片段相对时间，不自带已核原片映射。
- 真实服务调用：仅在已批准的媒体/区间、阿里云北京接收方、审核用途及预算内，核当前价格再用现有入口。存在 key 不授予上传/计费权限；模型失败/费用不确定不自动重试，不换 session 规避限额。
- 固定私有配置是适配器安装根 `.env`：源码模式为仓库根，Motion portable 为 Skill 根，不是媒体项目 cwd。只由用户通过安全配置途径填入 `DASHSCOPE_API_KEY`，不从聊天检索/复制密钥，不读出展示、不写日志、不入 Git/报告/归档；现有文件不覆盖。配置方式与权限检查读合同，不新增并行密钥存储。暴露过的旧 key 应撤销后安全换新，不能为验证而调用它。

无配置时模型入口记录 `SKIPPED_NOT_CONFIGURED`，真人路径仍可继续；没有实际听审者则该门未审。此适配器是评论服务，不是配乐/TTS 服务；没有调用就不能声称服务可用、模型判断准确或已经计费。

## 输出与能力边界

将技术值/测量可用性与听觉记录分列，注明实际输入、执行者/模型回执、覆盖、时间观察、证据、未决项和复验结果；另列声画同步与用户接受。沿已有项目记录及交付 schema，不新造一套 PASS 台账。需要改声音时交给[配乐生产](../soundtrack-production/SKILL.md)或既有声音导演，保留当前问题与已接受范围。

离线能验证输入、安全拒绝、解码/混音和模拟响应合同；不能验证在线服务、实际计费、真实听审、立体声感知或用户喜好。独立入口通过[组合包](../MEDIA-SKILLS.md)与一份 Motion 共享依赖并列分发，不承诺单目录自足；原单 Motion portable 继续用所带审核脚本与正文。
