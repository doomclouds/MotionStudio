# 声音导演 · 仓库内入口

先分清用户说的“配音”是人声表演、配乐、音效，还是整条声音。用已有媒体与上下文确认；不确定且会改变工作范围才追问。不把参考混音的认可解释成某种人声、合成器或原创配方的认可。

直接声音委托无需先制作影片；Motion 委托则接收其锁定的画面、时长、事实与权限。声音导演负责声音方向、素材选择、旁白表演指导与混音取舍，Motion 导演负责最终画面、时间线和整片交付；冲突回到当前委托，不互相预签验收。

唯一工作流正文是 [声音导演工作流](../motion-film-director/references/sound-direction.md)，人声任务按需读其中的旁白指导。原创或重大重设计先沿正文进入共享参考发现→蒸馏→组合闭环，实际听参考、跨例比较并回到制作验证；缺听审不冒称研究完成。现有 [声音书架](../../knowledge/design/library/sound.md) 仍是工具/领域资料入口，不复制另一套知识库。先定位真实仓库根并记录 commit，再核实际工具、素材和授权。

本入口是可读工作流程，不是自动代理调度、TTS 服务、作曲模型或听审模型。此版验证目标为路由、文档可达性与便携工作流，不声明已完成真实影片或配音质量验收。独立声音 Skill 的打包与宿主自动注册尚未实现；现有 Motion portable 包携带工作流正文和人声指导，不携带本入口。私有媒体、声音身份、反馈和实际记录留在授权项目，不随 Skill 发布。
