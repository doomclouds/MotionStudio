# 声音导演 · 仓库内入口

先分清用户说的“配音”是人声表演、配乐、音效，还是整条声音。用已有媒体与上下文确认；不确定且会改变工作范围才追问。不把参考混音的认可解释成某种人声、合成器或原创配方的认可。

直接声音委托无需先制作影片；Motion 委托则接收其锁定的画面、时长、事实与权限。声音导演负责声音方向、素材选择、旁白表演指导与混音取舍，Motion 导演负责最终画面、时间线和整片交付；冲突回到当前委托，不互相预签验收。

任务已明确时可直接使用薄入口：[配乐生产](../soundtrack-production/SKILL.md)负责选用/编排/制作音乐，[音频审核](../audio-review/SKILL.md)负责现有音轨的实际听审与技术诊断，[视频审核](../video-review/SKILL.md)负责连续视觉和声画合看。它们继续读取下列唯一工作流/制作/审查正文；不自动启动其他代理、不重复生成报告或互相循环委托。旁白和配音表演仍走本导演的人声指导。现有阿里云适配器仅做可选审核，不提供音乐生成。

需要实际处理配音、配乐与音效时，按需读[声音制作工艺](../motion-film-director/references/sound-craft.md)：从段落意图、动机发展、表演take到独立声部和最终混音；自己承担制作和复验，不以参考整混音或技术指标代替。

唯一工作流正文是 [声音导演工作流](../motion-film-director/references/sound-direction.md)，人声任务按需读其中的旁白指导。原创或重大重设计先沿正文进入共享参考发现→蒸馏→组合闭环，实际听参考、跨例比较并回到制作验证；缺听审不冒称研究完成。先读 [声音书架](../../knowledge/sound/INDEX.md)，从 [声音资产目录](../../engine/sound-elements/INDEX.md) 找可调用 SFX/BGM，逐件读 asset.json 的意图、入口、权利和未听审边界。默认候选不是质量认可；本地生成输出也须真实合听。先定位真实仓库根并记录 commit，再核实际工具、素材和授权。合成前先执行正文的听审能力停点；未听参考可做明确标注的技术草案，不可宣称参考分析完成或质量通过。方向展示须给用户可播放的同画面比较（纯音频用同时间窗/播放条件），反馈后再决定保留/撤回。

本入口是可读工作流程，不是自动代理调度、TTS 服务、作曲模型或听审模型。此版验证目标为路由、文档可达性与便携工作流，不声明已完成真实影片或配音质量验收。独立声音 Skill 的打包与宿主自动注册尚未实现；现有 Motion portable 包携带工作流正文和人声指导，不携带本入口。私有媒体、声音身份、反馈和实际记录留在授权项目，不随 Skill 发布。
