# 路径字格：先准备文字，再定位基线

## 机制边界
排版系统先给出有身份的字格及advance，本资产把中心距离映射到同一canonical三次路径。它不测字体、不处理连字或双向文字，不能把Unicode码点直接切开后声称完整语言支持。重复字母仍需要不同glyphId。

## 间距和视觉墨迹
tracking只放在相邻字格之间；normalOffset沿左法线平移基线中心，不弯曲字形。advance跨度不是墨迹包围盒，斜体overhang、重音和上下伸部仍可能相撞。检查路径内fit后，还要看实际字体、邻字和裁切。

## 失败的意义
整行放不下或任何中心缺切线都拒绝，不缩字、不裁切、不借上一字方向。路线缩短时由作者明确改变起点或文字布局。闭环留白可以由调用方分配，但不新增自动环排模式或绕回能力。

## 与路径共用身份
依赖真正的cubic-path实现，不复制它的采样器；公共barrel与直接入口共享品牌。存储原始控制点并重编译，而不是保存JSON计划后直接复用。历史候选没有因文件迁移获得新的阅读、听审或艺术接受，见[README](README.md)。
