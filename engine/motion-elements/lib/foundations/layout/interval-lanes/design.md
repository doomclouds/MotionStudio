# 半开区间分轨：显示冲突，不替作者改时间

## 选择理由
保留全部固定区间，把时间重叠的项目分到不同水平轨。半开边界使前项结束与后项开始相等时可共轨，清楚区分“显示现有排期”与“选择最优项目子集”。

## 确定性不等于跨快照稳定
按start/end/ASCII ID排序，再选择编号最小的可用轨，消除输入重排对轨号的影响。更改时间后仍可能换轨；算法保证当前快照最少轨数，不优化搬移量。导演应给观众足够的身份线索，而不是假设同ID永远留在同一行。

## 图形尺度与语义
单位由调用者统一，接口不理解日历、时区或人力资源资格。窄区间投影小于最小绘制合同会拒绝，不放大成虚假时长。字幕、阴影和受保护区域不包含在geometryBounds里，需要检查实际画面。

## 交接边界
两个合法端点布局之间的插值可能互相遮挡，最少轨数证明不适用于动画中间帧。空布局也是有效快照，但不能据此改变现有handoff对空到空的限制。完整参数、历史使用及来源见[README](README.md)。
