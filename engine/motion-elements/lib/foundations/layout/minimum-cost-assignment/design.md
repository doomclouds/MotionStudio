# 最小成本指派：先定义成本，再解释最优

## 对应关系的职责
同数量源和目标之间求一对一匹配，columns[i]绑定第i源与目标列。业务身份、距离或颜色差成本由调用者明确定义；算法不理解“最自然”或“最重要”，错误成本会得到正确但无用的最优结果。

## 方阵与禁边
仅有限非负方阵，不允许遗漏、新增或用Infinity当禁边。需要不同基数或硬不可达关系时应另立合同，不能在这里假装支持。相同输入tie策略确定，不保证所有最优解中字典序最小。

## 匹配不是路径
匹配可为layout-handoff提供对应关系，但没有轨迹、避障或碰撞保证。最小总成本也不自动让每条连线短，更不保证它们不交叉。导演应检查身份可追踪和同时运动的拥挤。

## 数值验证
本地三项排列穷举独立检查总成本，原共享套件保留更大随机oracle及资源边界。示例只说明给定矩阵的结果，不声明生产或风格接受。合同和研究来源见[README](README.md)。
