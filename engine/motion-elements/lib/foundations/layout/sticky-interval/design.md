# 分区固定标题：保留当前位置线索，也让旧分区离场

## 选择理由
标题先随内容移动，到pinY后保留，所属容器末端再把它带走。它表达“正在读哪个分区”，而非永久悬浮标签。三个phase都由当前scrollOffset决定，倒序seek不依赖滚动历史。

## 坐标只换算一次
输入矩形与容器在内容坐标，输出已是视窗本地最终矩形。绘制时再减scrollOffset会造成双倍移动。外层窗口位置、clip和父矩阵仍由调用者设置，函数不判断标题是否还在屏幕内。

## 交棒不是碰撞求解
每个标题独立求解。前后标题是否重叠，取决于作者提供的分区、尺寸和层序，不应把独立sticky当成自动排版器。pin与release相等允许一个固定瞬间；负scrollOffset和负pinY也有定义，不随意归零改变语义。

## 数值与观看的边界
末端先做end-height再减scrollOffset，保留IEEE运算顺序，避免代数改写带来边界差异。几何release仍被计算不代表它在屏幕上可见。历史UI作品仅有限认可，不等于优秀风格背书；完整合同与证据见[README](README.md)。
