# 固定弦波：让反射来自边界，而不是关键帧

## 选择理由
固定两端与初始拨弦轮廓共同决定运动。用奇延拓求绝对时间状态，使跳时、倒放与分段渲染不依赖前一帧。它适合解释波的传播与反相反射，而非给任意曲线增加“弹性”装饰。

## 形状与时间的分工
profile定义归一化弦上的初始位移，speed定义传播速率；绘制比例、线宽、颜色由调用者决定。尖角轮廓有弱解而不是处处光滑的速度，均匀采样可能漏掉移动尖角。提高采样密度后仍需观察屏幕像素，不以数学边界通过代替视觉平滑。

## 导演取舍
两端必须是观众能理解的固定点。若要自然衰减，应选择有衰减的机制，而不是声称本模型有阻尼。若只想主体回弹，应考虑damped-response；本模型表达沿空间传播的轮廓，不是单自由度位置响应。它也不是音频合成或弦乐器物理。
