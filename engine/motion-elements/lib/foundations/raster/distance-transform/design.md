# 距离变换：先问距离指向哪个像素集合

## 平方距离场
二值mask的1像素中心是种子，每像素返回最近种子的平方欧氏距离。若要实际长度需显式开方；不要把平方值直接当线性亮度。无种子返回Infinity，渲染前必须处理空集，不能直接当alpha。

## 与轮廓的距离不同
输出在离散像素中心域内精确，不等于真实字形边界、亚像素轮廓或矢量距离。内外分别求值可组成有符号样本场，但连续边界与抗锯齿仍由调用者负责。

## 组合与性能
完整距离场可供轮廓光带或等值线，区别形态学的矩形邻域极值。两个方向抛物线下包络是同一机制，不拆计数。固定mask可缓存结果，输入变化才重新计算；没有播放时钟。
