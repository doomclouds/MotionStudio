## Runtime and module-instance contracts

**The whole private union barrel is Node-only** because arrival's unchanged timeline dependency imports `node:crypto` at module evaluation. Tree-shaking is not a portability proof. No browser execution or browser compatibility is claimed. The public baseline entry is unchanged. No helper extraction or dependency refactor was performed to conceal this boundary.

Use one canonical module path per mechanism: compiling through the private index and sampling through its reexported same module is valid; compiling through another byte-identical copy can correctly fail WeakSet/WeakMap branding. Serialized plans and equal JSON identities are not authenticated compiled plans. Persist raw specs and recompile. Event bindings/strict data guards/timeline remain arrival support dependencies, not extra exported candidate mechanisms.

Input and ownership contracts deliberately differ. Polyline, arrival and visibility support null-prototype records; most other inventories here require ordinary Object.prototype records. Ordinary dense arrays are not generic iterable acceptance. Hard-disc, grid, wave and temporal samples have fresh mutable outputs; other APIs freeze output graphs, while typed-byte ownership is its own contract. Do not impose a common deep-freeze or validator without a separately reviewed behavior migration. Number seconds, integer ticks/frames and rational string times remain distinct; no implicit conversion was added. JSON identity strings in grid/hard-disc/ray-chain are not cryptographic hashes.

## Resource and caller boundaries

Input maxima are not RSS or real-time guarantees. Temporal pixel×tap limits apply before callbacks but cannot bound provider execution or retained buffers. Budget exhaustion remains explicit failure, never a partial success or silent budget retry. Preserving a source hash is not an all-domain numerical proof.
