# design.authored-paths.v1 · 有声明的叙事路径

## 来源与取舍
`portfolio/works/theatre-narrative-wave/design/scene.mjs` 通过有序点与水平切线的三次贝塞尔表达叙事起伏；`portfolio/works/bus-morning-study` 的多路径比较提示需要明确路径类别及计数边界。本模块只抽“调用者提供点→可追溯路径→图例与示意声明”，不抽公交交通模型，不把茶话声原SVG假装为音频分析。

## API / 数据语义
`draw(ctx,{bounds,data,theme})`；只接受 `data.mode:'illustrative'`。1–16条路径，每条含稳定id、label、color、width(1–12)、2–1000个归一化点。x必须严格递增，表示作者给定的阅读顺序；y表示作者给定的构图高度，不是未经声明的统计轴。

`interpolation:'polyline'`直连顶点；`smooth`时输入点是必经的锚点，程序在相邻点横向中点生成两控制点，保持水平切线、无纵向超出端点范围。输入点不是贝塞尔控制点。曲线形状不增加数据，不代表插值科学合理性。

返回每条id/pointCount/绝对锚点与plotBounds，调用者可据此放后续注释或动作锚点（当前静态）。图例与caption必须提供；数字点数不等于车辆/乘客/波峰数量。不存在隐藏随机数或自动合成数据。

## 适用 / 禁用
适合故事节奏、工作流程示意、不同序列走向的视觉比较。不能用于任意地理折返路线、真实轨道、音频频谱、测量趋势、可信的统计推断；没有轴尺度与单位的线不能称为数据图。需要这些能力时保留专业案例实现或新增有数据契约的模块，不偷偷扩展本接口。

## 设计规则 / 验证
路径色在图例重复，保持与文字主色层级；路径密度必须适合尺寸。长图例会显式拒绝，不藏标签。示例一条平滑故事弧与两条折线服务序列，内容/主题/曲线类型不同；组合测试同时使用标题、斜切内容带与圆弧控件。测试严格x、范围、重复id、标签溢出、确定性/上下文恢复、明确拒绝quantitative。
