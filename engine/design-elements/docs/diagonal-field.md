# design.diagonal-field.v1 · 斜切色域

## 设计关系
来源 `portfolio/works/muqi-study/design/scene.mjs` 的斜切渐变：用方向变化连接主张与证明区域，而非给所有页面刷彩虹。提取斜率、边界高度、渐变站点及安全内容带，不复制原品牌配色。

## 契约
`draw(ctx,{bounds,data,theme})`；data.angle 为屏幕横向右行时边界向下的角度（-25..25°）；cutoff是边界在画布中央的高度比例（.3.. .75）；stops为明确的2–8个有序颜色站点，必须0开头1结尾；padding为内容净距。返回左右边界端点，以及upper/lower安全矩形。上区高度由斜边最低可容纳位置决定，下区起点由斜边最高位置决定，不能简单用cutoff切成两块。过大斜率或留白导致无内容带会绘前拒绝。

## 使用 / 不适用
适合发布、文化活动、工作室开场的主张/证据切换；背景色承担视觉语气，非统计面积。不要叠太多斜线、旋转卡片与挤出文字争抢焦点。安全区只防跨色边界，不保证任意文字对比；调用者仍要选字体、颜色并实看。非透视、3D或自然光照模型；不输出动态渐变。

## 组合与验证
暖色下降边界搭活动标题，冷紫上升边界搭器材说明；几何、角度、底色不同。同一模块的返回contentBounds被专题组合中的文字/证据真实消费。测试角度、站点排序、边界安全与无像素拒绝；两内容图不是新收藏作品。
