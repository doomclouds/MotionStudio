# design.ratio-rings.v1 · 精确目标比环

来源 `ocean-health-batch/health/verification/encoding-check.json`：原512/600对应.8533但源dash约.8183，26/30=.8667但源dash约.7724。新模块由同一value/max同时推导文字、百分比、弧角，绝不继承源手填dash。旧作品未静默修正。

1–4个ring[id,label,value,max,unit,color]，max>0，0≤value≤max；超目标不隐式截断而是拒绝，需调用者决定另表述。每环从正上方顺时针绘制，sweep=2π×value/max；lineCap=butt，不以圆帽偷偷增加可见弧长。0不画彩弧，1画完整环；Native对负起始整圆行为不同，100%使用明确0→2π整圆路径并以实际像素检查，不能只验证公式。

厚度8–28、间距8–32，同组厚度一致，最内圈必须留24px空心，图例与图形分栏、源声明置底。显示百分比四舍五入到1位（如58.3%），但弧仍按未舍入value/max。整数或小数原值/目标原样显示，长值溢出显式拒绝。

**不同半径/单位的环总面积不可比较**；可比较的只是各自完成比，不是活动量/健康水平。不是医疗评分、临床建议、真实运动追踪或相机交互。源与示例数字均须标合成。相较旧radial-scale：本族是无刻度同心目标比、精确整圆0/100端点；旧族是开放角旋钮量程/指针，两者语义不同。

例一读书进度（含0），例二工作坊准备（含100%）；组合一档案整理目标、组合二制作交付目标。同一实现，目标/单位/数量/颜色/厚度不同；各目标有内容对象，不把无关数值拼成视觉装饰。

稳定来源作品：`portfolio/works/health-color-code-study`。本地提取快照：`ocean-health-batch/health`。这里是设计关系提取；原作品scene未改为调用本模块，真实新调用见`examples/b05-compositions.mjs`。
