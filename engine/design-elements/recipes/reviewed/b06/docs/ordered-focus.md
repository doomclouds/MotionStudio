# recipe.ordered-focus.v1 · 有序选择与焦点内容

## 提取的关系
影展将当前选择与主视觉/行动并置；节气页面将24个有序色彩身份和当前推荐联动。值得复用的是“同一选中索引驱动顺序带、标题、详情卡”，不是复刻整页的坐标。节气作者已有drawSeasonalStrip，本配方原样调用、保留SHA，不再包装为第二个新族。

## 实现与输入
固定1200×750，恰好24项，每项沿用原helper的两字name、1–3字colorName和fill/ink，同时增加description/task。activeIndex控制全部当前内容。使用现有typographic-focus、material-surfaces，详情实际消费返回contentBounds。文字与颜色由调用者决定，宽高强调选中而非数量或时长。

两输入：二十四节气观察札记、二十四次创作学习练习。后者不是把原节气换标题：顺序项、任务文本、索引、色序、正文、背景都换，底层helper和组合流程不变。全部为合成说明，不声称真实开课/气象预测。案例字体子集不用于新内容；caller必须提供覆盖字体，检测缺字后显式修正文案字体契约，不容许方框被当作正常输出。

## 边界
不是时间轴数据、日期计算、任意N项导航、自动响应式或互动控件。24项限制来自当前source helper，保留它比假装通用更诚实。原影展没有调用这个组合；原节气确实调用底层helper，但没有调用本新组合。

## 验证
两内容图、修改activeIndex同步三处、输入状态不变、重复确定性；错误在离屏事务阶段拒绝，目标canvas不留下半张画面。对新字进行字体cmap覆盖检查、实看图片。技术通过不等于新的品牌设计获用户认可。
