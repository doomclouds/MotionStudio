# Separate rights

All candidate API implementations, procedural print/botanical pixel sources and new fictional copy are original for this study and MIT licensed (LICENSE). Generic own-data validation/font preparation techniques were adapted from our earlier MIT Native utilities, not from upstream application code. No official screenshot, upstream CSS/template/JS, user identity, reference photograph, generated bouquet, avatar, logo or icon is included in this source package.

The private design evaluation considered 8B architecture / print / florist templates (MIT template code) and Zulip promotional hierarchy (Apache-2.0 application). These are design-study lineage, not a claim that their image/trademark rights follow the code licenses; no upstream source code is incorporated into these new APIs. Case-specific comparisons remain in separate private studies and are not dependencies. No GSAP, Zulip app, network client or external service is run.

The optional example typography uses **Open Sans**, fixed Google Fonts commit `6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec`, `ofl/opensans/OpenSans[wdth,wght].ttf`. Exact upstream OFL is preserved in `licenses/OpenSans-OFL.txt`; source URL/SHA/Git blob in `examples/font-sources.json`. Three full-font wdth100/wght400,600,700 instances are renamed ComposeRegular, ComposeSemibold and ComposeBold including nameID25; original copyright/license name fields retained. Regular400 metadata exposes real selected outlines, not synthetic bold. No historical screenshot font identity is asserted. Binary fonts are outside the text projection; they are retained only in the private reproducibility bundle and can be independently regenerated from the public master.

`@napi-rs/canvas`0.1.100: MIT, exact notice in `licenses/Native-Canvas-MIT.txt`. fontTools4.61.1 is a separately installed preparation tool, not vendored. The core only consumes injected trusted fonts/Canvas and is not a rights verifier for caller inputs. No public release, formal family registration or upstream endorsement is implied.
