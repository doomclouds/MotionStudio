# Additive flow ledger — restricted source candidate

One cross-content method, not a new registered family: a finite ledger of paired nonnegative integer rates owns exact trapezoidal totals, independently complete category partitions, stable ranking and mirrored rate geometry. The same records drive every view. No network, capture, database, audio, timing loop or UI events.

```sh
node --test test.mjs
FLOW_TEST_ROOT=/absolute/existing/work python3 test-io.py
node render.mjs /absolute/absent-output
python3 make-package.py /absolute/absent-source.zip
```
Node22+ builtins only; Python3 stdlib for source packaging/CLI regressions. No npm install, external fonts, image downloads or network are needed. Four deterministic SVG/JSON outputs are external. SVG labels are small explicitly authored geometric matrices, not system typography, extracted font outlines or Unicode shaping. Native Canvas0.1.100 was used only in the private author review to rasterize previews and finite expanded samples; it is not a package dependency and PNG output is not the public method.

`compileLedger(input)` -> `curveTile` / `partitionTile` / `rankTile` -> `composeSVG`. Transparent tiles can be placed into other SVG documents using their complete issued plans. Two new examples: a two-facet media transfer study1140×940, and a one-way materials study760×1010. Both visibly identify synthetic data. They are not the original FLOWGROVE full application.

See CONTRACT.md for bounds and rejected inputs, DESIGN-GUIDE.md for meaningful use, DEDUP.md for comparison with existing methods, and CREDITS.md for separate rights. MIT new code/input helper and inherited MIT notices retained; the upstream alternative Apache notice is preserved without declaring both alternatives cumulatively mandatory. No private screenshot, source application icon, font, source telemetry or generated artwork is included.

Author checks do not substitute for the new independent review. 0 formal families, no automatic public registration or push. Whole repository/history/concurrency/publication gates are future integration work, not implied by this standalone package.
