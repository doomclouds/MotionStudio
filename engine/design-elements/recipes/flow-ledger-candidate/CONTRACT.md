# Bounded model and SVG contract

## Own-data domain
Ordinary Object.prototype/null-prototype exact own enumerable data records and ordinary dense canonical-index Array.prototype arrays only. Accessors, extras, symbols, sparse arrays, non-enumerable required fields, custom prototypes and unknown category keys reject. Own snapshots/append use defineProperty. Returned models/plans are deep frozen, privately issued; passing copies/forgeries rejects. Trusted intrinsics and single-writer inputs; not a Proxy, arbitrary modified builtin, concurrent mutation or hostile-code sandbox.

`compileLedger` requires exactly title, unit, startSecond, stepSeconds, dimensions, flows. Title1–40 and unit1–12 trimmed printableASCII are metadata. startSecond integer0–1,000,000; even stepSeconds2–60. Dimensions1–3 unique lowercase IDs (letter first, then lowercase/digit/underscore/hyphen,1–20), each label1–24 and categories1–12 unique IDs/labels. Unused categories stay visible with zero totals. Flows1–64 each specify categories in exact dimension order and forward/reverse arrays, all sharing2–241 knots. Rates integer0–1,000,000 in the declared unit/second, no negative, NaN, Infinity or implicit coercion. Entire ledger total must be positive; one direction can be identically zero.

Each direction integral is sum((r[i]+r[i+1])*stepSeconds/2). Even steps make every product and total an exact safe JS integer. Maximum aggregate total1,843,200,000,000. Categories are disjoint within each dimension: every flow belongs to exactly one category per dimension; **each dimension sums to the same total, different dimensions must not be added together**. Model source mutation cannot change issued results. There are no real-device identifiers, packet-count/drop semantics or clock/timezone claims.

`atTime(model,second)` accepts a finite closed-domain second, including final endpoint; returns bracket/fraction and piecewise-linear paired rates. Fractional interpolation is IEEE754, not an exact rational guarantee. Cursor never filters whole-session totals, rankings or the partition bar. Forward/reverse are nonnegative magnitudes; reverse is drawn below the baseline solely to separate directions, not as negative traffic or signed net flow.

`rankedFacet(model,key,order)` has explicit authored or total-desc order; ties use original category index. No top-N omission. Rank bars normalize to that facet's maximum; bars in different facet panels **cannot be compared by raw pixel width**. Both color segments use the same maximum. `decimalRatio` uses BigInt half-up rounding to0–3 decimals. Independently rounded display percentages need not sum100; actual geometry uses unrounded ratios. No decimal-exact general dimension arithmetic is claimed.

## Transparent font-free tiles
All options exact own records, palette exactly opaque #RRGGBB ink/muted/grid/forward/reverse. No default green/brand palette. `curveTile`: width480–1600,height260–700,second,palette. Shared +/-max domain; straight segments, no smoothing/overshoot; axes and cursor from model. `partitionTile`: width400–1200,height200–400,palette. Whole integral, directional bar and duration. `rankTile`: width400–1200,height200–1100,dimension,order,palette. Full category list, row height62; requires67+62*rows height. Every required label/value is measured by exact5×7 geometry; no wrapping, ellipsis, scaling-to-fit or hidden rows. Unsupported glyphs or fit reject even if numeric model is otherwise valid. Geometric label alphabet uppercaseA–Z/digits/space and .:-/%+ only; no font, kerning, Unicode or shaping. Font-free does not mean typographically general.

`inspectTile` returns the issued frozen plan, `tileSVG` a standalone transparent SVG. `composeSVG` takes width480–2400,height320–2400, budget≤4million logicalpixels, background #RRGGBB,1–12 issued tiles with integer x/y, and requires whole tile enclosure. Explicit overlap is allowed; this is composition, not a collision solver. Paint strings contain own geometry only, no image/script/style/foreignObject/external URI. Title metadata is XML-escaped. Embedded SVG rendering inherits the enclosing SVG/browser semantics; no Canvas host-state/PNG-decoder interchangeability claim is made.

## Files and verification boundary
Both CLIs require a normalized absolute absent destination outside package root, existing nonsymlink parent/ancestors; final live/dangling symlinks reject. Packaging preflights every fixed listed regular nonsymlink UTF-8 member before opening output; all unknown files ignored, including private junk in lib/licenses. Render computes both compositions before first output write. Trusted single-writer filesystem; no TOCTOU, hardlink, rollback-after-OS-failure or semantic private-content scanner guarantee.

SVG bytes/model outputs are deterministic for the pinned Node input. Native previews and expanded raster comparisons are finite observations, not universal AA/error bounds, arbitrary translation invariance or browser verification. No browser, live application, accessibility certification, production statistics, user aesthetic acceptance or public publication is implied.
