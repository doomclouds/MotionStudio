# Source and resource boundaries

New graph code and synthetic composition data are original work under the repository MIT license. General design study motivated the need for legible node relationships; no third-party source implementation, branded poster geometry, image, font outline, icon or logo is included.

The runtime is caller-supplied. Native Canvas is an external dependency, not redistributed here. Fonts remain external and their licenses remain the caller's responsibility. Test output records actual supplied font bytes for identity only; a hash is not a license. Source-only retention does not grant rights to redistribute a studied reference, surrounding private study or generated evidence.
