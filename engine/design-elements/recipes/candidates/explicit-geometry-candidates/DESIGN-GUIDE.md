# Compose grammar, not a borrowed page

## 1. Choose content before geometry
Use a run matrix when a short authored symbol or headline gains a distinctive pulse from **continuous horizontal segments**. Every array is explicit: reader recognition remains the author's job. Do not convert body copy or accessibility-critical labels into this grammar. Pair with readable conventional type supplied by the host. The core does not know letters or infer meaning.

Use a nested square when an **ordered border-to-core relation** is the point: specimen cards, edition systems, material studies or modular separators. Specify the layer sequence and inset steps rather than a source-brand preset. More layers are not automatically richer; keep enough screen pixels for each relevant band. Similar consecutive colors intentionally merge perceptually even though their geometric count persists.

## 2. Keep distinct visual roles
A run matrix is a mark, not a heatmap or an indexed raster. Continuous strokes intentionally bridge occupied cells within a run. A square stack is flat opaque 2D overpainting, not a physical tile render or texture. The ideal area formula describes the stack, not crop yield, production cost or a measured statistic. Never relabel arbitrary decorative color changes as real data.

## 3. Establish hierarchy with size and space
Plan geometry first; select a short matrix that fits the supported width. Choose cell/thickness/rowGap together: wider pitch creates an airy rhythm; thinner capsules need larger display size. Core padding is local raster breathing room, not an automatic host-layout margin. Give separate components clear space; examples reject intersecting component AABBs and remain intentionally finite fixed compositions.

For squares, choose contrast across adjacent layers. Insets are **basis points relative to size**, not pixel border widths. Repeated instances may change color order, size, spacing and role without changing the method. The caller can repeat/place independent tiles in any authored layout; no hidden field/seed imposes a page template.

## 4. Two different combinations
- **Form Lab**: landscape exhibition communication. Large mark establishes recognition; the smaller mark changes weight/color. Three explicit square sequences repeat into nine specimens. Caption counts derive from the two matrix models.
- **Tile Atelier**: portrait field guide. Eight large square specimens become the dominant reading route, while two smaller run marks label the page. Four outer-band percentages derive from those exact square models. It is not Form Lab with colors swapped: layout, proportions, hierarchy, model content and specimen counts differ.

Both combine both methods and host typography; neither uses the earlier studies' page structures, source brands, seed or complete alphabet. Examples are synthetic and do not announce real events, services or availability. Material/brand type and photography from other cases were evaluated but not extracted as duplicate generic helpers.

## 5. Review at the intended size
Look at full compositions, then transparent components and smaller display sizes. Verify mark recognition, supporting contrast, explicit intercomponent spacing and whether narrow layers survived rasterization. Reject or change content/geometry rather than silently shrinking, cropping, assigning meaning or claiming all legal models are legible. Test boundary rejection and host state separately from aesthetic judgment. Static validation is not animation or browser testing.
