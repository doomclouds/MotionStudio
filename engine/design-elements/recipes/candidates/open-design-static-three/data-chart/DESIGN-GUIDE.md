# Design retention · one full static frame

## What was learned and preserved

1. **Editorial hierarchy by scale rather than decoration.** A small red uppercase kicker leads into a very large serif claim. The entire lower half is reserved for evidence-shaped geometry, with light labels and a nearly invisible grid. Keep the headline and chart as distinct reading levels.
2. **A single restrained accent.** Dark line and ordinary points establish continuity; red is limited to the titled change, last three points, dashed segment, callout and selected annotations. A changed theme is permitted only with the same semantic roles.
3. **The line break is part of the source.** The isolated double em-dash line is visible in the official PNG; it is not a missing row or a browser bug we should silently repair in a faithful study. Four authored lines make the choice explicit.
4. **Whitespace is structure.** Content width is 1280 inside a 1920 frame. The gap between the large title and first horizontal grid lets each region breathe. Do not crop the source to “improve” density or count its chart nodes as separate works.
5. **Illustrative source data needs a separate truthful contract.** Preserving coordinates is visually faithful but not numerically faithful. Hence explicit `reference-geometry` vs `linear-values`, both synthetic-only, with an acknowledged mismatch required for the former.

## What is not generalized

The exact mixed Chinese/Latin headline, four line count, 1920×1080 canvas, 1280px text column, wide chart, footer arrangement and Native font-baseline calibration remain bounded to this recipe. This is not a general automatic chart-writing or newsroom editorial engine. There is no public family registration and no automatic migration of other source scenes.
