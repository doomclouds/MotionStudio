# Use a ledger, not three unrelated charts

1. Start with actual declared units and one additive record ledger. Synthetic examples must visibly say so. Do not create attractive independent totals and retrofit a line to match them.
2. Connect rates to volume by the declared piecewise-linear trapezoid rule. A curve height is rate; the integrated label is amount. Never label sampled heights as cumulative totals or infer totals from raster-colored pixels.
3. Use mirrored directions when positive flows need visual separation. The lower curve is still a nonnegative amount. Explain direction colors consistently in the partition and ranking views.
4. A facet is a complete alternative partition, not extra traffic. Stage totals and format totals both equal the ledger; do not sum those panels. Choose authored order for a process/story order, total-desc for a leaderboard, and retain stable ties/zero categories.
5. A category bar is normalized within its panel. Keep exact value labels; do not compare row lengths across independently normalized facets. To compare across panels numerically, compare the printed numbers or intentionally design a common-scale extension, outside this contract.
6. Cursor emphasis answers “what is the rate at this time?” Whole-window labels answer “how much over the entire interval?” A cursor is not a hidden filter. Put those scopes into copy where a viewer may confuse them.
7. Compose different reading orders: the wide media study leads with shape over time then total and facets; the narrow materials study leads with amount, category responsibility, then the time evidence. This is not responsive CSS or a skin-only color swap.
8. The block alphabet is a deterministic diagnostic aid, not the recommendation for all brand typography. Replace it only through an explicitly tested text renderer, not by adding unpinned system text and claiming exact reproduction.

Good uses: synthetic throughput explanation, logistics/resource transfer, production-stage load demonstrations. Bad uses: packet capture, inferred telemetry, probability distributions, negative financial balances, unrelated KPI cards, real-time network/security claims, or a ranking where hidden categories could change the total. Prefer existing shared-trace for arbitrary interpolated samples without additive facet semantics; prefer existing semantic-data/ratio-rings for a simple ratio.
