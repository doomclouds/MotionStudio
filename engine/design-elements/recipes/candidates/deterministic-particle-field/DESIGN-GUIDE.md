# Compose the field, do not turn it into a dashboard

**Keep:** one deterministic transparent texture with a known annular geometry and density profile. The useful transferable idea is separating geometry, rasterization and placement so a host can supply any content, background and layer order. The pure plan also permits a host to inspect actual point positions without painting.

**Do not keep:** the original product heading, diagnostic counters, green-black brand-like visual treatment, viewport composition, Worker implementation or benchmark story. None is required for reusable atmosphere. There is no whole-source-scene adapter in this projection.

## Hierarchy

Use a lower opacity and small point size behind dense reading surfaces. In the wide schedule fixture, an opaque card protects the grid; field occlusion is an explicit layer decision. In the tall route fixture, thick route strokes and solid node discs remain stronger than the points. An annular aperture can create room around a focal object, but it is not a label-placement engine. Add caller-owned labels through a separately licensed, measured typography system if needed.

## Change content and aspect ratio, not just color

The wide board has five independent lanes and discrete occupied cells. The portrait diagram has three independent polylines, turns, endpoints and a legend scaffold. They use different radius/aperture, count, seed, color and exposure. Both call the same field tile directly. The plain bars are nonsemantic placeholders intentionally avoiding external font dependencies; no disguised real dates, personal names or numeric claims are embedded.

Choose the logical field dimensions independently from the destination. Place at a logical x/y and use the caller's composition order, clipping or transform when appropriate. The asset's private guard prevents self-clipping during rasterization, not arbitrary host overflow. A host can layer several tiles, but should budget memory and avoid treating 20,000 as a desired count.

## Density is not data

Uniform-radius sampling produces more points per unit area toward the center. The angular grid is evenly stepped; the radius is seeded. This is not a uniform-area distribution, star catalog, physical particle state or numerical scatterplot. Never label dots as observations or infer a metric from their density. Seed is a reproducibility control, not an animation frame or cryptographic secret. Use an explicit time-based design asset if motion is required later.

## Integration decision

Keep this as a **restricted recipe-local candidate**, with zero new catalog families and no formal recipe registration. It complements geometric marks/material surfaces by supplying a high-count sampled texture; it does not replace those families. Broadening the sampling model, adding interactive controls or adopting a public family API requires a new contract, review and evidence from additional briefs. This extraction's two fixtures do not automatically meet that promotion gate.
