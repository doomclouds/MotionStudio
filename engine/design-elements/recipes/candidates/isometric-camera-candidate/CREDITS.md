# Source and rights

The fixed 30° projection and horizontal-plane inverse are adapted from LemoLab's `Iso.P` and `Iso.unP`; logarithmic zoom is adapted from `mixK`. The candidate adds bounded strict input validation, immutable copied camera snapshots, exact endpoint handling, a small module API and original synthetic tests/documentation. It does not copy the upstream renderer or scene.
