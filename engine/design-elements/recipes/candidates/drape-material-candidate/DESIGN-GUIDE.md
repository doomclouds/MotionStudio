# Designing with a bounded drape material

## The recipe's role

Use repeated slanted light bands to give an otherwise flat title/section frame depth. Keep the material as one authored layer: it should support the message rather than pretend to be photography, a garment or a physical sample. It is a restricted variation under material-surfaces/scalar-field design, not a fifteenth formal family.

The distinct method is anisotropic seeded folds sampled into2px-wide vertical gradients plus a radial darkening field. It is not a new general shader engine. The formula's upstream MIT attribution must travel with extraction.

## Two deliberate compositions

**Material Study —1080×1440**: one large warm copper field, an oversized block-letter title, spacious paper margins, and a compact below-field evidence line. Seed503 and model-derived base frequency are annotations, not measured science. Two endpoint chips sit outside the shaded field so the user can distinguish input colors from vignetted output. This is a portrait editorial treatment, not the source storefront or its private replica.

**Drape Atlas —1600×1000**: six smaller fields in a3×2 index. Seeds137/811/43/2029/659/887, different warm/cool/moss palettes and vignette values produce visibly different configurations. Titles under each panel derive from its own model. Shared sizes isolate the material differences; equal rectangles do not encode quantitative magnitude. The landscape rhythm is intentionally distinct from the hero example.

Both examples use original elementary5×7 letter geometry so the full candidate is font/image-free. It is a restrained material lab aesthetic, not an assertion that pixel letters are the only appropriate typography. In a future work, compose the layer beneath an independently licensed, measured text system rather than extending this example helper into a font family.

## Palette and hierarchy decisions

- Choose shadow/highlight endpoints that keep adequate separation; equal colors with vignette0 are deliberately allowed and produce a flat fill, useful as a test, not a production default.
- Use low vignette for a comparative atlas; stronger vignette can focus a single hero. It is a luminance effect, not physically based illumination.
- Copper/paper evokes a warm editorial material study; cool blue/lilac and restrained moss/teal distinguish atlas variants. **Green is permitted when it has a reason**; no hue ban is encoded. Do not make every new example a default-green dashboard.
- Keep important copy off the busiest ridges. Readability belongs to the host composition; a successful material render is not a text-contrast guarantee.
- Large physical scaling does not increase horizontal sampling: ratio2 still uses2 logical pixels per column. Avoid claiming arbitrary smoothness/resolution independence.

## Content transfer / motion gate

Compile once, then use the same frozen model for a material and its external annotations. Keep coordinates, legend labels and value semantics explicit. `sampleDrape` describes analytic stops, not PNG pixel sampling; never show its value as a verified final-vignette pixel.

For video later, this layer can be placed by an external compositor. That is only a proposed use. The current recipe has no time/phase API, loop semantics, keyframes, GPU stage or cross-frame proof. Seed changes are discontinuous pattern changes. Before adding motion, specify deterministic random-access time behavior, stability of text and sample annotations, timing/loop endpoints, surface lifetime and frame budget. Test those independently; do not borrow this static candidate's PASS.

## What not to extract

No historical screenshot, private comparison/report/audit, source identity/brand layout, fonts, generated photographic assets, original website event handlers or application runtime. Do not register the material helper, label helper, IO helper and two examples as separate public families. This is one bounded material recipe; examples are verification scenes, not two owner-approved portfolio works.
