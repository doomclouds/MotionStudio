# Why retain this bounded candidate

The useful method is the relationship between a spanning editorial anchor, two stacked peers and a three-column supporting row, plus **content budgets that are actually consumed by the painter**. The same outer edge and aligned bottoms make the hierarchy legible without implying data proportions. Reserved excerpt/stat regions reduce accidental collision with expanding explanatory copy. The API rejects incompatible text rather than using smaller type as an escape.

This is independently authored neutral code, not a source-page skin. The examples use a fictional archive and workshop. The source hero, company names, product claims, nested soft material treatment, dark contrast card, navigation, logos and closing banner are absent. Flat warm panels and a light blue excerpt make the retained layout relationship visible without reproducing the reference page's visual identity.
