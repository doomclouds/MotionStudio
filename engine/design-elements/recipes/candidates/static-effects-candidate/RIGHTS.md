# Rights and attribution boundary

Code adapted from nexu-io/OpenDesign's `frame-glitch-title` and `frame-liquid-bg-hero`, fixed commit `12d970eacc8971150e3c76470d2a9afe16dc2ed1`, is retained under **Apache-2.0**, not silently relicensed under the repository's MIT license. The package LICENSE and `licenses/OpenDesign-APACHE-2.txt` contain the full notice. Modification: native fixed-frame text/geometry, explicit component contracts, validation and external resource adapters; source motion was not recreated.

Both template manifests identify nexu-io as author and Apache-2.0. Neither source HTML requires stock photography, outside imagery or a proprietary character asset. Original PNG/HTML, private comparison material, font binaries and unapproved covers are excluded from this candidate. Source availability is not blanket media/trademark/publication clearance.

Font instances remain **OFL-1.1**. Font copyright and license metadata remain inside external derivatives; corresponding complete notices are retained here. Derivatives use new internal names. Space Grotesk and JetBrains Mono come from the fixed OpenDesign WOFF2 files; Inter Tight likewise. Noto Sans SC / Noto Serif SC source identities are pinned to google/fonts commit `6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec`; the source Git blobs match full existing input bytes. The Noto Sans reserved name“Source” is not used as a derivative family name.

`font-inputs.json` records official URLs, size, SHA-256, Git blob and notice. `font-lock.json` records exact derived font bytes, real weights and cmaps. Five inputs produce eight external font instances. The complete official-project OFL texts are content-pinned; no claim is made that each notice was fetched at the exact historical font release.

Glitch real maximum display weight700 and Liquid's unknown Chinese fallback are explicit limits. The native Noto650/600 substitutes and geometric italic/punctuation adjustments are not font-forensic identifications.
