# One clock, two independent decisions

Use this recipe when explaining **what is being edited** versus **what is visible now**. Do not use it merely to imitate a subtitle application.

1. Create the model first. State cards, timing labels, list and interval positions must come from it; never type a second copy of the time values into the product view.
2. Give selection a quiet filled row/underline; give current time an edge/vertical marker and active interval fill. Include plain labels (“Selected”, “Active”, “none”), not color alone. The same hue does not mean these states are equal.
3. Put full authored sentences in the list and caption. A compact interval band may explicitly show an ID or no label; retain the full text in the model and place a readable full-text view nearby.
4. A gap is meaningful. Keep selection while rendering an empty transparent caption. Do not carry the previous caption forward or substitute the selected cue.
5. Use generous bands rather than dense editor chrome: 3–8 visible cue rows and 4–8 labeled ticks usually communicate better than the maximum accepted bounds. Split long content deliberately, not with automatic ellipsis.
6. Caption is a layer, not a video card. Compose it over caller-owned footage, illustration, solid color or geometry, with an explicit contrast check. The package includes no footage and does not process caller media.

## Two compositions

- **Timing notes** (1280×840): four short lecture cues, 18 seconds, selection #11 / active #12. Warm paper, navy geometry and copper timing marks. A list, standalone caption and full-range band form a reading hierarchy.
- **Workshop** (1440×960): four different longer cues, 42 seconds, selection #204 / active #203. Dark slate and warm orange; partial 4–36 second view preserves clipped endpoints. A second clock at28.500 seconds produces an intentionally empty caption while selection stays #204.

All prose and geometry are synthetic examples. Neither composition is a real transcript, player UI or source screenshot reconstruction. Colors are explicit paper/ink themes rather than an automatic brand system. These are two recipes for composition, not two new component families.

## What was deliberately not promoted

No application window chrome, menus, waveform, film image, audio amplitude simulation, subtitles imported from a file, SRT export, frame/timebase conversion, keyframe animation, auto-scroll, keyboard controls or shaping engine. Reuse existing motion/layout/typography primitives for those independent concerns. Avoid making one generic “media editor” abstraction from this narrow model.
