This local implementation transcribes text/layout/rotations into native Canvas; no source screenshot is pasted into rendered output. Source preview and HTML remain local research/comparison files. Their presence here is not an automatic authorization to upload this entire folder publicly. Public packaging requires a separate explicit scope review.
