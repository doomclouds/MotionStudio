# 可迁移设计指导：Creative Voltage

## 适用目标

适合品牌/创意活动的开场、章节标题、强观点封面：一句话要先抓住注意力，
然后让手写批注补上人的温度。它不是信息密集报告、长文阅读页或数据可视化。
这是一张完整构图，不把左右面板或三个单词当作独立作品计数。

## 这张画面为什么成立

1. **对比不是装饰，是分工。** 左侧高能蓝负责情绪，右侧低亮暗面承载大字。
   47/53 的轻微不对称避免机械对半，同时给超宽 Syne 留出 760px 字盒。
2. **三个字体有三个角色。** Syne 是主张；Caveat 是手写批注；Space Mono 是
   系统化的边角标签。别把三种都当标题，也别增加第四种字体。
3. **只强调一个词。** 第二行用蓝填色加浅蓝描边，将蓝面板的色彩带到暗面板。
   保留填色：改成空心会降低重量，也不再忠于参考。`any` 字形自带的重叠边缘
   是此字体与描边叠加的结果，不是要“修复”的错误线条。
4. **严格对齐让夸张可控。** 三行右边缘共享同一锚点；底部脚注也认这条线。
   左上标签和手写字从 90px 左边距出发。松动的是手写旋转，不是所有元素。
5. **空白承担节奏。** 大标题只占画面中段。上方、下方的暗面空白不是缺内容；
   不要为了“用满画布”塞满说明、图标、CTA 或更多文字。

## 可调 / 应固定

**可调：** 三行短句、手写补充语、角落标签；经过对比度检查的单一强调色。

**本复刻应固定：** 1920×1080、47/53 分屏、90/110px 锚点、三个标题行、一个强调词、
三种字体角色、手写 -7°、下划线独立于手写旋转。可组合 API 允许整体缩放放入宿主，
不等于获得手机响应式版式。换比例应重新构图，不强行拉伸。

## 可执行改稿规则

- 先改文案，再跑 `npm test` 和 `npm run render`；不要靠缩字号偷偷容纳长句。
- 单行标题 advance 超过 760px，优先缩短或重新分词；保持三行结构。
- 手写语是补充而不是第四行主标题。它应更短、更口语，不重复全部主张。
- 元信息维持小字和足够留白；若变重要，说明模板已不适合这个任务。
- 字体排版必须使用整段 shaping，尤其 Caveat。逐字绘制会破坏上下文替换，
  即使字体文件和字号正确，手写形态仍然会错。
- 没有照片就不添加照片；本源设计确实是可编辑字体、色块、渐变和一条原生曲线。

## 静态与动态边界

这里沉淀的是静态空间关系和代码积木。不能从这张结尾帧推出入场时序、缓动、
手写自描逻辑或成片时长。若以后做动效，应另列时间契约、运动减弱策略及逐帧验证；
不要把静态通过写成“动画也通过”。当前未制作网页，未运行浏览器 QA，未推送。
