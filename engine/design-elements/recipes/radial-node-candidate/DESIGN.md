# Use direction as category, count as evidence

## When useful
A chapter map, editorial taxonomy, workflow options or a small set of creative routes. Its increment over simple circular buttons is **complete text ink / neighboring and central separation checks + count markers + selected-node/summary consistency**. It is one bounded composition, not two new families for diagram and summary.

The reference method is directional capsules, angle-derived pastel HSL and overlapping circular lobes from a CC0 theme. The implementation is a Native static recipe adapted from a prior MIT study, with a neutral count hub replacing the study emblem. It is not a port of menu interaction or a newly invented radial graph algorithm.

## Composition rules
- Keep3–6 named categories when labels matter.9 is a validation cap, not a recommendation; conservative AABBs can refuse layouts that might be manually arranged.
- A circle does not imply a clockwise process. Add sequence arrows only if a separate validated semantic model supplies order; this recipe deliberately does not.
- Marks are countable drawing operations but overlapping lobes are not a reliable precision chart. The summary prints exact integers. Do not present hue or angular spacing as numerical magnitude.
- Use enough radius for capsule/icon separation. A failed fit is an editing signal: shorten the label or intentionally increase supported geometry, not silently shrink/crop the type.
- Keep the diagram and summary in one tone and hue offset for a shared legend. Green is legitimate when its categorical hue belongs in the palette; no blanket exclusion.
- Selected increases outline weight and node lightness; summary prints selected explicitly. This is a fixed highlight, not focus/hover state or an accessible interactive control.

Existing/unpublished PULSE timing and glyph evidence solve different numeric/typographic problems. No registry/family addition is requested. A latest combined-tree/source-history check is still needed before any future integration.

## Motion gate (not implemented)
Require stable node IDs and explicit temporal semantics before animating selection/geometry. Test label trajectories, crossing occlusion, integer mark transitions, random-access frame reproducibility and endpoints. Changing snapshots or seed-like input is not proof of animation, interpolation safety or real-time performance. Preserve readable evidence while moving; do not inherit static PASS as motion PASS.
