# Design retention and content migration

## What is worth keeping

A small marker gives each item a stable left edge; title and supporting copy form
a two-level information unit. The 60px text offset separates the icon's shape from
reading text. Measured row height makes the list composable without assuming every
description has identical length. In two columns, peers share their row height.

The component is deliberately smaller than a poster template: no headline,
marketing proposition, logo, command, matrix/QR, footer, photo, background or
frame is owned by it. The host can put the same transparent component into an
editorial page, a workshop board or another authorized composition.

## Two genuine input/layout changes

- **Field notes:** three synthetic observations, one column, width 540, gap 30;
  pale paper host, dark blue text and green line marks. The host adds a two-line
  title, rule and small disclaimer. 720x1060 is a complete host composition.
- **Workshop:** six different synthetic prompts, two columns, width 1120, gap 56;
  dark green host, light text and lime marks. 1440x930 is a different complete
  host composition. Both functions consume the same list layout/draw exports.

No screenshot is sampled. These examples are code-rendered from the declared
fonts and four original geometric marks. Source emoji styling is intentionally
not reproduced; generated bitmaps and additional font/emoji licensing are avoided.
Word-boundary wrapping is a deliberate departure from the source study's character
wrapping, because this narrowed ASCII interface should not split ordinary words.

## When not to use it

This is not a responsive webpage, rich text, arbitrary international typography,
icon pack, marketing-copy validator or workflow application. If a string fails,
edit it, widen the bounded layout or propose a separately reviewed interface; do
not silently shrink it. Check the full host at delivery size, not only a tile crop.

## Deduplication

Conceptually overlaps existing typographic-focus, semantic-data and parameter-
controls primitives: marker + label + supporting detail is not a new visual
family. This module currently has no imports from those APIs and makes no claim
of integration into their registry. Keep it a case-local recipe candidate until
separate reuse evidence and registration review justify a different decision.
