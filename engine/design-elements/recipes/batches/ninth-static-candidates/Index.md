## Increment, not another generic family

Cue intervals share horizontal layout with PULSE but add millisecond text and editing/current-state separation, not digital/bus signal levels. Authored byte edits differ from scalar byte-field diagnostics and character-grid snapshots: they explicitly map given base edits to target coordinates and removed/inserted/retained provenance. They do **not** search for differences or compute a minimal edit script.

## Boundaries and restore

Both are static Native Canvas0.1.100 recipes. No player, parser, audio, automatic transcription, live file reading, browser UI, animation or new registry import. Font/runtime/output directories must stay external to the repository; see each README for its distinct environment variables and exact pinned sources. Complete applicable notices must travel with the source. The root MIT license does not replace BSD/OFL/dependency terms.

ASCII and actual-ink fit restrictions are explicit; structurally valid content can be rejected rather than clipped. Cue bands may explicitly reduce labels to ID/none; caption is transparent during gaps. Byte views show a finite16-byte-row viewport and authored edit provenance, not a complete file explorer. Placement inherits caller visual effects while preserving state/path. Finite Native raster checks do not establish arbitrary platform/transform/encoder equivalence. Technical and independent checks are not individual user aesthetic acceptance.

Full current-index/history policy, combined regression/cold application, and authorized publication are separate integration gates. No private review identifiers are published here.
