## Selection, not automatic promotion

Flow's value is the exact additive ledger and truthful repeated partition/rank relationships, not a new generic line chart: complete facets each sum to the same total and **must not be added across facets**. Its cursor does not filter totals. Per-facet rank bars use local maxima; raw widths across facets are not directly comparable. Zero-rate categories remain explicit; no real network capture or measured telemetry is imported. [Deduplication](../../candidates/flow-ledger-candidate/DEDUP.md) states the fixed comparison scope.

Geometry has no built-in alphabet, automatic wordmark, random seed, pixel-art cell renderer or preset six-motif family. One maximal run is one capsule. Square band areas are ideal integer geometry, not raster coverage/material quantities; tiny or same-color bands can merge visually. See [comparison](../../candidates/explicit-geometry-candidates/NON-DUPLICATION.md). Host composition/labels/color meaning/accessibility remain caller responsibilities.
