## The narrow increment

Changing primary copy changes the available annotation width instead of leaving an independent fixed secondary column. The pure layout accepts a trusted metric callback; the actual kit uses exact locked aliases and checks every authored note line against the derived interval before output allocation. This can be used for static editorial bands, credits or programme cards in motion content; no animation, temporal interpolation or all-frame fitting is supplied.

Existing [expressive-type](../../../expressive-type.mjs) already measures and aligns actual ink. [Typographic-focus](../../../typographic-focus.mjs) supplies title/body hierarchy; [FeatureStack](../../candidates/feature-stack-candidate/CONTRACT.md) uses fixed columns and [RichParagraph](../../candidates/rich-paragraph-candidate/CONTRACT.md) wraps styled runs. Those capabilities are not recounted. Generic composition can implement this relation; the increment is a bounded paired residual-bay contract, not invented ink metrics or universal typography.

## Restricted contract

One to eight ASCII authored rows, each primary left/right with one to four annotation lines. There is no wrapping, shrinking, fallback, BiDi, semantic collision search or arbitrary responsive layout. Actual ink, minimum bay, line spacing, height and pixel budget can reject structurally valid data. A plan belongs to its kit. Scratch-only `drawFresh` normalizes state; only `place` preserves host state/path while inheriting host transform/clip/alpha/shadow/composite. Canvas pixels remain mutable; measurement callbacks, ordinary intrinsics, backend, font registry and single-writer filesystem are trusted, not a hostile Proxy/dependency/TOCTOU sandbox.

Author and independent raster observations are finite samples, not universal translation/platform/error bounds or exact pixel inter-ink gaps. Static PNGs are not accessibility/browser/text-selection or production guarantees. The two fictional examples are new content, not user aesthetic acceptance or original-source migration.
