# B09 五例沉淀选择

|作品|可复用设计规律|本轮决定与关系|
|---|---|---|
|xie-symbol-study|单符号、强分区、信息角色保持单一|已有color-sections真实调用保留；巨字＋色样＋三线是本案组织，三条线不是比例图。不新增“极简品牌族”。|
|command-palette-study|行内容、角色图标、快捷键可读分组|原command-row已真实桌面6行/手机6行复用，继续保留本例配方；与material-surfaces壳区分。它依赖本案helper/字体，非任意快捷键执行器；本轮不再复制为新族。|
|market-livingroom-study|语义强调词而非整段倾斜|提emphasis-tile，补旋转最终bbox/字形高度；两真实语义组合验证。原scene未迁移。|
|bookcraft-vinyl-annual-study|巨数节奏与多个不同计量指标并置|保留narrative-metrics语义审计；年度收进/子集/卖出/试听/人数/价格/未来容量不能相加。没有期初/退货不能算期末库存；不抽“年度数值总量”配方。|
|vinyl-isotype-study|同尺寸单位图符的数量重复与左半枚|提unit-pictogram：明确unit、精确整数底层单位与半枚、保留零类；同尺寸不是面积映射。不同内容＋不同有限形状验证。|

本轮2个配方候选，**0新增通用家族，现族仍14**。用户认可五原作，不等于认可新组合或新增跨内容能力；源关系、真实调用、新组合调用分开记录。原scene一律不改。本包仅静态参数化表达，不含响应式/交互/Motion证明。
