# Compose indices, not a copied editor

## What survives the study
Keep one finite index matrix, a palette, explicit transparent index and a reproducible enlargement rule. Remove the editor shell, brand, tool panel, original landscape, generated landscape derivative, fonts and unrelated icons. The useful new contract is categorical raster color and alpha, not the numeric values/null-range semantics of value-grid. It may complement material surfaces but is not a new synonym family.

## Hierarchy and scale
Design the small matrix first. Large nearest-cell scaling makes each cell visible; use that intentionally as a craft/grid vocabulary. At noninteger scales, cell widths differ by one pixel but have no seams. Do not apply a smooth resize and then call it an exact indexed palette: interpolation can invent colors. A host may choose such treatment, but that is outside the layer contract.

The wide **signal-quilt** composition uses a large 16×12 radial motif as the focal element, two smaller HSV studies to its right, and a real palette strip below. Transparent corner cells expose two different host backgrounds. Its warm paper and dusk/terracotta values establish an intentionally quiet sampler, not a brand claim.

The portrait **weave-folio** uses a different 24×16 diagonal interlace array at 768×512, with two secondary proofs below. One proof uses a 368×245 noninteger enlargement, testing real cell-boundary behavior; the other enables the transparency checker. Slate/rose/sand against a dark surround distinguishes the motifs without a default saturated brand color. Both compositions consume the same entry point with different content, dimensions, palettes, HSV and layout.

Top bars are explicitly nonsemantic layout ornaments. There is no embedded text, title font, fake data, forecast or status claim. Add real labels using the host's separately licensed/measured typography. Do not mistake these demonstrations for production communication design or individual owner aesthetic approval.

## Color has a purpose
Choose palette roles before hue effects: outline, midtone, warm accent, light center. Keep enough contrast between adjacent indices; a palette can be mathematically valid and visually poor. Green is allowed and has a positive regression test; no color family is banned. Use it when subject, brand or hierarchy supports it, not merely because it is a default.

HSV is a clear, limited transformation, not a color-grade matching engine. Saturation/value are percentage-point offsets, not multipliers. Large shifts can collapse several colors to the same endpoint. Show a swatch proof when palette identity matters. Do not label the number of indices as the number of distinct visible colors after clamping.

## Alpha and composition
Use −1 to expose the host. Checker mode makes transparent cells opaque and is appropriate for a technical proof, not normally final artwork. Keep one canonical model and derive variants; do not redraw each preview independently. Caller layer order, compositing, transforms and clipping remain choices. Budget each retained RGBA surface and release unused proofs.

## Retention decision
Remain a restricted candidate under recipes: zero new public families and zero formal recipe registrations. Two new examples validate a bounded integration, not broad API promotion. Broader formats, arbitrary image loading, alpha palettes, downsampling or animation require a separate contract and evidence.
