# Bounded composition contract

Public entry: `createReviewTiles({fontRoot,canvasModule?})` -> frozen object with `diffPreviewTile(props)` and `reviewerSummaryTile(props)`. `canvasModule` is a trusted local module selector, not untrusted input. Runtime identity is checked. All three regular non-symlink font files must match SHA before any registration; false registration throws. Font registration is global: callers must not replace these aliases afterward. `tiles-internal.mjs` is implementation detail, not the validated public setup contract. No caller context is accepted or modified by the factories.

- Diff: integer width320..1000, printable ASCII filename1..90; dense1..12 rows; each kind `context|add|remove`, lineNo integer1..9999, printable ASCII text0..160. Measured filename fits width−40, text width−76. Returns physical2×width by2×(30+20×rows) Canvas. No wrapping, truncation, shrinking or patch parsing/applying; repeated line numbers are accepted illustrative labels, not validated diff semantics. Context/add/remove have fixed neutral/green/red backgrounds plus space/+/−, not color alone.
- Reviewer summary: width320..1000, dense1..8 rows; printable ASCII initials1..2, status `approved|pending|none`, color#RRGGBB. Caption0..70 printable ASCII. Actual measured combined label must fit. Returns physical2×width by56 Canvas. Approved count is computed from explicit statuses; no live approval or identity is inferred. Initials are generic labels, not users/avatars. Colors are caller-authored; arbitrary palettes need contrast review.
- Structurally invalid inputs are rejected before Canvas allocation. Measured overflow may allocate a private1×1 measurement surface, never a caller surface. Rows are copied by explicit own numeric indices; holes and inherited-only indices are rejected, and custom iterators are ignored. Caller input is unchanged.
- Fresh offscreens isolate path and typography. Their later `drawImage` intentionally inherits caller transform, clipping, alpha, filter and blend. Tile factories do not enforce caller scale or promise arbitrary-content aesthetic quality. No accessibility/interactive/browser/mobile behavior or cross-platform PNG identity is claimed.

No source raster, original full-page renderer, private review record or owner approval metadata is included. This is a restricted code candidate, not an automatic public-family promotion.
