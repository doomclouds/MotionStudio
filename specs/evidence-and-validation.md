# 证据与验收

规范版本：1.1.0；状态仍为 DRAFT。本次补充人工审计口径，不新增 schema、自动门禁或采纳声明。

CURRENT：技术、视觉、实际听审、声画同步、用户接受和公开权利分别管理。详细交付契约见 [导演 Skill](../skills/motion-film-director/SKILL.md) 引用的 delivery-workflow 与 final-delivery-evidence。

## 每条结论能追到什么（PROPOSED 记录要求）

在授权的私有项目记录中，结论关联：确切版本/媒体身份、范围（时间窗或静态画幅/状态）、实际方法/执行者或工具、输入配置/环境、观察及限制、支持/反证、后续修复和复验。采用现有证据 schema；本页不替换它们。

| 证据 | 可支持 | 不可支持 |
|---|---|---|
| hash/清单 | 字节身份、声明依赖 | 实际执行、内容正确、许可或观看 |
| 测试/完整 decode/数值 | 对应技术契约 | 艺术通过、真实感知听审 |
| 静帧/接触表 | 被观察帧的视觉事实 | 连续运动、交互、响应式、声音 |
| 连续观看/实际接收音频的听审 | 明确覆盖范围的感知观察 | 未观察区域或所有人的喜好 |
| 用户反馈 | 指定版本/对象/范围的接受或否决 | 第三方许可或后续改版接受 |
| 许可与授权记录 | 指定对象/动作/范围的权限依据 | 其他素材、其他发布渠道或永久授权 |

每门保留真实原状态（如 PARTIAL、NOT_LISTENED、NUMERIC_ONLY、NOT_TESTED）；不要为了统一报表改写为 passed。未运行、受阻、失效与失败分开。完整候选不能因时长旧门通过冒称最终交付。声明式记录和签名认证不同，签名本身也不证明实际观看/听到。

## 公开最小投影

制作证据默认外置私有保存。公开源码/方法只含经审定允许的事实与状态；portfolio 的唯一 work/1 元数据采用 NOT_INCLUDED 公开边界，不携带私有记录标识、报告指纹、存储断言。NOT_INCLUDED 不表示证据缺失或可访问。公开源码和自绘帧身份与私有报告身份分开。

## 变更后的复验

先列影响面，再复跑相关技术与实际感知检查。媒体/输入/版本变化则重新绑定，不沿用旧版 hash 的接受。修订证据不能静默把原反证删除；若此前结论错误，说明撤回及新依据。为展示规范合规而编造已运行测试、已听审或用户认可，属于不合格交付。

## 资产利用审计口径（PROPOSED）

用于回答“现有哪些资产、在限定任务中实际考虑或使用了什么”，不是给资产排名或证明设计能力。复用现有 catalog、作品 work/1 与文档入口，不建立第二套资产登记；库存与利用证据必须分开。

1. **先冻结分母与计量单位。** 记录被审仓库 commit、纳入目录及规则，从该版本真源提取清单；不能把另一版本的执行证据无说明地配上当前分母。基础族、正式配方、候选包、包内子配方、完整作品与方法文档分别计数。目录存在不等于登记，候选包数量不等于其内部能力数，方法文档数量也不等于原子经验数；不将异类相加为“能力总数”。
2. **逐层区分利用证据。** 索引命中只说明发现；实际读取说明考虑过；读后拒绝应记录合同不适用或内容冲突，不算执行失败。源码 import/call token 与作品声明只支持静态引用；实际运行需对应执行证据，返回值参与下游布局需核数据流。观看作品封面并借鉴关系属于参考消费，不是执行作品源码。部分阅读或截断保留范围，不升级为全文研究。
3. **事件数与去重资产数分列。** 同一资产被多次调用或观看，不能同时用作多个独立资产计数。拒绝父包不意味着逐项评估或拒绝全部子配方。按稳定身份及同版本范围去重，并注明无法映射的项；未知项不强塞入最近类别。
4. **绑定任务、版本与干预阶段。** 在授权私有记录中注明样本选择规则、任务范围、自主首版与审稿后修订，区分当时执行与本次重新验证。无继承对话不等于文件系统隔离、干净机器或无先前依赖；不得据此宣称受控冷启动实验。未独立保留首版时明确不可分离，不把最终版修订倒算为首版能力。
5. **保留未知与适用性缺口。** “本样本没有使用记录”不等于从未使用、无用或不适用；没有穷尽任务适用机会，不能把全库覆盖比例解释为有效利用率或成功率。治理文档未被事件记录覆盖也不代表未读。合成测试、静态合同、参考观察、实际制作与用户接受仍各自有边界，不因聚合而升格。
6. **公开方法，私有证据按原范围保存。** 遵守 [源码范围](../SOURCE-SCOPE.md) 和本页公开最小投影：不将实际制作/研究事件集、私人反馈、报告指纹、本机路径或原素材搬进公开库。去标识不自动授予公开许可。公共聚合若另获审定，应说明固定基线、计量规则、未验项和可重算范围；不把固定数字写成永久事实，不把私人数据缺席包装为可公开复跑。

这是人工解释合同，不新增采集器、评分、遥测、强制 ledger 或晋级规则。需要自动化时另审输入权限、确定性、合成测试与源码边界；不得把专案硬编码脚本直接宣称通用工具。数量不能替代实际构图职责、反例、运行验证或作品准入。
