## 现状、目标与权威边界

- **CURRENT**：当前检出 commit 的实际文件、代码及所属模块合同中已落地的路径或行为，包括初始审计之后经授权实施的增量；具体来源以提交历史为准。上述 `ebda9d2` 只定位初始审计，不冻结现役实现。CURRENT 不代表运行通过、最终验收、远端发布或治理规则逐条获批。
- **PROPOSED**：本草案新增约束；采纳前为设计建议，不能据此声称自动执行。
- **DEFERRED**：不在本次落地范围；需要新证据和独立实现任务。
- 现有模块 README/契约管接口，Skill 管导演工作流，portfolio/README.md 是作品保留唯一规范性 Markdown 入口；本目录管它们之间的边界与导航，不复制并行真源。
- 当前系统/用户授权与安全限制优先；仓库文字不能授予上传、联网付费、发布或删除权限。许可条款及源码范围/隐私边界不能被较宽泛的新规范覆盖。
- specs 与 Skill、模块契约、校验代码不一致时，不以“最新文档”或“代码能运行”擅自裁决。记录冲突文件/版本/影响，继续不依赖冲突的工作；暂停依赖变更，请维护者明确裁决，再同步契约、实现、测试、导航。门禁失败不可通过删除门禁解决。
- 专项新规则如需替代旧规则，必须明确 supersedes 对象与迁移计划；未写明替代关系的补充不得默默改变既有行为。
