# 从优秀参考到有意图的组合

UI、Motion 与声音导演共用的原创决策流程；不是自动选风格/评分器，也不声称此流程已证明作品质量提升。原创、新方向或重大重设计在定方案与编码前执行；既有方向内小修只复核受影响关系，沿用仍有效的参考/证据，不重做研究、不强迫另起多案。指定复刻先守其保留合同，不借“原创变形”改掉用户锁定项。

## 本阶段创造目标：需求驱动的迭代循环

本阶段以创造新作品/产品检验积木，而不是先扩库再找内容：`拆解作品需求与问题 → 在积木及其来源作品中找可参考对象 → 提炼关系并融合成新创意产品 → 真实制作发现缺口 → 缺口驱动补充积木/寻找优秀作品复刻学习 → 验证后再次创作`。这是当前阶段的学习目标；通用 Skill 不要求每次小修都跑完整循环，也不把补库或复刻变成按时交付的前置配额。

- 需求先拆成内容/用户任务、表达与体验目标、约束和可验证问题，再依下表找已有族、机制、配方及其来源作品。发现可参考对象后仍须实看、筛选和跨例提炼，不把积木目录当审美标准；没有组合必要时保留更简单方案。
- 先用现有能力实现有意图的融合，以真实输出暴露缺口。区分“未找到”“不会正确组合”“实现缺陷”“确实缺机制”“缺表达经验/优秀参考”，记录触发问题、已有替代与失败证据，不从一次不好看直接推导必须新增积木。
- 真缺独立机制时按所属模块契约补充；已有能力足够则改组合/参数/实现，不重复造族。缺表达经验时带着具体缺口寻找优秀成品，按授权范围复刻关键关系并做对照，再提炼适用原则/反例，回到原需求重新融合；不做无目的临摹或把整件参考换皮冒充新创意。
- 验证分两层：新增/修订积木核 API、边界和独立例；接回作品核表达、视觉、时间与实际声音贡献及用户反馈。机制技术通过不替代作品接受，复刻相似不替代原创成立。仅在有真实证据及相应授权时沉淀通用能力；未完成项记入项目待办，不把本轮候选写成成熟能力。

## 1. 带问题发现、筛选，而非收集好看图片

从 brief 写出本次需要解决的表达缺口：观众应理解/感受什么，现有方案为什么不足，参考需要证明哪种关系。先按需读[内容决策](CONTENT-DECISIONS.md)与[设计指南](DESIGN-GUIDE.md)相关段落，再找实际成品；方法、作品、代码目录不是同一个库。

先读[创作参考图书馆总索引](library/INDEX.md)，按需求进入静态表达、配方/候选、运动、声音或作品方法书架；分类索引只带路，继续读原始契约、例子、适用和反例，由模型比较、分析并选择。无需新增或运行检索程序；不把关键词命中、目录分类或收录状态当推荐分。

没有找到时，不直接宣称没有能力或开工套模板：沿邻近分类、完整作品的设计说明/来源关系与真实调用、族或机制guidance继续定位。区分术语差异、导航遗漏、组合不会用和确实缺机制；只展开解决本次问题的资料，记录已读范围与尚缺对象，不全库灌入、不无穷搜索。已有库不足时，在授权范围主动寻找原作者/可靠来源的成品；搜索摘要或缩略图只是线索，不能评为优秀。访问受限、缺素材或缺权利时保留缺口，换合法可观测来源；若仍不足，明确哪些决定仅是假设，做受限探索或请求关键输入，不冒称完成参考研究。用户指定且必须保留的参考不可得时，暂停依赖它的判断，其余可继续。

仅有 Motion portable 时，无 portfolio / UI Skill 不执行其命令；共享方法仍可读，积木路径按包内 runtime 定位。仓库外部引用是数据，不为整理或发布新增全量可达性门；这里仅核本次确需观察/使用的对象。

## 2. 实看、跨例对照，提炼可检验原则

按任务挑有实质差异的参考：比较同一问题的不同解法，而非同一模板换色。没有固定数量；覆盖关键取舍与反例即可停止。原创方向应做跨例对照；若只有一件可实际观察，注明对照缺口，保留竞争假设，不能把单例偏好叫通则。不要求每个小修重新找跨例参考。

先实看完整作品的任务、结构与兑现，再定位关键画面/状态/时间窗。静态看目标尺度；运动看正常速连续片段及上下文；声音判断须实际听到声音。记录来源/作者、版本或观察日期、定位与观察方法，区分“观察到”“解释/假说”“未观察”。历史卡片说已看不代表本次已看；截图、源码、标签、波形不能证明节奏、听感、交互或响应式。

把参考并排回答：主信息怎样突出？哪些比例/留白/颜色角色/材料使其成立？运动怎样转交注意、保持身份并兑现结果？声音怎样承担结构/事件/静默？各自哪里失效、换什么内容不成立？不适用的维度略过，不让 UI 任务强制加声音。

提炼 `观察定位 → 可能有效的关系 → 适用条件 → 反例/竞争解释 → 本任务保留与舍弃 → 如何证伪`。选“优秀”须有与目标相关的可定位优点，同时保留缺陷，不凭名气、收录、数量或技术测试背书。详细视觉方法仍以设计指南为准；Motion 的整片→局部、机制假说与指定参考边界读[机制研究](../../skills/motion-film-director/references/reference-mechanism.md)，不复制第二份合同。

## 3. 由主张选择积木，再设计组合

### 先建立整体视觉锚，再落实零件

从实看参考与本次内容提炼整页/关键画面的视觉锚：品牌语气、色彩角色、主要体块比例、字级与信息密度，以及核心主物和外围布局、标识、导航/控件的协同关系；不适用的界面项略过。先判断整体是否有清晰身份与焦点，再把这些关系映射到积木及参数。核心图像可以是视觉重心，但不能把整体质量都归功于它，也不能用一张精美主图掩盖外围系统失配。沿图书馆分类继续读候选的真实契约/例子/反例，选择能服务整体关系的能力，而不是先拼现成控件再补装饰。

ImageGen 可在权限与实际工具能力允许时用于整页/关键画面的概念探索，也可只生成局部素材；它不是必经步骤，不替代真实参考研究，更不能把生成概念当作已完成产品的参考证据。探索后说明哪些整体关系保留、哪些须因真实内容、实现或状态而调整，不把特定方案或配色固化为通用模板。既定方向小修沿用有效视觉锚，不为此重做整页或强制出图。

在现有项目记录中分清 **概念图、生成素材、真实代码实现、已验证交互**，分别指向实际版本与证据：概念图只支持所见视觉关系；素材须说明用途/来源及可编辑或分层边界；代码须有源码与实际运行输出；交互须实际操作验证。截图相似或局部像素相同不证明外围控件由何种代码实现，也不证明交互可用；未定位源码就明确未知。用户要代码时必须交付真实代码及运行边界，不能用整页生成图、贴图页面或视觉 mockup 冒充所需实现；代码中合法使用生成素材仍须如实标明，未实现项不得声称已实现，未验证项须明确标注，不能冒称通过。

先写本片/本页的核心表达，再建立一条可追溯决策链：

`主张/预期感受 → UI、运动、声音各自功能（或不需要） → 候选稳定 ID / 准确 API → 组合关系 → 本次原创变形 → 风险与对照判据`。

选前读实际契约和源码：UI 决定信息承载与层级；motion 决定对象、状态、时间和因果；声音决定结构、事件反馈或有意静默。不要按“每类至少调用几个”凑数。对有竞争力但弃用的候选写具体理由（争焦点、语义不符、读时不足、权利不清、能力未实现等），不是替全库写淘汰表。不适合就不用；缺独立机制才考虑补底层，不让可用积木反过来扭曲内容。

组合不是并排摆满效果：写明谁是主视觉、谁提供证据、谁转移焦点；共享对象/数据/token，明确层序、遮挡、安全区、时序与留读、运动单写入、声音 cue 的起因/峰值/落定及静默。按需查[设计到 Motion](../../skills/motion-film-director/references/design-to-motion.md)与各模块合同，不重写 API。音频核心未实现的动态处理不能因声音指南提及便假称可调用。

原创变形要改变有意义的关系：依据新内容重组构图、信息展开、对象动作或声画呼应，说明相比参考保留的原则、改写的关系、预期收益与可能损失。只换标题/颜色/快慢不是原创充分证据；也不为新奇破坏品牌、事实和用户已定方向。优先验证最可能失败的关系，不要求整片只能一种机制。

### 组合的具体样例，不是模板

下面是把已有原则落实为选择的方法，不是新的必填报告，也不证明迁移后已有效；只采用本任务相关项。

- **让同一身份承担不同功能。** 先选少量能辨认的形状、字排与色彩关系，再检查它们如何进入主视觉、工具状态与最终输出物：哪些关系保持身份，哪些必须随功能改变？例如主图的强调色可以关联选中对象，但不能让所有控件同时抢焦点。判断整页/整片是否仍能读出一个主张；只沿用一组色值、每幕换一套装饰，或只有中心图片有风格，都不足以证明统一。适用于品牌与创作工具，不要求所有数据界面变成海报。
- **用同一对象的变化兑现承诺。** 先写操作前、触发动作、操作后，再让同一对象保持身份，显示变化的真实后果。已有 [Tessel 日程数据](../../portfolio/works/tessel/src/reference-data.mjs)与[状态编排](../../portfolio/works/tessel/src/choreography.mjs)展示了按事件 ID 连接拥挤日程与重排结果的方法；其非官方复刻归属与边界见[作品说明](../../portfolio/works/tessel/README.md)。迁移时核“文字声称的结果是否真的发生”，而非只查卡片有没有移动；静态 UI 可用同状态证据或清晰的前后对照，不必强加动画。源码能说明实现结构，不能替代本次体验验证。
- **保留具体形式中的表达能力。** 从参考提炼故事时，同时检查用户锁定的媒介、玩法、视角和角色行为。像素闯关的作用可能来自跑跳、受阻、反馈和过关的连续后果，而不只是“目标→障碍→结果”三个词；已有 [Favorite52 关卡源码](../../portfolio/works/favorite52/src/legacy/source/v3/game/gates-next.cjs)可用于研究此种状态组织，非官方来源与资源限制见[作品说明](../../portfolio/works/favorite52/README.md)。指定形式内改内容，不能把动作全部换成信息卡后仍称保留了参考。未指定游戏形式的任务也不应机械套关卡；采用与否仍服从本次需求。

## 4. 实现与质量对照闭环

在项目私有记录中区分：来源启发、拟选、真实调用、已执行和已验证。真实复用须指向本版源码 import/调用位置、参数/配方及输出版本；仅挂稳定 ID、抄标签或“适配过”不算实际调用。没用库而自实现就如实说明，不伪造使用账单；代码执行也不证明表达成立。

对本次承担画面、布局或状态职责的既有能力，指出返回值/状态由哪个绘制或后果计算点消费；仅保存而未用于输出的字段不计该职责。若实际使用或依赖关系仍有疑问，只对相关机制做最小同版扰动或删减对照，核实际输出中预期区域/后果是否改变，并核应保持不变的部分；不要只看全图差异。逐帧样本数、额外寻帧检查的总调用数与真正消费输出的区间分别记录；预先计算但未进入画面的字段不计该阶段复用。调用计数、依赖清单、文件身份和像素变化各有边界，不单独证明表达有效；微小幅度与局部未验项照实保留。不要求每个简单调用都新建对照，也不为增加使用量强加机制。

原生制作也要分层记账：`render-shot.mjs` 的帧序列、编码/解码和版本记录证明实际制作入口；`sampleMotion` 的活动矩阵进入物件坐标、`solveTwoLinkIK` 的返回关节进入肢体绘制，才证明相应机制消费。一个变换被多阶段调用仍是同一机制，调用总数不是去重资产数或利用率；已有原生同帧复渲证据可按冻结版本沿用，不为计数强加采样。纯静态自绘、外部绘制和原生有声制作分别记录，没有导入既有代码就明确零代码复用。

实际 API 名称与消费分支也须准确：闭合折线的 `compilePolyline/samplePath` 不等于 `compileCubicPath/sampleCubicPath`；静态带状边缘若由位置和单位切线的法向共同生成，就分别说明两者职责。仅扰动位置不能独立证明切线贡献；返回角度、距离或参数若只存日志，不计绘制使用。一个采样器在前段驱动画面、后段仅留trace时，调用仍发生但后段不计画面职责。静态控件可以实际执行库绘制，而其返回receipt只供检查；不能倒称receipt控制了主体或滑杆已有输入事件。沿用上面的最小对照原则，不为每个字段强制另造消融。

将真实输出和参考的目标关系对照，不机械追求像素相似：同目标尺度/阅读条件检查焦点、比例与内容兑现，同时复核整体视觉锚及核心主物与外围系统是否协同，不只裁看最精美的局部；Motion 核常速连续表现、动作后果与读时；声音在相同画面上下文实际合听。需要判断某个组合是否有贡献时，保留简化版/删减版或局部 A/B，尽量控制其他变量；已有认可段落不因新流程重做样片。对照先问“主张是否更明确、关系是否更有表现力”，再看细节，不把效果数量当进步。

记录实际观察、失败信号、采用/撤回及未验项；失败先分诊参考选择、原则迁移、组合关系或实现，不只加装饰。沿各导演既有审查/交付合同回归，技术、视觉、听审、同步、用户接受与权利分门；没有实际输出或感知能力就标记未验，不发明审美分数或通过结论。经验只有经真实对照才能标注其已测范围，其余保留假说。

## 逐轮指挥与反馈回流

以上原则执行时，在已有项目决策记录中把本轮写成一条短指令，不新增报告体系或必填 schema：

`本版/目标画幅或时间窗｜要解决的一个主问题及可见结果｜保留项｜参考定位与采用关系｜积木职责/组合或自实现｜本轮改动｜实际输出与复验方法/失败信号`。

- **先给问题和边界，不预写好评。** 自行制作或交接实现时，传原 brief、当前源码/输出、已定取舍、合法依赖和上述指令。参考拆解交付的是能指导取舍的关系及反例，不是风格词或链接列表；只要求完成当前缺口，不强制新方案、扩库或另起代理。
- **收执行回执，再做导演判断。** 回执只需指向真实改动/调用位置、产物版本、实际观察与未验项；“已读指导”“用了积木”不是画面证据。先让评审看 brief 与实际输出，再给解释；UI 按目标尺寸与任务/状态审，Motion 按常速连续观看、实际听审和同步分别审，沿各导演现有合同记录，不相互代验。
- **按失败原因决定下一步。** 偏离任务/指定形式→回到需求与保留项；焦点、内容兑现或组合贡献不明→与简化版对照并调整关系；实现错误→局部修复并回归；仅缺证据→补对应观察，不以重设计掩盖未审。找不到机制时沿前述缺口分诊，不把每次失败都变成新组件。
- **保留、撤回或待验必须有对象。** 比较同内容、同观看条件的前后版本，写明改善、不变、退步或无法判断；只能确认局部就只确认局部。没有值得修的可定位问题，不为“优化”制造变化；完成当前委托的交付/审核条件便收口，尚待用户决定或权限的依赖暂停，未验项不得填通过。
- **反馈先绑定范围，再抽经验。** 在现有私有记录保留反馈原意、对象/版本、范围与后续动作；“喜欢风格”、局部认可、愿意保留、完整接受和公开授权分别判断。未知版本先标明未知，不能反填最新输出。某画面受到好评，只支持该次反馈，不证明所有指导都已读/执行，也不证明某条规则导致成功。
- **只回写会改变下一次决定的差异。** 用 `原有判断 → 实际观察/反证 → 修订选择 → 适用与不适用 → 下次如何检验` 更新所属既有方法；没新增认识就不新增文字。单例留有界观察，未做迁移/对照留假说；技术确定性、有限视觉反馈、跨内容迁移与流程因果效果分开。无对话上下文但仍共享文件系统的试验不得称严格隔离。失败/撤回保留，作品准入、公共方法审定及新机制晋级仍各走原合同，不由回流自动获准。

有界实例见[竞速鞋发布首屏的主张、产品与方向协同](DESIGN-GUIDE.md#虚构竞速鞋发布首屏主张产品与方向边界的协同)：借其静态关系、采用/弃用与实际调用边界来写本轮指令，不照搬配色/品类，不把有限正向反馈外推为交互、Motion 或流程因果验证。

## 检测工具的辅助职责

先指定要回答的问题和可观察的成功条件，再选择检测；不为取得相近曲线反向修改内容。工具负责采集、定位、测量和核对声明，导演负责解释关系、选择修改和分别保留观看、听审、交互及用户接受的证据。

**推理方向不能倒置。** 在同内容、同状态、时空对应及测量条件可比时，独立确认的高吻合通常伴随相关测量的小差异；这是一种有条件的经验预期，不是所有指标的必然定律。反过来，小差异只说明已测特征接近，不能推出完整复刻、语义正确、好看或听感适合。大差异也须排除字体栅格、编码、尺寸、配准及时间偏移等因素，不能直接判为作品不好。没有可比参考的原创任务，不能把趋近另一部片的数值当目标。

反例：均值/直方图相同仍可排列成不同画面；小面积按钮文字、图表单位或手与物体接触点错误，可能被全画面/低清 SSIM 均值掩盖；即使局部 ROI 的 SSIM 接近，也可能因区域选择漏掉邻域、压缩或缩小丢掉关键字形、错误状态恰有相近轮廓而误导。先看完整任务和原尺寸局部，再解释指数。ROI 不是语义识别器，不以挑选最好看的区域消除反证。报告应保留实际采样时点、原生帧身份、ROI 坐标与未覆盖区域；不同尺寸/采样下的数值不套通用通过阈值。

| 辅助工作 | 输入与可得输出 | 导演如何继续判断 |
|---|---|---|
| UI 来源/交接结构检查 | 文件路径、DesignHandoff 声明 → 可读性、字段与引用错误 | 不读取画面或认证资产字节；另核当前渲染、来源与可见状态 |
| UI 同条件画面对照 | 锁定视口/DPR/滚动/字体/状态的原件 → 并排、overlay、差异定位 | 当前是制作/观察流程，不是自动 UI 质量检测器；模块单测、交接 schema 和字体 cmap 覆盖均不证明整页正确、实际字形渲染或交互可用；核内容、层级、字形、数据语义，交互/响应式/键盘另实测 |
| 单片技术检查 | 本地影片 → 帧数/PTS、全解码、低清变化图、响度 | 定位复看窗；低频采样不排除单帧错误，静止不等于无内容 |
| 双片信号诊断 | 可比双片、显式时间窗/ROI → 同格式特征、差值与对齐提示 | 返回原生帧与正常速片段核对象/材料/动作；相近包络不证明相同因果 |
| 事件/声音辅助 | 人工事件观察或自有分轨 → 时间区间、缺失/歧义、频带竞争 | 标注真实性、完整动作与实际听感另核；计划落点不当观测、能量竞争不当掩蔽结论 |
| 证据与报告校验 | 声明、媒体/产物 hash → 引用、身份和呈现完整性 | 身份匹配不证明看过/听过；报告生成、退出0不自动签发艺术通过 |

UI 导演先看整页与任务，再以对照定位局部，保留状态/文字/数据错误优先级；Motion 导演先看完整动作与声音职责，再以检测定位事件窗，回到原生 PTS 邻帧、常速观看与实际合听。每条 finding 分列「观察事实 → 工具测量 → 解释假设 → 复看依据 → 修改/保留决定」，绑定版本、覆盖范围、反证与未验项；无数据保留未知，不填零值或通过。

短片尤其须显式选窗：采样索引、原生关键帧、片段播放和事件观察是不同覆盖层。默认窗口超出片长而被跳过、未产生指定帧或没有事件标注时，不代表该片没有问题，也不代表已完整观察。覆盖开场、关键动作/交接、结尾及至少一个未参与调参的控制窗；窗口应由真实任务决定，不为满足数量硬造事件。工具未自动执行的工作须明确保留未验。

## 空间与因果叙事：让环境变化兑现主张

以下保留静态参考与原创有限研究中的可复核关系，不新增积木、现役配方或已接受作品。已有对象身份、接触交接、连续背景、焦点交接与读时不重复登记；增量是这些关系怎样让一段叙事被看见。来源海报、封面与生产图只能支持构图观察；新写的路径、时序、传播和转场是原创选择，不归为原作已观察动效。正文和源码可补充规则证据，也不能代替运行原作。

### 观察者与环境回应

参考 [NASA/JPL Visions of the Future](https://www.jpl.nasa.gov/galleries/visions-of-the-future/) 的完整 Grand Tour、Europa 海报：大尺度世界、较小观察者和留给文字的空间建立关系；其中窗口式观景与前景人群更直接来自 Europa。署名 Courtesy NASA/JPL-Caltech；[图像使用政策](https://www.jpl.nasa.gov/jpl-image-use-policy/)不取消标识、第三方及背书限制，方法引用不携入源图。

- 原创植物夜景用小光点抵达后才让环境回应。若叙事是人物放出光，出发点须取实际手部端点，终点取目标随姿态变化的中心；独立近似坐标会使光在手外凭空出现。数值重合后仍看完整姿态和对象归属，不再把共享坐标本身当新方法。
- 分开环境事件与文字读时：主事件在一侧进行时，另一侧留白不必等到结尾才被使用；按主次提前出现标题，再给解释完整留读。检查全字可见到片尾的区间，不只记录淡入开始。亮起不等于生长，文案是诗意解释还是可见动作须说清。
- 适合有尺度对比和环境反馈的叙事画面；静态稿只采用层级关系，不能声称时序已验。有限轨迹/抽帧不证明真实照明、空间物理或常速情绪效果。

### 局部遮护必须在环境仍继续时成立

参考 [SBS《The Boat》](https://www.sbs.com.au/theboat/) 静态封面的云层、斜雨、船与环境尺度关系；作品据 Nam Le 故事，由 Matt Huynh 改编，归属见 [SBS说明](https://www.sbs.com.au/learn/resources/a-refugee-story-the-boat/)，不是 NFB 作品。未取得可复用资产许可，不带入源故事、美术或代码；未观察源章节转场。

- 原创种子分镜的遮护不能靠字幕宣布：罩下清楚，罩外天气仍在。若所有风线一起消失，看到的是天气停止而非局部保护。用无字幕画面核因果，再回到文字补不能从静帧得知的时间跨度。
- 检查整条雨线与遮护轮廓的关系，只按线段起点拒绝会漏掉从外穿入的线。有限二维示例可按实际轮廓和方向做采样裁剪，并限制保护范围到地面；这不是通用精确求交、流体或三维遮挡算法。物件接地点、种子地面点与后续芽点需对应；材料仍像弧枝时，不把几何通过说成陶片已被识别。
- 分镜可以验证摆放与局部遮护，不能证明落地动态、转场节奏、数日时间已被理解或无字幕受众测试通过。局部检查裁切也不等于成片实现了近景镜头。

### 先看见阻断，再用同一规则兑现变化

参考 Vi Hart / Nicky Case 的 [Parable of the Polygons](https://ncase.me/polygons/) 封面、正文与[固定源码](https://github.com/ncase/polygons/blob/3ec3fd74a52ce24f74790a47f117d1a3abefbbb7/play/automatic/automatic.js)：角色状态与群体结果相联系。源库 CC0 声明不使本次研究成为源交互运行或声音观察。原创灯笼故事改为确定性四邻接传播，不套用原作偏好/随机移动模型，不对真实社会群体或物理照明作结论。

- 阻断应有可见的缺口；若虚线已经贯通，字幕说“停住”仍会与图冲突。空位、线路断开、角色落位、接通和下一步传播共同消费实际状态；运动中靠近不等于逻辑已到位。
- 表情、光晕、计数与字幕消费同一状态。尚在传播时不要提前说停住，只有稳定停滞才说明缺口；补位角色仍遵守原规则，不因换颜色暗增能力。一次更新只看上次状态，避免同次更新连锁点亮整个路径。
- 离散事件以整数帧或明确刻度调度，核前一帧/事件帧/后一帧；十进制除法后取整可能把意图中的边界推迟。有限路径可检查无种子、不补位及补位对照，但不证明通用模拟、真实输入操作或观众已理解因果。

### 地点承载文字，留下经过而非留住旧字幕

参考 Matt DesLauriers 与 NFB 的 [Wayfinder](https://wayfinder.nfb.ca/) 官方宣传静图及[作者说明](https://www.mattdesl.com/)：地貌、小旅行者和稀疏符号承担注意力，而非界面框。只观察静图并读介绍，未运行生成诗歌、运动或声音；未确认其美术/代码/音乐复用许可。原创海岸行旅使用自写固定诗句，不冒充生成系统。

- 陆地、旅行者、痕迹、站点及文字共用世界投影；相机走过后，标记仍归原地点。到达状态触发当地文字，离开后文字可淡出而路径痕迹保留，区分当前阅读与经过的记忆。已有连续背景/尾迹原则不重复计功，增量是地点与阅读职责的分离。
- 文字说芦苇、盐地、石头时，地点应有不同的可见形态，不能只换站名和诗句。用少量明显地标兑现内容，不用额外粒子遮掩三个站点实际相同。
- 留读同时核位置和背景：字色在一块浅色地面上清楚，不代表跨到深色山脊仍清楚；淡出需早于旧字被画幅边缘裁断。背景框的对比测量不覆盖淡入、抗锯齿及编码后的全部像素；固定站点停留也不证明实时阅读舒适、响应式或无障碍通过。

### 隐去上下文后，以同一物件揭示尺度

参考 Charles 与 Ray Eames / Eames Office 的 [Powers of Ten](https://www.eamesoffice.com/the-work/powers-of-ten/)；实际构图依据是 [Library of Congress 展示的生产图](https://www.loc.gov/exhibits/eames/science.html)，从野餐细节到草地、港岸及更大环境。不是常速观看原片，也不复用其画面、配乐或假定开放素材许可；片中音乐署名不构成听审。

- 原创修补布片先保留足够身份而藏起纽扣、门襟等上下文，再拉远让衣物出现；如果第一帧已露完整语境，缩放可能只变大小而没有新信息。物件、材质细节及相邻地标属于同一世界变换，不能用两张近似图换接冒充连续。
- 将行进、识别停顿和最终偏心排字分开，文字在物件意义建立后进入。补丁厚边若像徽章，先修局部接触阴影与边缘，而不是增加整件衣服的花纹。几何身份连续不自动证明“修好”或“继续穿用”；针脚显现也不等于缝制动作。
- 同一纹理缩小时仍可能闪烁；世界坐标固定与逆序求值通过不能免除投影频率和常速检查。这里仅支持有限构图/编码抽帧下的身份观察，不重现十倍尺度规律、真实布料或完整空间镜头系统。

上述范围含静态分镜与离线编码样片；选帧、模型及局部复审分别支持所查关系，不是常速观看、浏览器交互、受众理解或完整审美接受。没有音轨是制作选择，不是声音已经听过；声音/合听仍须按声音导演流程另验。UI 导演可用这些关系安排说明图、步骤与状态依据，不能由影片样本推定真实操作已验；Motion 导演需将相应对象、事件、读时落实到本次输出，再记录实际采用与反例，不能把读到链接算作已使用。

### 尝试失败后，让新目标与成功反应可见

参考 Blender Institute 的 [Caminandes 2: Gran Dillama](https://video.blender.org/w/fb70d459-48d2-4db5-adba-813c84f9200a) 局部抽帧：较近表情、宽场地、短暂空场、动作与后果之间有分工。源片尾署名 CC BY 3.0 / Blender Foundation；素材许可不能自动扩展到另售音轨。本观察不是常速喜剧节奏或实际听审。

- 原创开灯情节先让失败结果持续，再让视线指向新的可操作物，随后才伸手；第二次动作须与第一次有实质区别。接触时手和物件共享目标，释放后结果保持；成功还需角色表情/姿态回应，不能只靠结尾标题宣布满意。
- 声称渐亮时同时检查灯芯、灯罩、光晕，而不只检查一个连续参数；布尔切色会让主体提前全亮。若要表达人物受到光，加入与同一状态关联的受光侧或地面回应，单独背光光晕不能证明照到了人物。这是作者设定的二维光色，不是物理照明。
- 事件音可按同一动作时间安排，但合成源码、波形与声轨存在只支持来源和结构落点；未听过就保留音色、平衡与情绪效果未验，不能把有声样片误写成静音。

#### 已有环境怎样让第二次尝试成为新策略

补充参考 [Felix in Hollywood（1923）Archive 转录本](https://archive.org/details/FelixInHollywood1923) 的实际视频抽帧：被拒请求、独处姿态变化与随后使用伞架支持“受挫后换策略”的有限解读；Archive 归因 Otto Messmer / Pat Sullivan，不把上传者转录本称为官方母版或原放映速度。[对应 Commons 说明](https://commons.wikimedia.org/wiki/File:Felix_in_Hollywood_1923_cartoon_film_(1).png)将 1923 影像标为美国公版，并排除录音；该转录本有后加音乐/音效，未核复用权、未听审、不携入素材。

- 与上文失败、视线、反应原则去重：新增条件是解法所需的环境物件应提前可见且位置稳定。原创登石摘叶研究先伸手落空，再把头眼转向已有石头，最后改变身体相对同一目标的位置；不是延长手臂、移动道具来赐予成功，也不是重复同一伸手。失败包含横距与高度，不能概括成纯垂直障碍或唯一合理解法。思考眼神在全景较小时，数值方向正确仍需检查可见尺度与实际停顿。
- 复用既有定长落脚与接触合同，但登高须分开支撑与摆动：支撑脚留在世界接地点，另一脚先到石顶，再交接支撑。两段肢体同时检查最大和最小可达距离；脚离髋太近同样可能不可解。曾出现膝穿石与脚髋距离低于两段长度差的反例，应修改路径并重编码，不放宽长度断言；有限骨架/轮廓采样不等于全像素或连续碰撞证明。
- 摘取沿用既有所有权交接：手先到叶基、枝叶随初拉、分离后叶随手而枝回位；接触点重合不证明完整撕裂或植物力学。原创建模/编码抽帧支持这条有限行动链，但后腿收拢仍夸张，支撑标记不证明重心平衡；不是通用或物理步态。样片无音轨，原片并非无音轨；两者均未常速观看、未听审，不据此认可喜剧节奏、情绪或受众理解。

导演按“环境解法、支撑交接、最小可达距离”进入本补充，回到当次构图检查道具预示、视线与行动顺序，再把支撑/摆动及取物交接落实到输出。这里只限定既有方法的失效条件，不新增机制、配方或已接受作品；入口可找到也不等于已被实际采用。

### 流动形态先排除画域和周期纹理的干扰

参考 Pavel Dobryakov 的 [WebGL Fluid Simulation](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation) 官方截图：高亮色团、卷边和暗留白。仅观察静图，未运行其 WebGL 或听声音；MIT 源码许可不被当作所有截图/媒体的独立分发授权，方法不携带上游资产。

- 合成双通道平流可以保持颜色身份，但规则条纹和两个等形主涡容易读成旋转标志，而非丰富的流动。有限修订用固定种子的非周期多尺度纹理、不等强移动涡减弱规律；仍宽软、有限，并未达到源图细丝层次，不能推广为高质量湍流配方。
- 矩形计算域不该无意成为主视觉边界。将初态与画幅边留出余量，显示层用宽缓渐隐；同时看上下收口及最终编码，最外框等于背景只排除该圈像素跳变，不能证明内部没有裁切感。显示遮罩与数值边界条件分开，不能借前者声称解决后者。
- 染料递推与光晕显示分开检验；通道重叠比例不等于感知混色、真实混合或守恒。预设流场、衰减和采样的研究不得称 Navier–Stokes、真实流体或常速艺术验收。

### 跨景行动保留目的，落脚不靠拉长肢体

参考 Blender Studio [Coffee Run](https://studio.blender.org/projects/coffee-run/) 的横向行进局部抽帧；[许可页](https://studio.blender.org/projects/coffee-run/pages/licensing/)标 CC BY 4.0 并有标识/外部材料例外。原作可见跨空间行进，不据此断言它采用了新稿的前景柱遮挡；音乐署名也不是听审。

- 先给持续携带的物件或目的线索，再改变场景。轮子/踏板相位沿用连续行程而非场景局部时间；遮挡物和换景裁边取同一边界。全遮挡只维持一个采样帧时不得叫长停留；改速度或柱宽后须看实际相邻帧与常速表现。
- 到达前让行程及其速度一起减缓，再安排脚底接地。固定膝盖、只把脚移到地面可能拉长小腿；二维两段定长求解需检查可达距离、同一膝分支、髋部/躯干衔接、全过程长度及鞋底，不只看最终接地点。有限模型不证明人体力学。
- 目的地应有空间依据，保留后续识别和读时；停在门外不等于交付、进入或完成往返。旁边建筑可后退到不同地面层次，不为对齐而强迫所有物件共面。

### 品牌部件不应伪装未接通的能力

参考 [Poolsuite](https://poolsuite.net/) 官方宣传裁图中的奶油色面板、粗轮廓、像素式控制和扬声器格栅；仅有裁图，不是完整播放器体验，未确认其媒体开放复用许可。原创黄昏设备只迁移控制部件也承载品牌情绪的原则，不复制照片、标识或代码。

- 主画面与按钮、字级、边线和材料需共用品牌语气；但拟物旋钮越像可操作物，未实现能力越需就近明示。禁用外观与简短说明共同指向播放和音量，不依靠远处页脚免责；合并重复说明而不删掉真实限制。
- 场景名应有图形依据：盐地不能只把丘陵换个名称，浅色水平带和山脊应能区分；改成浅地面后同步复查标题字色。这里是有限静态概念，不证明真实地点、录音或声景。
- 选择状态统一驱动标题、编号、说明和唯一标记，沿用既有状态合同，不另注册播放器机制。静态两图和变化区域测试不证明点击、旋钮、响应式、键盘或可访问性；未连接状态不提供播放时间或声学读数。

### 文字先腾出自己的区域，再交给下一句

参考 El Lissitzky 的 [For the Voice，Cleveland Museum of Art 藏品 2002.60](https://www.clevelandart.org/art/2002.60) 完整封面：大字、交叉读向与几何形。馆方明确标有版权，不因年代推定公版；页面描述的阶梯索引不等于已经实看内页，更未听过诗歌表演。

- 原创字形动作可直接兑现词义：中心短语分成两个锚点，让后来句子进入原先被字占据的区域。须保留字形身份、墨迹边界与可读词组，不能以无关飞散代替语义动作；最终静帧的读序也不一定等于完整序列的理解。
- 新句在区域清空、原字稳定后才出现。计算全不透明到结束的阅读窗，不把淡入开始算成全部读时；几秒短句停留是作者选择，不是受众阅读测试。
- 零透明内容应跳过绘制或真正透明合成，不能用背景色覆写旧字来假装隐藏。逐帧墨迹碰撞及开场与纯文字对照可暴露错误，但有限拉丁字形测试不构成通用排版、连字或多语言塑形能力。

这些修订分别经过静态/编码抽帧与有界模型检查，未据此完成常速节奏、受众理解或用户审美接受；其中合成事件音仅作结构检查，其他无声稿也没有听审证据。UI 导演按品牌与状态问题阅读，Motion 导演按动作、持续身份和留读问题阅读；实际采用仍须回到本次内容及输出核验，不把找到入口等同真实复用。

## 共同空间：合框、让路与用途改变

本节复用既有身份、投影、接触交接和延迟读时，只补有限研究中改变导演决定的条件，不创建作品、通用合成器、碰撞系统或新族。下列源片只做局部/概览抽帧，未常速观看或实际听审；原创样片全部无音轨，源片有声。源画面观察与原创行动分别陈述，公开方法不携带源素材、私有成片或制作代码。

### 合框前，先让两个视图同意一个物件空间

[Glass Half，Blender Foundation](https://video.blender.org/w/64222c8a-c4c7-4b3b-9850-7fb2078edcf6) 局部抽帧可见两人分配不同画框、第三人居中、随后多窗增殖；只支持框与视点的构图联系，不证明未听对白或具体转场节奏。[项目许可页](https://studio.blender.org/projects/glass-half/pages/licensing/)写 CC BY 3.0，实际片尾卡写 CC BY 4.0，版本冲突保留，不能默默合并为所有资产的许可。

- 原创树木研究让两个画框分别持有根与冠的局部视图；两次绘制共用同一物件模型，各自变换先收敛到同一投影，再消去分隔。保留短暂“已对齐但仍有框”的状态，使合并有空间依据，而非两张近似图片交叉淡化。
- 核接缝之外的完整物件：对齐正确但根端仍被边界裁掉，不能叫完整揭示。初始标签描述实际局部，不把根部/冠部误称不同相机方向。此例支持有限的局部到整体关系，不证明真实争论获得和解、多相机合成或观众已理解隐喻。

### 同一投影可以解释尺度，但不能替未发生的遮挡作证

[HERO – Blender Grease Pencil Showcase](https://video.blender.org/videos/watch/3eb93cab-79a2-4fd5-a636-d42e5c59ddea)，Daniel Martinez Lara：已看小物件与手/机械圆形结构、前景人物与远景群体及石腔/大环境的局部抽帧。官方视频字段为 Attribution 但版本未核；项目/新闻页访问受限后停止，未推定资产可分发。

- 原创纸拱通行让固定视点的地面、拱门、物件中心和显示半径共用透视，接近相机造成显大，不把它说成拉远揭示。前向圆片近似球体时，标明接地等式的构造边界，不声称精确透视球体、物理滚动或 Grease Pencil 工作流。
- 物件一直从开口中心通过，未靠近支柱，就只能证明经过开放空间；存在深度排序代码不等于验证了支柱遮挡。后续真需遮挡时须设计实际边缘交叉和邻帧对照，不为补覆盖而给已有画面强加消失。几何示意也不自动拥有原片的有机线条、情绪表演或任务完成叙事。

### 暂时让路，须给等待者和通过者不同的落脚空间

[Spring，Blender Open Movie](https://video.blender.org/videos/watch/3d95fb3d-c866-42c8-9db1-fe82f48ccb95)，Andy Goralczyk：源局部显示旅行者与重复垂挂植物，但关键手部被头身遮住，未证明触碰、施力或回弹因果。官方视频字段为 Attribution–ShareAlike、无版本；[项目 About](https://studio.blender.org/projects/spring/pages/about/)官方搜索摘录写 CC BY 4.0，摘录不等于完整页面审核，差异不能消去或推广到音乐。

- 原创帮助动作是抬起同一枝尖、保持通路、等同伴清空后放回；固定根与共同曲线上的叶片保持结构身份，区别于摘取、摧毁或永久清障。手尖绑定与定长手臂沿用既有合同；这里的植物形变是作者设定，非弹性求解。
- 仅把通过者画在前面，不足以解释两身体占同一地面脚印。明确近处通道和不同脚底平面，再核双方身体、持物手臂、眼睛和触角，而非只核枝条净空。改变通道高度后须重查低枝确实阻挡、抬起后确实可过；分层脚位只支持可见景深，不是完整三维碰撞或步态证明。

### 用途改变要靠新关系，不能补写旧功能

[Charge，Blender Foundation](https://video.blender.org/w/04da454b-9893-4184-98f3-248d00625efe) 抽帧显示工厂冲突后转入暖室、较小机械同伴、胸前亮物件及手部接触；无法从稀疏画面确定全部能源传递、线路或对白。视频字段 Unknown，实际片尾卡写 CC BY 4.0；片尾是该声明证据，不自动涵盖标识和所有外部素材。

- 原创带刻痕的环从挂架到手再到绳，同一鸟随后进入；由储存物变成共同停留/玩耍的物件可读，但此前没画工作用途，就不能称牺牲有用工具或完成能量救援。保留身份、空挂架与新接触关系，不用环境一起变暖冒充用途变化；示意绳环重合也不是绑结操作。
- 分开初始站立、腾空、落入物件与之后摆动。末端坐稳测试不覆盖起始脚悬空；脚线含描边的底部应对实际局部坡面，地面影子不能随鸟身体一起飞。修起跳高度时保持落点，重新看出发前、起跳、途中和落入；不以单个参考点相等宣称每个脚趾对旋转环都精确接触。

### 入口要真的可通过，关闭后仍须检查含义

[SINGULARITY – Painterly Space Adventure](https://video.blender.org/videos/watch/1ba07bbb-1456-4293-99a6-833fa450eda0) 局部抽帧显示暖色小个体与蓝绿群体聚集成方向性整体；没有直接证明新稿的开口、进入、闭合行动。视频字段 Attribution–ShareAlike 与实际片尾 CC BY 4.0 有差异，不能替未来资产分发裁定许可版本。

- 原创群体环先打开入口并停留，再让新成员进中心，最后恢复群体轮廓。入口来自实际形状和变换，不以中心线/外接圆代替通行证据；用同一轨迹穿过“未打开”的形状作反例，避免把本来就可通过的装饰动作当成必要帮助。
- 有限输出时刻可重绘不透明形状遮罩检查相交；说明阈值、阴影排除和抽样范围，不冒称编码像素检测、连续时间或物理碰撞。独立进程/分批运行解决图像内存问题不能改变阈值来消除失败。
- 空间容纳可读，不等于情绪唯一。形状相似、没有视线/姿态时，闭环也可能读成保护或禁闭；标题偏向“欢迎”不证明观众同意。保留其他成员身份与材质坐标，不靠增加粒子或光晕掩盖含义歧义。

## 品牌身份：改变表达，不偷换对象

以下补充既有固定片块、落定留读、材质表面和跨景身份的适用条件，不新增作品、积木族、字体或材质引擎。参考仅实看概览/局部抽帧；五项原创均为静音样片，未常速观看、未听审，有限独审不等于完整品牌、受众或审美接受。公开页面可播放不等于开放素材许可；下列商业参考未见开放媒体授权，不携带其画面、标识、字体、代码或声音。

### 扰乱字内结构后，回到同一份标准字样

[COLLINS Freeform](https://wearecollins.com/case-studies/freeform/) 抽帧可见明亮词语、局部字形扰动与真人影像；未证明其形变算法。原创采用栅格字样的互斥斜切片块，与整字腾空、固定瓦片聚合去重：增量是字内覆盖的完整分割和精确重建，而不是字体插值。

- 保留未经修改的标准字样；分割遮罩须无重叠且穷尽源覆盖，临时变换结束后精确回到原像素，再出现解释文字。检查旋转边界、反序求帧及零透明覆盖无操作；数值已落定不意味着观众看到了突然恢复。
- 初态已部分可认，就称结构扰乱后回正，不称从无意义抽象发现隐藏词。斜切栅格不等于有机字形或原作影像/情感关系。全不透明窗只量时间，不测阅读理解；源片有音轨但未听。

### 模块先成为首字，再让其他字进入

[BUCK Comfy Brand Refresh](https://www.buck.co/work/comfy-brand-refresh) 局部抽帧显示立体模块到平面首字附近的离散交接，不能断言所有模块连续变成所有字。所观察短视频无音轨，不推广为完整项目无声。原创用同两块正面归位成首字，其余字是另行进入的新形状。

- 沿用固定身份与片块署名；新增检查是首字最终正面遮罩与后续词中首字精确一致，不能终点换成近似字体。原生遮罩相等与有损编码误差分开，不把两孤立盒的平均深度排序说成通用三维交叠求解。
- 首字刚完成就拼全词，会挤掉识别机会。有限修订先关闭模块间距，给完全平面的首字独立停留，再逐字进入，并缩短/放大支持句；原生连续样本一致只证明保持区间，不证明节奏或移动端阅读已经改善。

### 持续身份还须在拥挤中段看得见

[NotReal / Vizio](https://notreal.tv/project/vizio) 选段以重复球体和空间重叠组织画面；[NotReal / Microsoft 365 AppStore Video](https://notreal.tv/project/ms-harmony) 选段以宽带向紧凑品牌构图收束。仅继承重复单元与形态收束关系，不复制球体图像、带形、图标或品牌；选段抽帧不等于完整案例或常速观看。

- 稳定ID、顶点数和连续路径只证明实现身份，拥挤中段仍可能融合成不可追踪的色块。除首尾外，针对交叉/收束窗口加密检查当前编码；重复单元可保持家族语言而不保证逐个跟踪，最终形态最好在解释文案前先可辨认。
- 临时拉开间距或调整目标侧序可改善可见分离，但若两者一起改变，只能把改善归于联合修订。单带与合成图的颜色容差匹配是近似栅格诊断，不是精确可见表面积或人类识别分；深度缓冲解决显示遮挡，不阻止几何相交。
- 平面路径的XY消费不把另写的深度/旋转变成三维路径API。画家排序的折面与有深度缓冲的零厚度曲面也不可混称物理纸张、布料或PBR。沿既有路径和身份规则处理，不新增同义积木；未常速、未听审，不授予完整艺术接受。

### 跨材质保留同一条线，而非只更换底色

[BUCK Rebrand](https://buck.co/work/buck-rebrand) 局部实看印刷、圆盘浮雕及卡片矩阵，支持应用比较，不证明制造过程。源片有声且有音频署名，均不是听审。已有材质法线、织物/缝线与品牌构图不重新登记；有限增量是让墨线覆盖、负高度场和针迹真正消费同一中心线，并保留中心、尺度和环路布局。

- 材质差异应落在线条响应上：墨色覆盖、随光变化的凹刻近似与离散针迹，而非三块不同底色。逐项核共享输入、光变化范围和最终针迹显现；负高度与像素变化不证明所有观众都读为凹面。
- 标本交叉淡化不是材料连续变形。曲线参数等间距不等于弧长等距或均匀制造针脚；规则织格、柔弱正面浮雕仍需实际大小与常速复核。二维半材质示意不等于真实纤维、物理反射或原作质感。

### 材料分片可追踪，不等于环保结果已成立

[BUCK / IBM Sustainability](https://buck.co/work/ibm-sustainability) 已看策略说明片局部及另一圆点动片的部分样本：微行动/宏结果是源品牌主张，点群变化不是因果或环保效益证明。前者有声未听，后者所选视频无音轨。原创改用单张矩形纸的分片提案，不复述泛绿或既有圆点传播。

- 一份分割模型保留每片身份、固定尺寸及总几何面积；先让大块离开，再水平腾清、最后纵向分离。曾同时斜移导致相交，须改路径而非放宽断言；标签在全部落定后出现。与既有所有权/延迟读时去重，只补分片来源与实际不相交顺序。
- 分清物理片数与用途类别；封面和多条植物名签不是每片各有一种新用途。标签只说明提议，没有装订或安装画面就不称真实二次使用。理想矩形面积不含切缝、厚度、耐候、印刷影响，更不证明零废料、减碳或净环境收益。全不透明帧数不得命名为“可读帧数”。

### 固定视觉锚点，靠周围线索改变它的角色

[BUCK Headspace](https://buck.co/work/headspace) 局部可见不同位置、尺度及场景中的圆形；不能说源片始终保留同一屏幕锚点。音乐署名、峰值和 RMS 不等于听过。原创固定圆片位置、半径和颜色，在暴露的硬切中替换唱片沟纹、沙丘天空、字标，让它分别读作标签、太阳及字标旁的品牌组合。

- 这沿用形状匹配剪辑，不新造机制；条件是只改变角色解释所需的周边，锚点由同一绘制函数保留。不称连续世界、物理变形、遮挡换景或缩放揭示；裸圆旁有品牌名也不证明独立标识被识别。
- 原生内部像素相等不足以验证完整轮廓。有限编码检查可在特定配色阈值下核每帧色罩、质心与重叠，并用刻意移位反例检验敏感性；须保留阈值和有限背景范围，不推广为感知连续性或任意背景检测。景观字幕应避开地形边缘，阴影不随不相关装饰旋转。

导演按“字内重建、首字归位、同线异材、分片用途、定锚换境”进入这些条件，再读既有机制合同并对本次实际输出复验。模型/原生图/编码抽帧分别支持相应关系；条件入口和字面检索不是调用率、跨项目有效性或已完成声音验收的证据。

## 载体与场：让共同依据决定可见变化

本节将既有颜色归纳、载体文字、环境呼应、遮挡与相位延迟收紧为导演条件，不登记新作品、积木或引擎。参考与原创只完成抽帧、有限模型和局部独审；静音原创未常速观看、未听审、未做受众阅读验收。观察到的外观不证明参考作者采用某算法，完整解码也不证明节奏成立。

### 从场景取得颜色记忆，而非换成相似渐变

[COLLINS Bose](https://wearecollins.com/case-studies/bose/) 局部画面由实景转向水平条纹与品牌尾段；不能据此推断行均值或光学快门。原创场景可先建立可辨的地形，再把其逐行颜色统计转为背景，最后安排标题。与字形切片、整字腾空和同线异材去重：这里追踪图像属性的来源，不追踪字块或材质中心线。

- 测试实际标题前图像是否等于独立计算的源行颜色及明确色调处理，不只断言控制参数到终点。水平滤波若使用循环边界，会把另一侧内容卷回边缘；不需要首尾拼接时可延拓边缘，并用两侧脉冲反例复查。
- 颜色来源连续不代表亮度原样保存。为了文字对比而压暗中央须披露；变换、压暗、标题出现若有重叠，应写为交叠时间窗，不能说三阶段依次完成。宽柔色带不是高密度速度条纹，也不是光学运动、独特品牌识别或完整身份系统。

### 车身承载文字，通行行为分配读窗

[COLLINS Robinhood](https://wearecollins.com/case-studies/robinhood/) 列车段可见对向通行、车身字带及城市纵深。关系不是整幅城市视差：文字与车体同时进入、缩小并被环境遮挡。原创可让近车快速通过、后车慢行，先后交出焦点；快车不自动享有后车的阅读停留。

- 车窗、字带、轮子共用同一变换；沿斜轨只平移水平车体，会让一侧轮子脱轨。示意性剪切可使轮缘方向与轨道一致，但不是刚体旋转、标定透视或物理接触认证。
- 建筑要真正覆盖车顶、窗与轮子。只挡车下半部或把车夹在画幅边缘，不等于建筑完整遮挡离场。可按实际透明覆盖、变换和建筑多边形检查末段全部状态，再实看编码尾帧，不能只看中心点已入遮挡区。
- 低速窗口只提供阅读机会；位置连续但速度接段不连续时，抽帧不能判定是否突兀。每句从完整显现后分别核读时，常速阅读和小屏字级另验。

### 屏内外形态呼应，不冒称共享几何

[COLLINS Mailchimp](https://wearecollins.com/case-studies/mailchimp/) 的环境与屏幕关系已有研究记录，后续视频采样属于**旧来源动态补证，不计新来源**。有限索引零命中不能推翻同页历史正文正命中。环境植物/鸟类与屏内生命体支持同语义、异质媒介的解释，不证明团队意图。

- 可让实体器物与屏内变化使用相近色彩和曲线词汇，产品文字及交互标记保持静定，变化限制在独立区域。这是形态呼应，不是同一几何输入、相同纹样或屏内外真实交互；与前节同线异材须明确区分。
- 嵌套开弧闭成圆环后可能更像靶环，与器物平行刻槽的关系减弱；不能只凭开场相似宣称整段一致。全平面绘制不等于复现照片环境与平整界面的物质反差。
- 参数达到闭合只证明闭弧，不证明视频无缝循环；保守图形边界不等于像素级无交叠或可读性。主标题清晰不替小导航、按钮和页脚通过小屏阅读。

### 同一遮挡，两个接收位置出现不同结果

[NASA SVS Solar Eclipse Animation Elements](https://svs.gsfc.nasa.gov/5093/) 抽样可见光源、遮挡体、接收球与阴影边界；原创可改为平面源线、薄挡板和两个固定接收位置。它补充单层覆盖的上游依据：位置相关的源线可见比例先算出，才映射成场、接收条和数值，而不是分别动画一个暗块和百分比。

- 一份遮挡几何同时驱动场和读数，沿源线回投挡板端点、求区间交集，再除以源线长度。用独立高密度射线采样检验多时间、多位置，包括随机场点、全遮/无遮及反射对称；结论在差异已出现后再进入。
- 准确范围仅为二维均匀源线长度的可见比例，不是太阳圆盘、角面积、照度、能量、衍射或食相预测。画出的挡板厚度可只是符号；颜色是设计映射，不能称量测亮度。绘图区裁切的射线不是物理终点。
- 两接收位置和读数说明同一原因的不同局部结果，不保证观众已理解；细射线、局部被圆形标记挡住和裁切场域仍可能削弱解释。NASA媒体使用须按[官方政策](https://www.nasa.gov/nasa-brand-center/images-and-media/)核署名、第三方例外与标识限制，不把项目名称当背书或所有资产无条件开放。

### 固定成员执行同一动作，延迟形成群体波峰

[COLLINS Muse Group](https://wearecollins.com/case-studies/musegroup/) 的片状场局部可见扇开、侧向变薄与再次展开；相同页面的字体构造片与字内重建重合，不为多收来源再重复登记。原创可让独立矩形按固定横向次序依次执行同一抬升/旋转，形成一次穿行的波峰。

- 固定成员不等于中心静止：横向位置/身份固定，竖向中心仍移动。分别检查成员数与次序、三维边长、多个局部相位的邻成员延迟关系；斜投影后屏幕长度改变不违反三维刚性。
- 与标量输运、瓦片选择、字形重构区分：这是解析姿态，没有场数据传输、模拟历史、相互作用力或文字拼回。通用错峰和缓动不是新技术；看起来像均衡器也不表示声音驱动。
- 同初末几何与尾部静定不等于持续无缝运动。固定视图的排序和图形明暗不推广成任意相机深度解算或物理材质。时间输入检查应显式排除布尔值，不能由其整数子类身份误收。

冷启动按“行色记忆、载体读窗、环境呼应、源线可见、成员相位”选择关系，再读既有合同并验证本次输出。有限独审支持这些受限条件，不提升完整艺术、物理、可访问性或声音验收；商业参考未建立开放媒体许可。这里只保留去素材化方法与公共来源链接，不携带参考媒体、原创私有成片、生产源码或评审记录。

## 状态与叙事：让变化兑现具体关系

以下沿用现有时间坐标、共享投影、身份桥接和接触约束，新增的是适用条件与反例，不登记新积木、真实产品或已接受作品。参考与原创只经过局部抽帧、有限数据检查和独审；原创静音，未常速观看、未听审，不能把模型一致或静帧清楚写成完整节奏、交互或受众验收。

### 移动序列位置，不偷换所选来源

[Kdenlive 编辑手册](https://docs.kdenlive.org/en/cutting_and_assembling/editing.html) 的 Remove Space 动图显示空隙右侧的成对片段向左靠拢；只是局部操作参考，不是整套编辑器验证。原创说明可让关联轨道消费同一片段记录，后续片段一起移位而上游保持不动。

- 所选来源时间应由片段ID、source-in和局部offset派生，序列游标由该片段当前放置位置加offset派生。仅在默认例里让固定数字相等不算真实绑定；改source-in、片段起点及所选ID，确认状态、标签与预览选择真正跟随。
- 分开验证时长不变、下游邻接、空隙与总终点变化、关联轨道共用坐标。相同预览裁图只证明画面保持；若预览是每片段的一张原创插画，就不能称按来源时间解码、视频寻帧或真实播放。
- 固定片段/插画映射不推广成任意元数据编辑器；项目栏和片段缩略图仍可能依赖位置列表。闭隙过程的插值是解释性布局过渡，不是NLE逐渐修改时间的操作实录；“关联声音占位”不含音频、波形或声画同步证据。参考许可按手册实际声明保留，不由方法研究转授所有素材。

### 隔线成为隔墙后，先开放再证明可以通过

[BUCK Get an Airbnb](https://buck.co/work/get-an-airbnb) 抽样可见视频格子、分隔房间及持续人物身份周围的环境重构。原创可从同一个俯视世界转向斜视，让已有高度变得可见；不是墙物理长出，也不同于把两个独立视图合成共同投影。

- 保留地板、隔墙和物件的同一世界坐标与身份，先让隔墙归零并停留，再允许物件跨越旧边界。用物件足迹与有限墙体的实际相交关系检验全部移动状态，并在同样位置保留闭墙高度作正交叠反例；只看墙消失不能证明空间可用。
- 最终物件应完整容纳且彼此留隙，旧地板缝可保留为历史痕迹。永久撤去内部隔墙、让已有物件聚集，与临时开门接纳新物件去重；共同平面和顺序纪律仍是既有做法。
- 统一仿射投影不等于标定相机或物理透视。按地板、墙、影子、主体分层的场景专用排序，在当前路线可用，换视点或靠墙可能失效。滑动不是滚动，画出的接触影不证明重量或物理接地；聚集也不证明实际协作完成。

### 从叙事身份进入界面，不把故事说成产品记录

[BUCK Asana Silos](https://buck.co/work/asana-silos) 局部可见工作区覆盖叙事环境，再进入产品页面；不支持“筒仓真的变成任务卡”。同品牌另一支作品是关联来源，不因品牌同名就当同片重复，也不把有限索引未命中当成全档去重。

- 原创可让角色颜色、脸与职责标签保留，把原平台解释为卡片、角色解释为负责人，再补交接箭头。先共处、再出现依赖关系，比单纯换成UI背景多一层关联；共享背景展开中尚未容纳所有卡片时，不称已经完整合框。
- 数值缓动不代表可见事件渐变。文案由阈值一次显现、完成勾同步硬显、结语另一个阈值切入时，逐帧枚举真实首次出现，不能写成逐项完成或整个时间段渐入。
- 虚构界面应明确标示概念片/非产品录屏，但声明不等于功能正确。箭头与勾号只表达编排；若状态字仍保留ready、没有可见共同交付物，就不能称严谨状态机或完整协作因果闭环。短结语、细小浅色标签仍需常速和小屏复核，不把主张句当作工作成果证据。

以 [NotReal / ServiceNow](https://notreal.tv/project/servicenow) 选段的工作环境与屏内任务为对照时，环境道具只交代语境，任务变化须在屏幕里可见。原创可让同一图案从修订界面延续到桌面纸样，但屏幕文字内移幅度较小时，状态字可能承担主要解释；不能仅凭坐标变化宣称观众已看懂。预编排修订和纸样显现不是实际输入、打印、AI能力或效率证明，像素距离不能冒充印刷尺寸。

### 同页滚动让章节提示消费实际位置

[NotReal / Microsoft Edge](https://notreal.tv/project/microsoft-edge) 选段显示稳定外框与不同食谱章节；局部截图不证明DOM、粘性侧栏或真实输入。编辑层级和滚动本身沿用既有方法，不新登记机制。

- 分别测量完整文字墨迹已露出、遮罩填满画布、作者指定稳定阶段三个时刻；阶段标签不是首个满遮罩像素。在边界前后检实际遮罩与最终图像，不能用一个保守阶段开始时间冒充最早可见时间。
- 完整墨迹曝光也不等于移动边界旁已经舒服可读。短功能词和标点停顿须另做常速阅读检查，最终重述不自动提高理解或无障碍；无声音时只称编辑节奏，不称音乐同步。

### 少到多的点，留下可追溯的来处

[BUCK Illumina](https://buck.co/work/illumina) 局部近景亮团缩为单点、再出现多点，支持面积与数量反差，不能由抽样反推材料、生物或流体机制。原创可用明确父子关系派生端点并保留旧路径，让少到多具有可读来源。

- 模型有两个子实例而初始同位重叠，不代表此刻观者已看到两个。对选定原生图亮核作阈值/质心补证，比只数列表强，但仅适用当前配色与样本，不是全编码分割或受众计数证明。

- 最终句子出现时间与整幅构图停止时间分别记录；细暗历史路径在小屏可能消失，亮终点可数不代表来路易追。微小重构留白不夸称揭露新空间。

### 弯带吸引目光，文字平面保住读窗

[BUCK NIKS](https://buck.co/work/niks) 的局部多色弯带与压缩弯曲文字形成注意力中心；它不是Nike，平面片段也不足以认证完整环幕、双消失点或相机穿行。原创可让有不透明底的文字面与周围色场协调收敛，最后回到平直、静定的读窗。

- 若字与底已经在同一位图中，再经同一逆映射采样，可说牌面与文字共享二维变形；独立极坐标背景没有因此共享世界表面、透视相机或几何。构图对齐不等于共同三维空间，正分母也不证明任意域可逆。

从“微缩通行、细节单位、整句恢复、分支来路、弯带读窗”定位上述条件，再检查本次素材与最终输出。公共方法不附私人源片、原创成片、截图、代码、哈希或评审报告；公共案例可观看不授予品牌、字体、图像或声音复用权。

## 材质与时序：先隔离变量再判断表达

本节沿用既有材质对照、共同投影、相位延迟与约束释放，只补真实制作及独审发现的选择条件，不新增积木、渲染器、配方或已接受作品。参考仅有限概览/局部抽帧，未常速观看、未听审；原创练习全部静音，亦未完成常速与听审。抽帧可读、几何一致及完整解码不等于参考级制作、审美通过或总体利用率提高。以下将源片所见与原创选择分开，固定参数只用于隔离问题，不作为通用艺术配方。

### 固定灯位改变亮度，不冒称移动灯光或相机

[Panoply NBA Finals](https://panoply.co.uk/cases/nba-finals) 的抽样可见暗场金属浮雕、边缘照明、近景细节与后来可读的标识；不足以恢复整片镜头或灯光路径。原创可用独立构造的浮雕物件，先让材质层次成立，再从局部裁切回到整体。

- 在几何、相机和材质不变时，将不同固定灯位的线性光照结果按非负强度混合，并在混合后统一tone mapping与输出编码；不要混合已显示变换的图片却称物理光照相加。此策略不能产生新视角、光源移动或新的遮挡，固定图像裁切拉远没有三维视差。
- 分别看主字、边框、底面与背景反射。过粗微纹理可能把深色釉面读成皮革/塑料；微型凸字在远景只能作细节，不能承担关键信息。正向挤出的字称浮起或凸字，不称凹刻。几何真实也不能自动认证材质真实。
- 对照固定几何下的灯强变化；换材质、改曝光和换相机若同时发生，就不能把改善单独归给灯光。预览与最终合成使用不同显示变换须明示并看最终编码，不拿预览替成片验收。

### 重复镜头配方，不等于跨场连续旅行

[Panoply Fios On Demand](https://panoply.co.uk/cases/fios-on-demand) 的来源说明与抽样支持不同环境中共享镜头/尺度关系、文字落在场景里的研究方向；不据此断言已复现全片切换。原创可让各场采用相同局部拉远曲线和字高，但硬切由远景重置到近景就是独立镜头，不是连续后退或尺度匹配的交接。

- 先分清世界字高、屏幕投影字高与感知突出程度。相同相机曲线和字高不保证字后环境同样干净；高亮书脊等结构会与字形竞争。将干扰物移向两侧后，检查整个运动区间的投影间距，再看最终编码，而非只检查落版。
- 前景门框、文字支撑与后景分层能建立有限视差；平面图层及叠层字形仍是2.5D布景，不是闭合挤出字网格、全局光照或通用遮挡求解。若目标是连续穿行，须另做切口邻帧与锚点交接，不能沿用“每场曲线一致”作为证据。

### 延迟倒影只改变一条因果关系

[Panoply DEREALISATION](https://panoply.co.uk/cases/derealisation) 的页面描述与抽样提供熟悉环境中的异常行为方向，不证明源片使用杯子倒影延迟。原创可让主体正常移动、投影立即跟随，仅令插画倒影读取较早的同一运动状态，其他道具保持不动；这是独立的时间矛盾，不是源片算法复原。

- 保留建立正常关系、产生偏差、主体停下但倒影继续、恢复同步的阶段。延迟以时间定义，再检查采样帧；非整数帧延迟与可见起动帧差不必相等，不能把舍入差诊断成失同步。
- 固定道具要检查实际画面区域，不只读常量；倒影缺少桌面和环境会显得悬浮，应明确插画镜面而非光学反射。收尾文字还要避开镜框等既有强边界，稳定背景不是天然空白区。数值追赶成功不证明常速下的惊奇、幽默或不安，也不作心理/医疗解释；无音乐时不把叙事“节拍”称为音乐同步。

### 暗面辨形先守住拓扑，再谈金属质感

[NotReal The One Club](https://notreal.tv/project/the-one-club) 的有限片段可见尖角金色形体、宽光带与稳定构图；不能扩写为已审整案或已听其声音。原创可用另一闭合网格及反射方向模型检验旋转时的切面，但轮廓旋转、深度正确和材质可信是不同问题。

- 暗面与背景融为一体会令闭合形体看似断裂。冻结网格、相机与旋转，单独提高环境暗部或有限掠射补光，再比较原问题角度及新角度；这种艺术补光可能让面更灰、更像板材，不能同时宣称金属真实度提高。
- 超采样可以减少轮廓阶梯，不改变网格拓扑，也不是运动模糊。检查面顺序反转后深度结果一致、原/新几何未换；同条件平涂消融帮助判断光照贡献，不靠“有高光”证明金属。
- 真实三维网格与透视插值不等于PBR、粗糙度卷积、相互反射或能量守恒；静止椭圆影不是接触阴影。局部暗面修复仅覆盖已复验的问题，不把原先不够成熟的整体材质评价一并改为通过。

### 延后释放保持同一压缩态，让等待成为唯一变量

[Panoply TIDE](https://panoply.co.uk/cases/tide) 的说明讨论约束与释放，局部抽样可见固定双侧结构及变化的中央开口；原作声音耦合只属于来源文字，未独立听到。原创可用轮廓场代替流体，固定压缩过程、完全压缩形状和释放曲线，只逐轮增加压缩后的等待。

- 将压缩时长、压缩态保持时长与释放时长分开，验证同相位形状一致、释放开始逐次推迟；这证明时序设计，不证明主观期待增强。周期长度相同也不代表各动作阶段等长。
- 参数原点固定不等于图形面积质心固定；中央开口须检查实际栅格或明确几何界，而非只检查一个中心常量。画面里的进度线和注释必须避开最大变形轮廓，终态留白不能排除压缩峰值处的近切线。
- 轮廓变形不是黏性模拟，开口保持不等于流体体积守恒。下移注释可修局部近接，但小字仍只是辅助标记；无声实验不能接管源片的声音、节奏或完整广告品质。

从“固定灯位、重复镜头、延迟倒影、暗面辨形、延后释放”按问题选择；已有制作恢复、证据绑定与权利规则不重复登记。混杂旧新帧或未完成编码须按[QA](../../skills/motion-film-director/references/qa.md#工程完成与可恢复)重建/隔离后再审，独审修订须进入最终编码而非仅存在于对照图。公共正文不附私有标题、源片、成片、截图、源码、哈希或评审报告。来源预览与页面所述交付时长不同就分别记录，不假定同一剪辑；Panoply的条款不能冒用为NotReal授权，公开观看也不转授品牌、字体、模型或声音重用权。

## 氛围与关系：让情绪先有可读的画面依据

本节复用层序、材质层级、接触、共同采样与状态对照，只保留有限原创练习及独审修订改变的决定，不新增积木、作品或情绪评分器。AOUD、Voxa只观察官方静帧与说明；其他来源仅有限视频抽帧，均未常速观看、未听审。原创包括一张静态imagegen概念图与四支静音二维示意，未验证常速、声音或受众感受；静态图没有动画验收可言。亲密、宁静、归属、悬念是创作意图，不因编码通过、文字宣告或抽样清楚而成为已证情绪效果，更不等于参考级美术。

### 近缘遮挡先交代物件放在哪里

[NotReal AOUD](https://notreal.tv/project/aoud) 的官方静帧支持有机皂体、粗细材质与周边柔化的观察；不能因悬置构图就推断源片漂浮、转动或运镜，也不把皂体误称香水。原创静物可借暖场和植物前景建立亲近的构图，但先让物件落位成立。

- 容器、内部物件、近侧口沿分层：物件先置于开口内，再绘近缘遮挡，局部接触影与器皿底部阴影分别处理。物件中心在容器bbox里仍可能盖住前壁，看似悬浮或贴在外侧；修尺寸、层序和接触线索后看实际编码，不用“是插画”免除放置关系。
- 前景虚化不宜成为抢眼的重复横条。有限修订中，叶长、角度、透明度与软硬差异减少了条纹读法；过度模糊或整体变淡未必保留植物身份。Gaussian blur只是图像柔化，不证明光学景深，扁平碗面与剪纸叶仍不能冒充参考材质工艺。
- 微弱光带和枝叶位移可以构成动态海报，不自动成为叙事表演；一段单向漂移不能叫周期摇摆。静帧来源只能启发独立运动选择，不能为新动画的时间曲线背书。

### 同色异织用轮廓和纹理频率分配层级

[NotReal Voxa](https://notreal.tv/project/voxa) 的官方静帧可见同色产品组、织物与较光滑基座/控制区的对比；页面中的产品页面图不是已运行的交互或可购买功能证据。声音/动画署名也不证明实际看过、听过；本地未提取到视频不能断言网站无视频。

- 原创可用同一色相家族连接不同抽象轮廓，以细织、中等条绒与粗编环分配触感主次；这是主动放大材料差异，不是来源材料规格。先看轮廓、孔洞和接触阴影，再看细纤维；同色不等于各物同亮度、同尺度或同视觉重量。
- 遮挡可以给层次，不必为了每个物件完整露出而摊平构图；但前景开口、后景识别部分与高物上方留白应仍可读。粗纹理与高轮廓共同加重一侧时，须评估整组平衡，不能把纹理丰富自动评为更好。
- imagegen生成的是一张概念栅格，不是已建模的三维场景、针脚拓扑或可制造缝线。静帧里的编织连续性与接触影不能证明另一视角、运动中变形或物理光照成立；若后续要动画，须另建一致几何/材料或明确位图动画边界。图像生成、来源输入与来源静帧分开记录，不假称摄影或实际产品。

### 接触后变形，身份线索随同一主体变化

[NotReal Fenty](https://notreal.tv/project/fenty) 的选定短片样本可见柔软形体夹住产品及随后更饱满的轮廓，不能反推软体求解器或体积守恒。原创可让侧垫接近时主体不压缩，接触后才变窄，释放后再变宽并点亮同一主体的开口。

- 共享宽度、间隙与位移能约束中心线接触；开口、接缝从主体当前尺寸计算，防止形变后脱离或暗中换成另一资产。接触先于压缩、释放先于亮起须分别核，不把同一时间轴上的变量称为碰撞力驱动或电路响应。
- 中心线零隙不保证全轮廓不穿透。沿接触剖面加密采样并保留数值容差，仍只支持所查帧/轮廓，不认证任意连续接触或真实压力。局部Gaussian凹陷和超椭圆形变是二维示意，不守恒三维体积；软垫大部平移、浅凹陷也不能称复杂材质变形。
- 持续开口可保持身份并提示灯光，但圆润外形与光晕不构成可用灯具规格。先兑现接触、释放、身份，再决定是否需要更丰富材料；简单解析阴影不能替代来源商业产品的立体质感。

### 共同到岸既要路径汇合，也要目的地属于岸

[Panoply / Column Studio Seattle Sounders](https://panoply.co.uk/cases/seattle-sounders) 的说明提供水与地方身份的方向，抽样同时大量呈现金属徽记和地标；不能把原创双路线到岸说成观察到的源片编排。若选水域与共同到达，须让新地理及灯光自己承担可读关系，不套用真实城市名称或徽记。

- 两路线汇于亮椭圆只证明共同节点，未必读作岸。把目的地连到岸线、接上干地小路，并让灯头与灯柱/底座分离，可加强“登陆处”的读法。宽泛光晕可能吞掉同色灯点；减泛光、保留各灯轮廓，比只加亮更有区分度。它不证明观众感到归属或真实人群已经到达。
- 路床与沿路光场若都被描述为水下，应消费同一采样坐标；一层扭曲另一层不变，会破坏对应。先超采样路径再缩小能减轻原生阶梯，但不等于整条折射流程高分辨率求解，位移后细边仍需看最终编码。
- 全画面位移和亮带若也影响沙岸、植被，就只是整体水感处理，不是水体/空气的物理分层。降低位移振幅参数不等于测得全局位移幅度，更不证明常速舒适或情绪平静；末段仍变化可表达“较静”而非“冻结”。艺术亮带不是焦散、Snell折射、流体或三维相机。

### 缺席残影靠稳定参照交代变化，不靠标题补故事

[Panoply American Horror Story](https://panoply.co.uk/cases/american-horror-story) 的页面描述与抽样提供缓慢显露、强烈明暗/色彩对比的研究方向，不足以恢复全片切点或听感。原创可用单次暗间隔移去物件，保留钩子、背板与故意不可能的影子，让相同位置的前后差异成为事件。

- 先分清完全藏住、若隐若现和逐渐可辨。固定雾纹只统一降低透明度，就称清晰化，不称中心向外清除、侵蚀或体积凝结；开场已经微露的形状不能再宣称完全未知的惊喜。
- 暗间隔前、期间和之后检查实际编码邻帧，核参照不跳位。空钩太小、影齿太糊会让残影读成第二件物品或污渍；适当强化钩子与收紧影边后需重看原生和缩小图，局部改善不保证所有屏幕。标签若暗示一对物件，会竞争“原物消失”的读法，应改标签语义而非只在报告里解释。
- 残影不随物件消失是作者设定的矛盾，不是正确光传输。单次短暗切不是频闪循环，也没有因此通过光敏安全、惊吓强度或悬念验收；静音示意不能替源片听感作证。

按“近缘遮挡、同色异织、接触后变形、共同到岸、缺席残影”进入上述限定条件。五项不全是影片，不用影片帧数给静态生成图计功；局部修订不提升原作品整体成熟度。沿用既有[QA](../../skills/motion-film-director/references/qa.md)绑定最终版本与证据；来源文本、静帧、视频样本和原创解释分开，时长矛盾不擅自合并。公共指南不携带私有图像、影片、生产源码、提示词、哈希或评审身份，也不转授来源品牌、材料、字体或声音权利。

## 品牌与载体：区分视觉呼应和实际共享关系

### 纸面隐喻可服务品牌画面，不冒充整理功能

[Seventeen Frontify](https://www.weareseventeen.com/project/frontify) 的静帧同时呈现平面品牌页面与立体工作流/图形元素，支持界面词汇转成触感画面的方向；不是已观察到页面变成立体的完整动效。原创可保留清晰标题列，将纸卡、折角与布带安排为另一组材质层级。

- 先保护标题、短句与主体的分离，借纸纹/织纹而非假控件小字建立质感。厚卡、布带和斜放底板容易读成高级文具或礼品布景，不是数字画布截图；空卡连在一起也不能兑现“把散乱想法整理成方向”的过程。

- 单张imagegen栅格只支持所见层叠。布带后段被遮住时，连续穿行是视觉推断，不能认证一条可制造的带或稳定可动画网格。生成记录、实际图像与来源输入分开，不把看似CGI写成已有三维资产。

### 多载体同标保留几何，布局按载体让位

[Seventeen OPN Festival](https://www.weareseventeen.com/project/opn-festival) 静帧可见厚重合并字标、明亮强调色及衣物/挂证应用；活动照片和屏幕亮色不证明印刷工艺或荧光颜料。原创可换用独立字形与配色，比较海报、角色证和衣物示意上的同一标记。

- 这与既有字内重建、材质换线去重：保持同一字形坐标、字距和等比缩放，允许深浅反相；辅助方向线和角色信息按各载体重排，不把一张海报机械缩小成所有物料。
- 可分别重绘整张载体，再将真实标记区域与共享生成器同尺寸输出比较；这比只说用了同一个函数更能确认实际消费。像素一致不等于所有观看距离可读，最小载体的字腔、斜边阶梯与次级文字仍要单独看。
- 平画衣物不证明胸前实际尺寸、布料拉伸、缝线或刺绣可行；RGB亮色不等于荧光油墨。一个矢量字标不是完整字体或响应式身份系统，虚构角色证不是已签发通行凭证；无日期/场地的海报也不是可执行活动信息。

### 跨面图场先保留房间，再判断图形是否连续

[Seventeen Hiroshige at Outernet](https://www.weareseventeen.com/project/hiroshige-outernet) 的有限静帧支持高墙/顶面大图场与小尺度观众的关系；近重复空间照片及书籍制作图不能当作多个独立机位。它们不提供投影标定、UV、精确拼缝或原作时序。

- 原创静态空间图可保留墙角、墙顶交界、深色地面、座椅和小人物，让巨大图形仍属于建筑，而不是无边界海报。生成的人物只是尺度线索，不是真实观众、测得尺寸或沉浸效果证据。
- 同色块跨面呼应不等于同一轮廓连续。分别沿墙到墙、墙到顶追踪上下边界；一个角看似衔接，不能替另一个角的分叉/断接作证。若生成要求“一条连续带”但只得到协调色场，应承认目标部分实现，不能把它说成源片本来就要求的机制。
- 真要落实连续图场，需要共同图形母版、各面映射及现场尺寸/视角验证；一张imagegen栅格不能交付这些。地面彩色反射不认证光传输，画面宽阔也不保证视线、舒适、无障碍或真实安装可行。

### 图形呼应不必伪装成从包装长出的世界

[Seventeen Coca-Cola Dreamworld](https://www.weareseventeen.com/project/coca-cola-dreamworld) 的静帧支持产品与奇异环境共享视觉语言，不支持已观察某条运镜、展开或变形。原创可以独立包装和周围形体呼应角度、折面与配色，但要区分样式相似、实际共享几何与连续转化。

- 封面符号与环境三角形若分别绘制，就称造型呼应，不能称符号变成地形或所有面消费同一网格。产品不打开、场景不从其内部出现时，结语里的“打开世界”仍是比喻，不是已演出的行为。
- 具有三维顶点、相机基和透视投影的插画不能笼统降为二维缩放；但有限画家排序、非封闭表面也不是完整三维生产或通用遮挡求解。固定底点只抬高峰点会改变边长，不是保持铰线/纸长的真实折叠。
- 中间高度可能读作独立切片而非折纸，近色条带的内部折面及伸出底座的接头尤其易歧义。看上升中的编码帧，先修明暗/连接关系，不用超采样冒充几何连接或投影阴影。主体可读与品牌世界有共同语气，不证明材料成熟或消费者响应。

### 经过后响应由同一位置决定各处局部时钟

[NotReal RingCentral AI Expression](https://notreal.tv/project/ring-central-ai) 的短样本可见重复透明感载体及局部暖亮区变化；不能由此推断一个发射点、原作因果公式或完整设计系统。原创可用持续移动的位置决定各固定载体的到达时刻，再让其局部响应先上升后衰减。

## 显露与延续：确认变化前后保留了什么

以下复用轨迹、身份属性、遮挡和表面变化，只补有限原创与独审改变的判断条件，不新增机制或作品。五项均为静音程序图形研究，来源有音轨但未听审，来源和原创均未常速观看。完整解码、抽帧、数值与消融可约束实现，不能代替节奏、美术、听感或参考级验收；样本中的材质外观也不证明来源求解器。

### 轨迹成标分清收束、替入和文字显现

[Panoply Amazon Original](https://panoply.co.uk/cases/amazon-original) 的短片抽样可见纵向光/材质分区、部分隐藏的字标和最终居中签名。可以提炼延迟可读性，但原创径向轨迹和椭圆是另行设计，不是恢复源片运动。

- 粒子端点落到环上，只证明位置对应。另绘环淡入、轨迹淡出是替入，不是粒子连续融合成实体；标题独立淡入也不是被光学结构揭示。文字若在收束结束前已出现，应记录交叠，不说严格先收束再出字。
- 细暗轨迹、大留白和泛光可以构成克制构图，但开场近空、小字缩小后消失、通用椭圆缺少识别性仍是具体风险。数值上的最终停留只提供阅读机会，不证明观众读完或感到情绪抵达。
- 超采样与Gaussian光晕只改善栅格边缘和图形光感，不是光学bloom、折射或体积光。延迟签名与既有揭示方法去重，新增判断是标记、运动轨迹和文字究竟共享几何还是仅在时间上接续。

### 同纹再框保留材料身份，不假称制造过程

[Panoply / Grey Canada Herradura Legend](https://panoply.co.uk/cases/legend) 的说明与抽帧支持焦木、明亮过渡、反光形态到包装的材质叙事；不足以证明无剪辑连续变形或木材变玻璃的物理过程。原创可让一个物体坐标纹理变暗后缩小，揭示始终存在的工具轮廓。

- 与既有跨材质保持属性的方法去重：核近景和产品视图消费同一UV标量，暗化完成与拉远开始分开。均匀缩放加横向重排是重新取景，不是形体变成另一个产品；参数框比例恒定也不保证带缺口、侧面的可见轮廓具有该比例。
- 规则纵线和梳状擦痕容易读成面板或条码；不均匀中断、弯曲和颗粒沉积可减弱这种误读。修订后仍可能像深色木条，类别仍依赖文案，不能把局部改善提升为真实炭材或完整美术通过。
- 独立绘制的粉末擦痕不是工具实际画出的结果，暖色扫带也不是燃烧、热传导或碳化。既要保留纹理身份，也要明确性能证据缺席，不能以“材料起源”隐喻代替制造或产品测试。

### 颗粒撤出揭示既有图像，不把遮挡当转化

[Panoply OPPO F7](https://panoply.co.uk/cases/f7) 的有限样本可见颗粒环境中露出的产品状表面，以及后来受屏幕边界约束的亮纹理；不证明颗粒变成电子材料或连续变形。原创可让有固定身份的颗粒离开中央，显露一直存在的图像。

- 每个颗粒的起点、终点、大小和颜色保持索引，只证明记录延续，不证明质量守恒或遮叠时每粒可见。初始遮挡有缝就不能称完全隐藏；末端颗粒围成装饰环也不是重力沉降。
- 去掉颗粒层，比较开头和结尾的底图、边框、文字是否相同；再对实际编码的无字中央区域比较清除前后。这个反例能区分揭开已有图像与替换图像，比单看粒子数量或最终截图更有力。
- 平面边框、图形阴影与解析插值不是三维产品、颗粒动力学或工作屏幕。外圈密集颗粒压住四角、细线在小图中退后，应作为构图取舍单看；静止源码帧与压缩视频容差分开，不能要求有损编码逐字节相等。

### 同形换面把共同计时与因果耦合分开

[Panoply Quantumania](https://panoply.co.uk/cases/quantumania) 明确是早期视觉研发与运动实验，不是最终院线镜头。有限抽样可见纤维状亮结构、暗色团块和高反差表面；探索微观世界是项目意图，不是科学行为已被证明。

- 多叶二维标量场可以保留连续轮廓，同时改变色带与浮雕条纹。合成高度梯度给出类法线明暗，不是三维体积、透明凝胶或物理膜；几何相位与色前沿共享时间，不等于色前沿驱动形变或能量传播。
- 平涂控制同时拿掉颜色、条纹、高光和明暗，属于组合表面消融；无前沿控制若同时拿掉混色和亮边，也不能分别证明两者贡献。像素有差支持这些组合参与绘制，不构成单变量因果实验或观众解释验证。
- 重复圆润条带和宽高光可能像软垫浮雕，中央发软、周边纹理等距与参考纤维层次差距都应具体说明。竖向软扫带清楚，但未必读作物质内部的流动。逐帧指定阈值连通也不证明连续时间或所有抗锯齿阈值的拓扑。

### 移壳见架先证既有结构，再谈隐喻

[Panoply The Game Awards](https://panoply.co.uk/cases/the-game-awards) 的抽样支持岩层、点场、分层/晶体外观和奖杯的观察；页面“揭示底层系统”是创意说明，不证明每种效果都消费同一结构模型。原创可让不透明带编号壳体移开，留下原位置的连接框架。

- 与既有透明外壳、桥体与遮挡方法去重：增量是壳体保持尺寸和身份，仅平移；底架和支点始终不动。初始仍有少量框架可见，就称近乎遮住而非完全不可见。
- 去掉底架而保留壳体及背景：闭合时差异很小、打开时差异明显，才支持“移壳显露既有框架”的局部关系。图连通、支点坐标一致与透明度不变不是受力、刚度、碰撞安全或建造可行性证明。
- 三分量坐标经过仿射投影仍是二维绘制的爆炸示意；固定画家层序、前后两张框架图不等于完整空间桁架或通用深度求解。悬浮块没有吊装、细线交叉像线框覆盖、无接触阴影，限制应保留，不能把隐喻写成工程结论。

按“轨迹成标、同纹再框、颗粒撤出、同形换面、移壳见架”选择变化关系。先读已有规则，再核当前返回值/层序/属性实际进入成片；单批新增指南不是总体利用率提高的证据。来源页面所称广告时长和取得文件时长不一致时分别记录，不假定同一剪辑。源音轨存在、音量数值、实际听过与原创无音轨必须分开；原素材、私人标题/源码/影片/报告、提示词及哈希不入公共正文，公开观看不授予品牌、字体或音像重用权。

- **色带衬物。** [Cub Studio / Polaroid Music](https://www.cubstudio.com/polaroid-music) 的静帧可观察产品与连续色带的前后关系，不能推出源音乐、波带速度或三维路径。原创带状背景可让真实路径位置和切线进入边缘绘制，再用只改一带的对照检查该区域变化及标题/主物的不变区域；这支持局部消费，不证明更好看。外部静态绘制与原生影片管线分列，不因用了路径模块就声称用了整套渲染引擎。
- **转视角见间距。** [Cub Studio / Trompe l'oeil](https://www.cubstudio.com/trompe-loeil) 的建筑静帧支持尺度与空间歧义，不证明连续错觉。原创可固定不同深度的几何及人物世界锚，只改变共同投影，让初始重合变为分离；不能分别滑动两半后称相机证明。正交正视、缺少地线/俯角时，即使几何正确也可能被读成滑块，须保留知觉限制；真实变换返回值作为角度标量被消费，不等于库提供了完整三维相机。
- **同物缩放与换预设。** [NotReal 匿名公司工具包](https://notreal.tv/project/toolkitforacompanywecanttell) 的选框人物片段不证明可用编辑器，也不授权推测客户身份。原创在同一预设缩放期间保持本地几何，换预设则明确切换ID与轮廓；缩略图、主体、标签及检查器共用所选数据，包围盒由真实几何求得。显示尺寸是否包含选框padding须声明，地线单独固定。主体与静态参数控件共用一个值，不代表控件返回值驱动主体；可画控件仍无拖拽、键盘、撤销或响应式功能。
- **跨载体留读。** [NotReal / RAD](https://notreal.tv/project/rad) 的静态罐体、字标和海报可研究少量不变量跨载体，而非源转场或声画节奏。原创共用同一标记函数/几何，只按载体改变布局、尺度和反色；虚构名称与原创几何也不构成商标清查，平面包装图不证明实物装配。保持最终版字标还不够，入场中途也须核保护区；若与先前声明冲突，撤回泛化结论，按[全帧保护区回归](../../skills/motion-film-director/references/qa.md#保护区检查覆盖全部相关帧)保留失败反证并限定修复影响。

这些经验只支持对应静态或有限抽样关系。原生全帧复渲、最终编码检查、正常速观看、实际听审、交互/印刷/用户接受分门；公开正文只留去素材化方法和官方来源，不收入私人作品名、媒体、报告或hash，也不据批次数量提高成熟度。

## 用途与空间让信息有共同锚点

以下与既有共享状态、共同投影、静帧陈列和动作后果去重，只保留适用边界。公开来源用于静态关系研究，不据页面动画署名推断已看过运动或听过声音；原创栅格生成、程序静态绘制与原生有声短片分列，不按作品数量新增机制。

- **功能分区与家具同锚。** [Gunner / Herman Miller](https://legacy.gunner.work/herman-miller/) 的静帧可研究色块、家具尺度与开放剖视，不能验证平台数据或空间规划。使用既有 `gridLayout` 时，让 `geometryBounds` 的 x/y/width/height 实际构成地面区，x/y 同时锚定该区家具；家具尺寸若独立编写就不称宽高驱动家具。未用的 matrix/zIndex 不计消费。只平移读取后的局部坐标而地面与家具一起移动，支持下游共同锚消费，不证明布局算法最优。楼板外溢的诊断不是推荐布局，固定投影和画家层序不是测绘、光照求解或通用深度渲染。
- **信息卡与场所标识同源。** [Mana / OAIC](https://www.mana.tv/work/oaic) 的静帧支持信息平台与人物尺度，不证明真实政务服务、数据流或认证安全。原创可从同一记录派生卡片及空间标识的ID和角色色，大卡承担完整事实，小标识只承载摘要；共用颜色还须核实际像素与文字含义，而非只核数组。既有 `transformPoint` 返回坐标可直接放置静态顶点与人物锚，这不是运动API或影片管线。正面文字配合等距底座是混合说明图，不假称统一实体投影；连接虚线不是实测路线。虚构时间、地点和服务须在图上明示，不能仅在报告里澄清；原尺寸可读不替代手机、对比度或无障碍测试。
- **动作意图不等于完成。** [Mana / Quality Homes](https://www.mana.tv/work/quality-homes-3d) 的厨房静帧可观察圆润人物、日常物件与环境尺度，不证明源片因果或建筑性能。生成静帧中道具靠近容器口、手扶容器，只支持尝试或展示，不能宣称已经插入、松手后稳定或完成装配。接触含糊就保留含糊，不能用精细材料覆盖；三维外观不是可编辑模型、骨骼或可复用渲染资产，也不算代码复用。
- **动词放在用途载体上。** [Mana / Fiber Flexibility](https://www.mana.tv/work/ahlstrom-munksjo) 的望远镜静帧把观看词语放在器身，可研究文字与工具用途一致。页面混入的通用reel图须排除，不把同页文件全算该项目。原创可让观察工具上的短句指向被看对象，但局部放大读法不是连续光学映射；镜内外纹样不一致或镜外同样繁密时，应注明偏离原意，不称科学倍率、连续追踪或商业验收。纯生成栅格没有调用引擎，不将提示词或漂亮图像转写成新积木。

以上只支持已观察的静态关系与限定动作。原生全帧数值/复渲、编码抽帧、常速观看、实际听审与用户接受仍分门；公开正文不收私人标题、媒体、源码、提示词、报告或哈希，源图公开可见也不授予复制权。


## 材质对比与姿态须分别核显示和行为

沿用异媒介共处、静帧陈列、功能同锚与动作意图边界，只补下列反例。源静帧、开发GIF选帧和页面制作说明不能合成一次完整观看；纯静态程序图与生成栅格均不是静音影片。有声概念片的编码、音轨存在与数值同步也不代常速观看、实际听审或用户接受。

- **控件回执。** [Gunner / Google Home App](https://legacy.gunner.work/googlehome/) 的插画表与GIF选帧支持界面状态和环境语法的对应，页面所述Lottie生产不证明当前应用功能。原创可由同一采样值绘制控件和房间色调，并在接触阶段直接消费原生控件返回的 thumb 放置指针；与只让两者各自读时钟、或仅把回执存起来区分。接近末点、拖动起点和释放起点要分别连续；显示整数可由连续值四舍五入，拖到终值后保持接触也不必立刻释放。sampleMotion/withMotion 的有效区间和实际绘制职责分开，闲置求值不计画面贡献。静态控件仍无真实输入、设备连接或键盘功能；同值调色不是物理照明。
- **静态接触。** [Gunner / Knandu Apparatus](https://legacy.gunner.work/knandu-apparatus/) 的开发样本支持细线肢体与大色块的尺度反差，不提供完整动作顺序。既有 solveTwoLinkIK 的返回关节和端点若进入绘制，可证明静态姿态消费；把中心线端点约束到表面，不等于线宽不越界、自然受力或真正推动。还要检查头身遮住多少肢段，不能由关节可达推断完整开放轮廓。静止脚标与地线相接只是视觉落脚，不证明平衡、摩擦、重量或一段角色表演。
- **粗细异材。** [Gunner / Mesh](https://legacy.gunner.work/mesh-1/) 的角色图与过程GIF选帧支持平涂身体、粗糙地形和局部亮光的反差，不因文件名就认定扫描方法或物理材质。原创可用 transformPoint 实际返回坐标放置人物，地形另由自绘颗粒和面色构成；不是所有可见细节都来自引擎。鞋底与灯底的接触边端点应检查落在对应地形/台面多边形内，而非仅处于相同纵向范围。二维包含关系和装饰阴影不证明真实接触；脸未朝下、手未触纸时，只称停在地图旁，不称已经读懂、握住或导航。
- **冷暖修补。** [BUCK / Woolmark](https://buck.co/work/woolmark) 的环境与物件静图支持室外冷色、室内暖区和材质一致性，不提供修补动作。原创静物可让补片、边针脚、散线和工具共同提示暂停的工作；灯比补片更亮时，不宣称补片独占焦点。提示词要求工具插在针垫中，成图却放在桌上，应记录偏差而非以文字覆盖像素。织物、陶瓷、金属、木纹的生成外观不证明制造尺度、针线连续或布料物理。
- **同柜异材。** [BUCK / Zapier Motion Library](https://buck.co/work/zapier-motion-library) 的材质方体、透视人物和草图/成图静图支持异质表达由统一边界组织；页面描述多支动画不等于已观看全套。原创可让不同概念分别采用泥、纸、织物和画线，同时借重复把手、层边界和柜体保持识别；与同一形状换表面区分。固定抽屉伸出差异不证明抽拉顺序，柜脚阴影不证明导轨、承重或防倾倒。没有输入或状态反馈的家具图不是实际UI。

生成图只记录栅格产物、提示词及已知生产方式；未核原始调用时，提示词自述不升级为独立工具来源证明。没有网格、材质图、绑定或原生调用，就不把三维外观与提示词计为可重复渲染资产或积木消费。现有API实际消费、局部自绘和纯图像生成分开记录，不用调用次数构造利用率。公共正文只收去素材化方法，不收私人作品标题、媒体、源码、提示词或报告身份；参考可见不授予素材重用权。
