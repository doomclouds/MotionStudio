# 显露与修订：变化前后如何核对

只在遇到相应问题时选读。本页保留原研究的来源、观察范围、反例和未验限制，不是新资产登记或本次验证记录。通用制作流程见[参考到组合](../reference-to-composition.md)；资产 API 与状态仍以所属合同为准。

## 显露与延续：确认变化前后保留了什么

以下复用轨迹、身份属性、遮挡和表面变化，只补有限原创与独审改变的判断条件，不新增机制或作品。五项均为静音程序图形研究，来源有音轨但未听审，来源和原创均未常速观看。完整解码、抽帧、数值与消融可约束实现，不能代替节奏、美术、听感或参考级验收；样本中的材质外观也不证明来源求解器。

### 轨迹成标分清收束、替入和文字显现

[Panoply Amazon Original](https://panoply.co.uk/cases/amazon-original) 的短片抽样可见纵向光/材质分区、部分隐藏的字标和最终居中签名。可以提炼延迟可读性，但原创径向轨迹和椭圆是另行设计，不是恢复源片运动。

- 粒子端点落到环上，只证明位置对应。另绘环淡入、轨迹淡出是替入，不是粒子连续融合成实体；标题独立淡入也不是被光学结构揭示。文字若在收束结束前已出现，应记录交叠，不说严格先收束再出字。
- 细暗轨迹、大留白和泛光可以构成克制构图，但开场近空、小字缩小后消失、通用椭圆缺少识别性仍是具体风险。数值上的最终停留只提供阅读机会，不证明观众读完或感到情绪抵达。
- 超采样与Gaussian光晕只改善栅格边缘和图形光感，不是光学bloom、折射或体积光。延迟签名与既有揭示方法去重，新增判断是标记、运动轨迹和文字究竟共享几何还是仅在时间上接续。

### 同纹再框保留材料身份，不假称制造过程

[Panoply / Grey Canada Herradura Legend](https://panoply.co.uk/cases/legend) 的说明与抽帧支持焦木、明亮过渡、反光形态到包装的材质叙事；不足以证明无剪辑连续变形或木材变玻璃的物理过程。原创可让一个物体坐标纹理变暗后缩小，揭示始终存在的工具轮廓。

- 与既有跨材质保持属性的方法去重：核近景和产品视图消费同一UV标量，暗化完成与拉远开始分开。均匀缩放加横向重排是重新取景，不是形体变成另一个产品；参数框比例恒定也不保证带缺口、侧面的可见轮廓具有该比例。
- 规则纵线和梳状擦痕容易读成面板或条码；不均匀中断、弯曲和颗粒沉积可减弱这种误读。修订后仍可能像深色木条，类别仍依赖文案，不能把局部改善提升为真实炭材或完整美术通过。
- 独立绘制的粉末擦痕不是工具实际画出的结果，暖色扫带也不是燃烧、热传导或碳化。既要保留纹理身份，也要明确性能证据缺席，不能以“材料起源”隐喻代替制造或产品测试。

### 颗粒撤出揭示既有图像，不把遮挡当转化

[Panoply OPPO F7](https://panoply.co.uk/cases/f7) 的有限样本可见颗粒环境中露出的产品状表面，以及后来受屏幕边界约束的亮纹理；不证明颗粒变成电子材料或连续变形。原创可让有固定身份的颗粒离开中央，显露一直存在的图像。

- 每个颗粒的起点、终点、大小和颜色保持索引，只证明记录延续，不证明质量守恒或遮叠时每粒可见。初始遮挡有缝就不能称完全隐藏；末端颗粒围成装饰环也不是重力沉降。
- 去掉颗粒层，比较开头和结尾的底图、边框、文字是否相同；再对实际编码的无字中央区域比较清除前后。这个反例能区分揭开已有图像与替换图像，比单看粒子数量或最终截图更有力。
- 平面边框、图形阴影与解析插值不是三维产品、颗粒动力学或工作屏幕。外圈密集颗粒压住四角、细线在小图中退后，应作为构图取舍单看；静止源码帧与压缩视频容差分开，不能要求有损编码逐字节相等。

### 同形换面把共同计时与因果耦合分开

[Panoply Quantumania](https://panoply.co.uk/cases/quantumania) 明确是早期视觉研发与运动实验，不是最终院线镜头。有限抽样可见纤维状亮结构、暗色团块和高反差表面；探索微观世界是项目意图，不是科学行为已被证明。

- 多叶二维标量场可以保留连续轮廓，同时改变色带与浮雕条纹。合成高度梯度给出类法线明暗，不是三维体积、透明凝胶或物理膜；几何相位与色前沿共享时间，不等于色前沿驱动形变或能量传播。
- 平涂控制同时拿掉颜色、条纹、高光和明暗，属于组合表面消融；无前沿控制若同时拿掉混色和亮边，也不能分别证明两者贡献。像素有差支持这些组合参与绘制，不构成单变量因果实验或观众解释验证。
- 重复圆润条带和宽高光可能像软垫浮雕，中央发软、周边纹理等距与参考纤维层次差距都应具体说明。竖向软扫带清楚，但未必读作物质内部的流动。逐帧指定阈值连通也不证明连续时间或所有抗锯齿阈值的拓扑。

### 移壳见架先证既有结构，再谈隐喻

[Panoply The Game Awards](https://panoply.co.uk/cases/the-game-awards) 的抽样支持岩层、点场、分层/晶体外观和奖杯的观察；页面“揭示底层系统”是创意说明，不证明每种效果都消费同一结构模型。原创可让不透明带编号壳体移开，留下原位置的连接框架。

- 与既有透明外壳、桥体与遮挡方法去重：增量是壳体保持尺寸和身份，仅平移；底架和支点始终不动。初始仍有少量框架可见，就称近乎遮住而非完全不可见。
- 去掉底架而保留壳体及背景：闭合时差异很小、打开时差异明显，才支持“移壳显露既有框架”的局部关系。图连通、支点坐标一致与透明度不变不是受力、刚度、碰撞安全或建造可行性证明。
- 三分量坐标经过仿射投影仍是二维绘制的爆炸示意；固定画家层序、前后两张框架图不等于完整空间桁架或通用深度求解。悬浮块没有吊装、细线交叉像线框覆盖、无接触阴影，限制应保留，不能把隐喻写成工程结论。

按“轨迹成标、同纹再框、颗粒撤出、同形换面、移壳见架”选择变化关系。先读已有规则，再核当前返回值/层序/属性实际进入成片；单批新增指南不是总体利用率提高的证据。来源页面所称广告时长和取得文件时长不一致时分别记录，不假定同一剪辑。源音轨存在、音量数值、实际听过与原创无音轨必须分开；原素材、私人标题/源码/影片/报告、提示词及哈希不入公共正文，公开观看不授予品牌、字体或音像重用权。

## 邀请与修订：让组合关系承担有限主张

以下复用排版、照明图形、负空间、字形定位和通路示意，只补有限原创及独审的条件，不新增积木或作品。一项为静态imagegen概念图，四项为静音程序图形短片；静态图没有运动验收，影片也均未常速观看、未听审。来源片段范围、音轨存在与整案声音署名分别记录，不能把无音轨短样本推广为整案无声，也不能把近底噪测量当听审。

### 字牌合列先给个体读窗，再给共同对齐

[NotReal Google Developer Groups](https://notreal.tv/project/googledevgroups) 的选定片段可见彩色叠字、深底轮廓版与城市/学生变体；官网描述统一社区的品牌与动效工具包。原创可把不同句子分别带入，再共享对齐线，但这不是恢复源片的精确转场或完成同等品牌系统。

- 与既有错峰、字形腾空和布局过渡去重：整张字牌保持文字、颜色和编号，先到错位位置、再共同对齐。入场在画边截字是暂态，不称全程可读；最后等宽和间距清楚也不能代替各句进入后的读窗。
- 同样长的横条和编号容易读成步骤清单，而非具有个性的社区成员。轻微倾斜不能自动承担角色差异；若目标是地方身份变体，单一终稿里的三条句子不足以证明跨场景识别系统。图形编号不是交互控件，虚构邀请也不是已具日期、地址的可执行活动通知。
- 本次取得的来源片段无音轨，但官网有音乐/SFX署名；只限定该文件，不把整个项目称为无声音设计。原创构图的可读性与来源角色/变体的丰富度分开评估。

### 主名伴语先分语义角色，再谈副标志

[NotReal Rebrand](https://notreal.tv/project/rebrand-studio) 的短选段可见手写主名的副标志、墙面/线缆与亮暗状态。部分样本还有不均匀亮灭，不能说源字全都同时切换，也不能由亮灭推断逐笔书写；这个局部组件不是整案全片。

- 稳定主名称与另写的通用邀请词可以分工，但邀请词没有重复品牌身份，不能冒称已验证的替代标志。名义上的主名较小、伴语占画面中心可以是单张构图选择，却不证明跨载体或远距品牌识别。
- 同一中心线蒙版整体调强度是整词亮灭，暗态已存在就不是字形从无到有地书写。四个独立自绘字形只构成一个词，不是可用字体家族；重复渲染同帧也不冒称完整逆向跳帧测试。
- 双重回笔、尖锐回折与小字退后需看实际原生图。Gaussian泛光更像发光笔迹，不是玻璃灯管、墙面受光或电气模拟。来源有音轨但测值接近底噪，既不能写成无轨，也不能称已经听过或听来静音。

### 负路成景让安静区域穿过密集形体

[NotReal Nike Gumball Pack](https://notreal.tv/project/nike-gumball) 的极短选段可见粉色圆润形体围绕稳定白色标志，局部配件提供颜色对比；官网另述泡泡、透明度和游乐材料。选段不涵盖完整系列、鞋款或所有材质，也不证明软体、压力、碰撞或相机求解。

- 原创静态图可改变焦点，把连续负空间路径而非品牌标记作为安静主体。前景裁切、中景开孔与远处小空地分配尺度，分别核路径入口、弯段和终点没有被形体吞没；形体自身的洞不应误作主路的断口。
- 异形拱与折垫能建立玩具感，但重复过多、近景单侧过重和远景过于简略仍需判断。生成结果更像绒布/泡棉，就按所见材料命名，不把提示词里的光滑橡胶当成已实现的shader。
- 透明薄叶的厚度、重叠和底部合并可能含糊；一张imagegen栅格里的连续路不等于可导航三维场地、可建造游乐设施、软体仿真或可动画资产。文字输入记录只支持所记录的生成输入，不证明隐藏生成过程或独占权；该静态结果没有声音、时序一致性或动态验收可言。

### 首字带句保护对象区，也修真正的行基线

[NotReal eBay Authenticity Guarantee](https://notreal.tv/project/ebay-authenticity-guarantee) 的极短选段支持大字缩小、产品照片与多行字逐渐组合的观察；不足以覆盖官网所述完整混合媒介影片。该选段无音轨，官网仍有配音/声音职责说明，不能将局部静音当成全案事实。

- 与既有整字移动、阅读空间及字内重建去重：首字保持字符与字体身份、改变尺寸，其他字另行进入，不是轮廓变形。固定对象区与逐帧字形墨迹边界可约束排版；再用无文字对照核对象区未被文字覆盖，屏幕隔离不是物理碰撞测试。
- 各字按顶部对齐可能把句号抬成近似撇号，应共享行基线，并在最终编码里核修正。单一拉丁短句的逐字布局不是通用整形、多语言或响应式排版系统，半成词只是构建暂态。
- 全句达到不透明和最终署名完成是两个读时起点；余下帧数是阅读机会，不是读完、舒适或情绪回应证据。静止二维灯具与艺术光池可以呼应文案，但光不产生文字，也不证明灯具铰接、电气、光学或实物材料成立。

### 拒案换件以指定入口核修订，而非假称自动审查

[Panoply Graphite](https://panoply.co.uk/cases/build) 的页面描述建造、评审、修改和合并，抽样可见建筑体、透明感评审段及界面/代码标签。原创可以改为平面院落的一次拒案修订；不能把脚本播放的图解称为实际代码审查或产品功能。

- 与既有桥体通行、移壳见架去重：保留院落与周边坐标，整个错误入口块移走，再用两个新翼块留下真实空隙，不是原块淡出或形变成两片。核指定接近线在旧块中相交、新间隙容纳线宽及端点，再核替换就位先于路线出现。
- 时间顺序满足不代表运行时验证。若临时令替换位置未就位，路线仍按自己的时钟绘出，就只能称预先编排，不是检查器自动发现并纠正阻塞。保留这个反例，比只测试正确时间轴更能约束宣传。
- 周边仍有窄缝时，只称指定中央入口受阻，不称整个院落密闭、唯一通路或全局不可达。金线到圆心没有实际人物通行；二维矩形、树符号和固定偏移阴影不构成施工、三维相机、建筑规范、无障碍或安全验收。“重新加入”是图形重组，不是Git合并或结构焊接。

按“字牌合列、主名伴语、负路成景、首字带句、拒案换件”进入适用条件。清晰图解与参考材料工艺、数值通过与美术判断分别保留；源片段有/无音轨、官网声明和原创静音不互相替代。公共正文不收私人输出、源码、提示词、报告或哈希，不新增数量或总体利用率结论；品牌、照片、字体、原声及生成图的权利仍须分别核定。
