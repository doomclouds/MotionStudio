# 从源码学习媒介，而不是给成片加滤镜

本页研究 LemoLab 的 [Risograph 风格合同](https://github.com/lemomo-ai/lemo-opuscar/blob/bebbbe1aa92a3cb4bb6f83500e61b23a17d1aa00/styles/risograph/STYLE.md)、[Sunday Ride 样片解构](https://github.com/lemomo-ai/lemo-opuscar/blob/bebbbe1aa92a3cb4bb6f83500e61b23a17d1aa00/styles/risograph/DEMO.md)及同版本绘制、印刷和声音源码。这里是有来源的代码学习与适配，不是只看片的独立还原，也不把上游作者的工作称为本库原创。

## 先让图形承担油墨关系

三个颜色通道可以分别表示三个墨版的密度，而不是屏幕上最终的红绿蓝颜色。后画对象替换三个通道时形成挖空；只向指定通道叠加时形成套印。最终纸色与各版墨色相乘，才产生混色。先核一版时主体是否仍完整可读，再安排新增墨版揭示什么：如果关键部位完全不含第一版，它会暂时消失，这应是有意的揭示，而不是偶然丢失轮廓。

这种结构不能由“彩色插画＋噪点遮罩”代替。测试至少包含独立色版、两版重叠、留白、低密度网点和高密度实色；改变一版时，其他版与重叠区的后果应符合预期。原方法使用纹理采样、余弦网屏和有意的墨色不均，不等于专业分色、ICC校准或真实墨水模拟。已有[面积覆盖网屏](../../../engine/motion-elements/lib/foundations/geometry/halftone-screen/README.md)解决圆点与格子的几何面积，不能据名称把两种算法互换；[三版印刷候选](../../../engine/design-elements/recipes/candidates/spot-ink-print-candidate/README.md)另列自己的有限合同。

## 分开角色、镜头与印刷变化的时钟

上游样片把角色按两帧一姿态处理，镜头仍逐帧移动；色版的基本错位在镜头内保持，只有强调事件产生衰减跳动，停顿段才让各版漂开。纸面的大块墨色变化按镜头固定，小部分颗粒按印刷节拍更新。复用的是这些不同时间尺度的分工，不是任意逐帧抖动。

新增色版还可以引入新的乐器声部，形成同一段落的视听递进；反过来，也可以用减版、退声部表达失去。必须先有内容理由，再让视觉事件与声音安排引用同一时刻。源码里的共同时间表证明预编排关系，不证明观众听到的落点自然；短暂停止音乐也不表示环境声、余响和全部声部必然同时归零。这里没有实际听审结论。

## 复现依赖的行为，而不只核文件存在

字体文件加载成功，仍不证明不同字重真的生效。同一变量字体的多个请求字重可能得到相同字宽与画面；需要实测各字重，并与同源静态字重实例对照，而不能假设运行时正确应用了轴值。检查应同时覆盖字体身份、轴值、真实文字测量和原生尺寸的笔画，而不是只看注册返回值。替换运行时后的小字笔画仍可能不同；局部描边补偿必须记录为适配，不能说成原字体参数或通用修复。

声音源码、声部文件、旁白和最终混音也是不同资源。旁白文件缺失时，依赖人声音量的音乐压低也可能不再发生，不能把无旁白重建称为原混音。合法沿用原片完整音轨、由源码重新合成配乐和拟音、获得可独立再编排的声音资产，分别记录来源与缺口。响度脚本成功退出后仍须检查实际峰值与响度；数值、实际听审和声画观感各守自己的证据范围。声音复用层级见[声音书架](../../sound/INDEX.md#既有资源审计边界)。
