# 观察式复刻：画面怎样落到组合

只在遇到相应问题时选读。本页保留原研究的来源、观察范围、反例和未验限制，不是新资产登记或本次验证记录。通用制作流程见[参考到组合](../reference-to-composition.md)；资产 API 与状态仍以所属合同为准。

## 观察式复刻把画面关系拆成可验证组合

只允许看片的任务先隔离原作源码、旧移植和原公式报告；画面上的 API 名称或帧率标签不是实现证据。以下来自独立重画与编码后抽帧修订，只补组合的操作条件，与既有时间、遮挡、角色表演和混合美术方法去重；不新增正式积木、配方或作品。源像素只作私下观察，不当贴图混进重建。方法选择可沿[时间合同](../../../engine/motion-elements/docs/guides/core-api-and-time.md)、[角色表演](../../../skills/motion-film-director/references/character-performance.md)及[混合美术](../../../skills/motion-film-director/references/hybrid-art-workflow.md)进入既有实现；这些导航不等于本次全部实际调用。

- **固定讲解框与可变演示区。** 先锁定时间轴、标记和舞台的共同坐标，再分别拟合钟针、大小/颜色、曲线揭示与中心扩散格。曲线先是观察到的图形，不由文字标签推断原算法；中心距延迟与退场包络分开调，避免只修入场后留下过早点亮或过晚熄灭。用同一时刻核游标、标签及演示结果，阈值附近补邻帧；这是预编排同钟说明，不是可交互编辑器或事件响应。已有 `motion.opacity` 的返回 opacity 可用于实际淡入淡出，几何和时钟另由独立绘制承担，不把所有画面归功于该调用。
- **种子纹样与扩张场分开。** 图形展示段先保留一个可辨认的中心种子网格，再让外围格按各自启动时间扩出；统一色场、单元尺寸和描边接缝分别核。先比较种子出现、首圈增长和满屏三类帧，再调波动与装饰。不能用满屏图案整体缩放代替逐格增长，也不能把轮廓形状齐全当作连续形变已经匹配。粒子体积还须检查侧面/空洞/投影密度，只有几个关键形状相似不证明三维运动成立。
- **物件交接用互斥持有状态。** 角色故事先列“手中、离手飞行、接收、装入、收合”的对象身份和可见性；投掷前贴合手部锚点，释放后撤去手中副本，回传时只保留一个运动物件。多件成果收进容器要分别起行、错峰到达，再合盖，不用整体缩小冒充收集。姿态切换还要撤去上一姿势的肢体，防止叠出第三只手。核释放前后、收合两侧及镜头切点，关键帧成立不证明真实折纸透视、握持受力或常速表演自然。
- **高密度字版先分层再谈材质。** 字面、侧面、倒角与逐字姿态分开，窗口的标题栏、内容、位置、出现时间和遮挡次序分开；先核主体占幅、字间距与信息密度，再处理高光。虹膜可独立控制线束长度、亮暗组、瞳孔轮廓和扫描标记，不能只以整体增亮代替内部结构。分别核局部静帧和字母汇聚段，前者修好不能宣布后者已统一；面色与二维偏移只是金属/玻璃近似，不声称环境反射、物理折射或完整三维渲染。
- **画中穿行拆开镜头与角色。** 绘画背景、角色运动、推镜、平移、入口闪环及前景草梗分层；先锁定天空占比、树丛与地面裁切，再判断角色相对场景的位移。前景应遮住脚部而不吞掉主体，闪环的大小与断续笔触须与场景材质协调；整幅画的空间构成不能靠噪点滤镜补救。可由图像生成独立制作背景，再以程序绘制角色和遮挡，但生成栅格不是可编辑三维资产，也不因叠加角色就算完整步态系统；局部短片不扩称整片复刻。

**消费与验证边界。** 以上实践中，时间轴演示实际调用了公开 `sampleMotion` / `rational`，以 smoothstep 曲线求值 `motion.opacity`，并消费返回的 opacity 控制淡入淡出和格子错峰；钟针、曲线、图形等仍是独立绘制。其余图形展示、角色叙事与密集字版主要为独立离线绘制，未消费现有 MotionStudio 积木；绘画穿行是图像生成背景加程序绘制，未调用通用引擎。不能把思路相近、读取文档或新的公共导航记为实际消费，亦不能将这些独立片段宣称为已封装可调用的新模块。

**复核边界。** 先以低密度样本核全片顺序，再在疑难转场加密；精确时间用帧号与媒体时间基准，滤镜联系表可能有取样偏移。修订后从最终编码回抽同刻及邻帧，稀疏暗画面同时看前景和全画面，低全图误差不证明高相似度。独审只覆盖实际看到的版本和时刻，后续作者修订不能继承前版独审结论；一般用户认可与方法发布许可也不升级成逐项高保真接受。本组为静音输出，部分来源有声但未听审，GIF无声不能补造原音效；没有完成常速观看的证据。抽帧、全帧解码和语法运行只支持各自技术范围，不代替常速、实际听审、音画同步或艺术验收。原作媒体、私人报告、提示词和实现均不随本方法入库。


### 轮廓与相对空间先于表面细节

观察式角色复刻先选转向、最高/最低姿态和伸展极值的同刻帧，比较头/躯干/四肢的轮廓、朝向和相对高度；“同主体、同方向”不能代替姿态匹配。把主体、另一角色与至少两个可辨认背景锚点同时标在画面坐标中，分别比较位移与彼此间距：背景和人物一起平移，并不证明相机与角色已经配准。有限二维缩放转向不能代替真实透视、肢体深度分离或接地约束。先修这些差异，再加颗粒、雾光和材质；否则细节可能只让错误轮廓更清楚。

照明也有自己的生命周期：分别核局部光池变成长条扫光的起点、宽度/软边和退回局部光池的时刻。新增光束可修复缺失的画面关系，但在应收回的时刻仍保留长条，仍是时序偏差；不以中段一帧好看证明整段光场成立。这里是基于成品像素的比较方法，不反推原作摄影参数或物理散射模型。

### 放下物件时分别核接触、释放和离场

沿用上面的互斥持有原则，但落在台面上的物件还须分开检查三件事：物件底边到达支撑面、手指解除握持、手臂/身体遮挡撤出画面。物件已经停住而手仍握着，或放手后手臂比参考更晚离场，不能合并称为“放下完成”。在每个事件前后取同刻与邻帧，保留物件身份和落点，再核撤手后结果的独立读窗；手的轮廓、腕部对齐和遮挡边界与物件轨迹分别修。接触表只支持这些被观察到的关系，不证明真实受力、连续动作自然或常速节奏已经通过。

这两项是对既有观察式复刻、互斥持有和读窗方法的细化，不新增 catalog 机制、代码模块或独立配方。复核版本绑定继续沿用上面的复核边界和[导演验收](../../../skills/motion-film-director/references/qa.md)，不把既有规则再计为本轮新增。


### 先对齐镜头阶段再组合布局与投影

同样有卡片、立方体和散开镜头，不等于同刻内容相符。沿用前述媒体时间基准，在阶段边界两侧确认当时应是信息卡、展开卡组、平面画面、完整立方体还是散开块；缺失过桥镜头会把后段整体提前。联系表的整秒标签不是精确 PTS，修订时间表须回到源媒体同刻帧；有限加密抽样只能支持近似边界，不能宣称全帧追踪。榜单放大、胜负卡亮暗交替、单卡结论和片尾界面也按此核次序，而非只检它们是否曾经出现。

可复用的组合责任链是：`offsetCards` 提供卡片布局，`transformPoint` 将局部四角带入该布局，再由调用者决定展开角度、时序与最终四角；`compileProjectiveRaster` / `warpProjectiveRGBA` 按这些四角采样已准备图像，返回像素须进入最终合成才算这段实际复用。立方体各面的几何、可见顺序、切块图像和散开轨迹仍由调用者提供，投影采样器不会自动生成三维物体、转层或相机。先验证完整体上的图像连续，再检查分块后是否保留各自图像；真正运行这些调用不等于原图、打光、倒角与运动已经匹配。组合不是新增机制或配方，多个 API/helper 和逐帧调用数不转写为新增积木数。具体 API 范围见[布局与组合](../../../engine/motion-elements/README.md)及[投影栅格](../../../engine/motion-elements/lib/foundations/raster/projective-raster/README.md)。

**先辨认缺机制还是缺内容。** 透视采样、遮罩和粒子测试通过，仍不能供应摄影人物、连续跑步素材、产品多视角或高质量材料图。`raster.matte` 解决源图与蒙版的合成，不生成蒙版中的人物；有限粒子发射不自动获得产品表面分布或目标形状对应；材料面板层级不能替代具体透明体、金属折面或织物摄影。若缺的是主体素材，先取得或独立制作授权范围内的素材并检查身份/运动连续，再做片内组合；不能用更多装饰图元把缺口包装成修复。只跑库测试而未把输出用于影片，应记录为机制验证，不能追记成初版影片复用。保持[混合美术流程](../../../skills/motion-film-director/references/hybrid-art-workflow.md)的素材与运行时边界；这里不认定素材已取得，也不宣称常速、听审或完整复刻通过。


### 界面推近与退场先分清坐标域和合成层级

信息图从双栏推近右侧版面时，先确认左侧数据是否仍停在屏幕原位，再决定变换施加在哪一层。用 `motion.transform` / `withMotion` 包住右侧版面并设置该版面的缩放锚点；左侧数据在屏幕坐标单独绘制和淡出，不把整幅画面一起放大来模拟局部推镜。反证是左侧文本也位移/变大，或右侧标题因错误锚点偏离原轨迹。几何与文字仍为独立重绘，局部矩阵消费不证明真实相机、字体一致或数据交互。

叠层界面退黑时，各个子形状分别乘透明度，不一定等于完整界面统一淡出：重叠区域可能残留更亮的底栏或卡片。若目标是完整画面压向黑场，可先完成该场景合成，再覆盖一层统一黑色遮罩；若只淡出一个对象，则先把对象及其内部重叠合成一层，再做组透明度。按实际目标选，不把整幕遮黑强加给需要独立保留的前景。比较重叠区和无重叠空白区的同刻亮度，淡黑结束、下一场擦除开始和字标首次可见分别核；原生像素结果不自动等于有损编码边缘。

### 用可见量校正局部相位而非套一个统一缓动

在原生时间基准上分别记录擦除边缘位置、各条形长度、字标区域亮度和首次可见时刻，先确定每项的起点、增长与停留，再拟合有限关键点。可以将观察到的边缘位置归一化为现有 `transition.rect-wipe` 的进度，将条形增长的归一化比例用既有 `sampleMotion` 线性插值返回值驱动宽度；不因返回字段名为 opacity 就把几何消费记成新的专用图表机制。逐条增长不默认同一起点或同一速率，轮播也不默认等间隔，字幕之间的亮墙/无字读窗不能被连续遮暗吞掉。

测量须声明区域、坐标、背景与抗锯齿容差；文字区亮度还受字形、背景和重叠影响，不把它直接当作已恢复原始透明度参数。稀疏关键点匹配只支持局部修订，不能推断中间每帧、常速观感或整片相似。以上细化复用既有变换、透明度、擦除与局部揭示，不新增 catalog 条目；原生渲染、音频流水线及测试工具另列为工程能力，helper 不重复计积木。独立合成声音没有实际听审时仍是技术草案，移动视觉事件后重新编码不自动证明音画同步；无声 GIF 按原生无声处理，不为凑声轨补音乐。

### 编辑演示保留一个不随修改变化的对照

来源为 huashu-design v2.0 官方媒体 [Slides / PPTX](https://github.com/alchaincyf/huashu-design/releases/download/v2.0/c2-slides-pptx.gif) 与 [Tweaks](https://github.com/alchaincyf/huashu-design/releases/download/v2.0/c4-tweaks.gif) 的同刻帧观察及独立重绘修订；不是读取原作实现。前者双窗中，一侧保留原标题，另一侧依次选中、删空、输入新标题；后者保持宿主版式，由三个不同控件依次改变配色、字型和卡片密度。此处的增量不是再造控件回执，而是分清**哪一部分必须不变，才能看懂另一部分改变了什么**。

- 导出演示中，窗口外壳相似并不能证明内容仍可编辑。分别保留选区、旧字消失、空编辑框、新字增长和完成后读窗；原稿窗保持旧内容，目标窗才改变。若两窗同步替换，就失去前后对照；若只整体换图，也失去可见编辑过程。镜头内的演示不认证真实 PPTX 导出、文件格式或编辑器功能。
- 多维调整先声明作用域：调色只改变相应表面/文字色，字型调整保留内容与主要布局，密度调整才改变成员数量和排布。控件开始移动、越过状态阈值、目标画面稳定是不同事件，不能强制三者同刻。跨两个离散设计状态的淡变可能短暂叠字/叠卡，须核过渡中点和最终成员数量；没有逐成员轨迹就不称真实重排。
- 适用于产品讲解与固定画幅比较，不要求所有产品保留永久双窗。小字、字体替代和窗口微小位移须单独对照，黑背景占比大时全图平均误差会遮住这些缺口。上述仅有有限帧对照，未证明常速阅读、交互或高保真接受。

### 串行高亮与结果到达是两条时间线

来源为同一发布的 [Brand Protocol](https://github.com/alchaincyf/huashu-design/releases/download/v2.0/w1-brand-protocol.gif) 与 [Fallback Advisor](https://github.com/alchaincyf/huashu-design/releases/download/v2.0/w3-fallback-advisor.gif) 媒体观察。前者步骤卡串行出现、高亮交接，之后才有结果浮卡；后者先在大卡墙选出少数项，再以错峰的建议卡和不同预览具体化选择。两者都不能只用“当前第几项”控制所有可见层。

- 步骤卡出现不表示上一步高亮必须立刻熄灭；结果浮卡开始遮住步骤也不表示流程已消失。独立记录存在、强调、退出和结果入场，检查交接两侧邻帧。保留参考中实际观察到的短暂并存，不将一个统一序号误当作状态机，也不由动画推断背后真的执行了搜索、下载或命令。
- 建议列表的错峰不止控制透明度。中途可以第一卡已稳、第二卡近稳、第三卡仍较小且下偏；在这个时刻提前排齐会消掉逐项到达。分别采样尺度、位移、显隐和停止时刻。后续预览须与建议有明确对应，不能用三张漂亮但无关的缩略图充当推荐证据。透视卡墙的二维错切近似不升级为真实三维布局。
- 这细化既有状态/阅读与错峰组合，不新增机制、配方或通用流程状态机。既有 `sampleMotion` 可提供各轨道数值，但卡片身份、选择集合、文本和预览内容仍由消费者负责；只调用一个缓动函数不能计为整套业务系统复用。

### 资产边界与下一次消费

以上四段界面重绘实际消费了既有 `sampleMotion` 与有理时间；部分还消费 `withMotion`，但不能互相借用调用记录。它们没有产生新的公共控件或图标库，字体、字标和网页缩略图也不是可直接分发的通用资产。新内容迁移仍待实际制作验证，当前保留为有限观察的方法候选，不是跨项目通过。

[Clawd — Night at the Museum 官方影片](https://github.com/alchaincyf/huashu-art-motion/releases/download/v1.0.0/clawd-night-at-the-museum.mp4) 的全时段独立程序插画重建，仅进一步暴露既有“缺机制还是缺内容”、互斥持有、接触/释放和画中穿行的边界，不为凑批次数再登记同义原则。长片实际使用原生渲染与有限粒子，并未消费共享聚光候选；其程序展品不能冒称摄影/名画资产，完成时长也不能替代材质与人物比例验收。需要灯锥和接收面协作时，先读现有[聚光场候选](../../../engine/design-elements/recipes/candidates/spotlight-field-candidate/README.md)的合同与限制，不重新造同名实现、不将候选追记为长片调用。

### 产品跨年代与成片回到工具的双层论证

以下来自有限的产品发布、协作界面与快剪品牌片观察及作者修订说明；部分同刻对照可见，但没有完整常速、实际听审或跨项目迁移验证。只保留去素材化的选择条件，不把生成替代摄影或局部纠错提升为成熟素材、通过的商业片或新增机制。

- **固定主物，拆开时代变量。** 同一产品穿越多个年代时，先比较屏幕中心、主体占幅、提手和功能部件的相对位置，再分别安排面板材质、周围物件、摄影裁切、字版与信息边条。只换背景颜色仍会丢失年代语法；年份计数到达、背景换完与主体转身也不必同时完成，不能由一个时间标签推定整幕状态。有限平面投影能让纹理附着前面，不能供应背面几何、金属反射或跨面照明。
- **成片与制作工具承担不同证明。** 前段先让一支产品片自身成立，再把同一画面缩入工具界面，后段解释制作能力。交接要保留可辨认的画面身份，并在进入工具后重新分配主体、边条和功能信息的占幅。把后段删成普通品牌片尾会改变论证；同一截图套入任意窗口也不能证明真实软件操作。局部版式接近不代表整套工具展示相位正确。
- **缩略图墙同时需要布局与内容库存。** [固定格网](../../../engine/motion-elements/lib/foundations/layout/grid/README.md)按调用者提供的独立ID计算位置，不提供每格作品。先核可辨认的独立设计、材质和构图差异，再安排墙面整体运动；用少量图案反复填格，会把作品广度变成重复陈列。密集快剪要单列每个短阶段，不能用几个大场景拉长填满。缩略图应按实际展示尺寸预烘焙，避免每个小格长期持有完整尺寸快照；这来自作者记录的内存失败修正，不是本次重演的性能基准，也没有通用容量保证。

### 摄影到协作界面时保留空间和对象守恒

摄影场景进入产品界面时，先让原场景留作共同背景，再由人员、项目上下文、看板动作、指标和目标结果依次接管。顺序正确只是叙事骨架，不能用几何示意代替摄影主物；新生成的相似建筑或人物也不证明原主体身份、独立肢体表演或镜头运动已恢复。

看板移动一张卡片时，不只画一条新轨迹：同一ID的源位置须释放，源堆栈和目标槽位随之更新。检查离开、途中、到达三段中可见副本数和相邻项位置，避免“目标卡移动了，源卡仍在”的假完成。这是既有互斥持有原则在界面集合中的细化，不新造业务状态机。[布局交接](../../../engine/motion-elements/lib/recipes/layout-handoff/README.md)负责其合同内的几何过渡，业务集合与绘制可见性仍由消费者负责。计数按已观察值与时刻校正，必要时使用已有[关键帧轨道](../../../engine/motion-elements/lib/foundations/motion/keyframe-track/README.md)的 hold/linear；这里仅给复用入口，不追记这些API已在来源影片中执行。

### 把可复用静态素材与连续表演能力分开

快剪中的包装、饮用人物、液体微观与几何框架可以分别准备，但一张图集中有多个镜头，不等于具备连续动作。移镜、缩放、静帧切换和解析泡沫只能承担各自关系；喝饮料的手口接触、角色连续姿态、液体拓扑及多视角包装身份仍需独立证据。先修同刻的主体类别、背景色与镜头阶段，再评材料细节，不能靠替换一个被指出的孤立帧宣布整段修复。

可复用准备至少区分：独立素材身份及来源/许可、图集单元与裁切边界、允许的显示尺度、是否含透明边、所需视角/姿态，以及没有覆盖的动作。既有[sprite atlas支持](../../../engine/motion-elements/docs/support/sprite-atlas.md)只选择已提供的矩形和时间，不生成中间帧、不保证角色一致，也不自动包装或赋予素材分发权。公开库保留这一方法，不携入品牌图像、生成演员、私有成片或图集；私人素材的存在本身不代表已审定为通用资产。

**能力缺口与复用裁决。** 时间采样、格网、局部变换、平面投影和图集选择已有实现，以上证据不足以再造同义模块。尚缺的是具体内容库存、连续表演、多视角/材料生产与相应艺术验证，不能把它们统一称作“缺一个动效函数”。声音同样不能由有AAC轨或技术响度通过推出自然融合；选用已有[声音书架](../../sound/INDEX.md)的事件职责与混音方法，按同版画面实际合听后再判断。新增声音代码、素材权利和听审状态均回各自原合同，不在这里重复登记。
