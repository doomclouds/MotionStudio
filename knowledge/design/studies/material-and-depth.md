# 材料与深度：外观与空间证据

只在遇到相应问题时选读。本页保留原研究的来源、观察范围、反例和未验限制，不是新资产登记或本次验证记录。通用制作流程见[参考到组合](../reference-to-composition.md)；资产 API 与状态仍以所属合同为准。

## 材质与讲述：让身份线索先于解释

本节沿用身份保持、形态呼应、图形分层、裁切与留读，只补充受限条件和失败检查，不增加新积木、通用材质引擎或已接受作品。来源及原创均只完成局部抽帧、有限检查和独审；静音原创未常速观看、未听审，数值一致与静帧构图不等于材质真实、观众识别或完整审美验收。

### 纹样中的同一片瓣，得到第二种读法

[BUCK Hermès](https://buck.co/work/hermes/) 局部纹样包含密集花卉与突兀的眼/手，不能从这些样本扩写未看的全部投影或融墙段。原创可让中央同一对片瓣张开，附加身体/触角线索，再离开仍留在原地的茎；环境保持静定，使一次事件显著。

- 同一轮廓和附着肋线、圆饰一起接受刚性变换，支持片瓣到翅膀的可追踪身份；不称拓扑形变。身份提示、脱离、行进、文字分阶段安排，不用先出现的标题替代画面辨认。
- 观者可能读成蝶、蛾或幻想昆虫，不把有限样本认出“有翅生物”说成特定物种识别。最终悬在空中就称徽记式停留，没有支撑物不称落在字标上。
- 周期动作结束要同时收敛振幅/姿态，不只检查终点位置。静态细线、交叉纹和针迹提示可形成平面工艺感，但不能冒充真实刺绣、纤维或来源的织物深度；规则镜像花园也不等于丰富不规则纹样。

### 共享构造使主体融入，识别线索使它分离

[BUCK Sherwin-Williams](https://buck.co/work/sherwin-williams) 局部动物与环境都由色卡式结构形成。原创可让固定地形与活动外壳使用同一片块图形和配色，先显露头/眼，再移动整个身体；不靠只把主体涂成背景色代替共享构造。

- 初始识别线索应确实被遮挡。可检查实际遮罩下眼部采样区域，而不只断言眼坐标在一个理想椭圆内。先露出线索再离开环境，以固定背景作参照，不混成相机拉远揭示。
- 若片块一次绘成缓存图后整体移动，验证的是外壳图案随位移不变；固定ID列表不证明每片运行时追踪，更不证明任意变形中的身份保持。用真实图像区域与背景区域分别核对，而非只数常量。
- 圆轮廓或足部早已暗示外壳，就不称完全伪装、隐形或已证实惊喜。规律拼片可能读成砖/篮筐而非立体彩纸；键控滑行和身体伸长不代表生物推进、体积守恒或接地。附近植物不是已发生喂食、奖励或交接。

### 小事讲得夸张，仍要提前建立解决工具

[BUCK FedEx Tall Tales](https://buck.co/work/fedex-tall-tales) 局部漫画分格、工具特写、尺度反差和英雄姿态提供讲述语法，不由静帧补出对白、真实经历或声音节拍。原创可先用分栏介绍风源、纸张、纸镇，再切近解决动作，最后拉远回到普通书桌。

- 珊瑚点、形状和颜色能支持跨硬切的语义身份；介绍栏与动作段另画的几何不称守恒或无缝变形，小字装饰未保留也须承认。动作段内部共同缩放才支持同一桌面由近到远，不把所有镜头都说成共享坐标。
- 压住之后保持结果，撤手后再拉远；风纹消失与纸张停止只是编排的图形因果，不是压力、抓握、空气动力学或纸材质模拟。极简平涂动作不等于来源的绘画层次、角色演出或镜头张力。
- 固定漫画框的遮罩须保护页眉/页脚；放大场景不应撞文字。各句分别核显现窗口，不能以最终三秒保持替代中段仅一秒长句的阅读验证。文字硬切与镜头/动作缓动分开记录，避免把“动画变量在变”写成“文案渐入”。

### 包装先可读，再让周围世界借用造型语言

[BUCK Lily's Bars](https://buck.co/work/lily-s-bars) 局部可见立体花朵、巧克力形态和产品揭示；原创可改用从开头即存在的包装，保护标签阅读区，周围花瓣在固定深色中心外展开。静态产品、平面生长不冒充源片的CG旅行、景深或蝴蝶故事。

- 包装扇形与环境花朵可复用造型函数，但花瓣数量、排列及中心形状不同，只能称构造词汇呼应，不称同一标识几何或纹理转移。与屏内外环境呼应去重，补充的是包面保护区与固定中心的实际验证。
- “有四个中心”的常量列表不能证明画面中中心固定。检查真实图像区域包含应有内容、多个时刻一致，并用故意移位区域作反例；另核包装区域未被花叶遮住。原生区域相等不等于有损编码像素相等或品牌可读性已通过。
- 预先存在的深色中心配合花瓣缩放，不是发芽、制造过程或食材来源证明；图形环不是光照模拟。虚构包装不代表可购买产品、配方、营养效果或商标可用。细包装字与浅色结语仍需实际大小、小屏及常速阅读复核。

### 异质媒介同时共处，主体仍只是一张位图

[BUCK Mirinda](https://buck.co/work/mirinda) 局部把产品、真人和图形文字并置；原创可让有摄影感的主体、平纸色块、印刷网点与手势线条在同一画面承担不同层级。它与跨材料轮流替换同一线条去重：差异在同时共处，不是主体换材料。

- 新生成的摄影感图像须明确为生成资产，不称实际拍摄或制造的物件。对同一透明位图做平面缩放、旋转和裁切，只保留位图身份；高光不会重新照明，也不会露出未生成的三维侧面。贴图纹理随主体走，固定画布噪点只是后加印刷层。
- 宏观裁切可以有意超出边框，文本保护则须逐处检查：字与主体、标题与页脚、字幕与网点分别有风险。最终文字/主体零相交不能证明开场标题/页脚不相撞。用实际字形墨迹遮罩及最终编码样本检查，而非只比字体框或相信作者意图。
- 前景弧线穿过主体是图形叠加，不自动成为穿过孔洞的实体带；折线装饰不是功能勾号。硬切前后使用同一位图也不建立连续空间。三次硬切不等于节拍、光敏安全或音乐同步验收。
- 修订后重生成或清楚隔离旧proof，冻结编码与当前证明图必须对应；旧图的文字碰撞不能被新版说明掩盖，新片也不应被过期proof误判。生成图增加材质对比不等于完整品牌系统、商标新颖性或全球审美接受。

导演按“片瓣改读、同材显形、漫画回落、包装保护、异媒介共处”选读本节，再核本次真实资产与编码。公共正文只保存去素材化关系和来源链接；源媒体、生成资产、原创私有成片及评审证据不随方法入库。公共播放与生成工具可用都不替代许可、人物/品牌和字体/声音权利核查。

## 材料与空间：分清身份连续和控制因果

以下沿用同纹再框、跨面图场、图形呼应、共同投影及角色姿态方法，只补各自的成立条件，不新增积木或作品。五项均为静音程序图形研究，包含参数化折面、有限透视与二维插画，不是完整物理生产。源抽帧、原创技术验证与独立有限观察分开，均未常速观看、未听审；这些证据不授予参考级质感、交互功能或用户美术接受。

### 材料后显保留同一表面，再做最终整合展示

[Panoply / someform Hyperboot](https://panoply.co.uk/cases/hyperboot) 的抽帧可见织面、蓝色环、橙色内部路径、分离部件及最终设备展示。前段已经出现品牌与部分产品，准确关系是材料说明先于最终整合展示，不是把全部身份隐藏到最后。设备宣传不构成独立疗效、制造或仿真证据。

- 与同纹再框去重：局部纹样、折线及外缘消费同一表面坐标，再让外侧绕折线抬起；区别于只把既有产品均匀缩小。固定底面、连续铰线和壁长可作数值检查，但单片跨铰多边形、后绘系带与角部开口仍须实看。
- 交替格子补齐更接近风格化表面构建，不是真实纤维穿织。三维折面经近正交投影后由二维多边形绘制，不是布料受力、封闭容器或可制造产品；中段裁切会限制同时确认全部折翼的机会，最终整物可读不能替代该过程观察。
- 编码来源也属于证据：若先写有损中间片、再解码加字并二次编码，后存PNG仍含先前压缩，不是原始渲染证明。应包含实际收尾脚本，区分历史两遍流程、单遍视觉重建及仅语法检查的重建入口；不得承诺未实跑的逐字节复现或用任意误差阈值冒充质量验收。

### 折面续纹以共同坐标核每条接缝

[NotReal Google Environmental Graphics](https://notreal.tv/project/google-environmental-graphics) 的选定短片段支持框内几何重排、局部裁切与球体明暗带来的空间读法；不是整案影片，也不证明官网所述楼梯图形已经完成现场安装。原创可把一幅连续带状图分到多块转动面，而不复用其圆、三角拼图或品牌配色。

- 与跨面图场的静态同色呼应区分：上下轮廓都由同一母版坐标进入各面，逐个铰线检查数值极限和实际编码接缝。每面单独画近似波带，即使颜色协调也不算连续映射；数值连续同样不等于光照或材质无缝。
- 带透视分母的解析平面只是有限2.5D图解，不是通用网格、厚度、铰链、碰撞或安装可行性证明。固定装饰地面若不跟随板脚投影，会让末端穿出地面提示；可移除这个错误线索，而非靠文字把它改称物理阴影。低板尖与页脚区仍需分别检查。
- 有音轨且测得近静音只描述该下载片段；官网声音署名、整案声音设计和实际听过是不同事实，不能互相代填。

### 同钟呼应不冒充输入驱动的世界

[Panoply / Whitewood FlexStrike](https://panoply.co.uk/cases/flexstrike) 的抽样有控制件近景、功能字幕、体素环境和第三方游戏片段。近景承担操作细节，环境承担统一视觉语法；不能由环境奇观推导性能。取得预览与官网标注发布片时长不同，须保留差异，不假定同一剪辑。

- 继承图形呼应和同形换面的因果边界：指针、扇片和光点若各自读时间函数，只共享影片时钟。即使动作先后接近，也只是预编排视觉关联，没有真实交互、共享控制状态或功能验证。改标题不能补出不存在的输入依赖。
- 区分固定刻度与旋转指针，分别记录指针停止、最后成员展开与回拢完成的时刻。章节标签不是每个对象的精确状态边界；光点在控件不动时仍继续，正好反证它并非操作结果。
- 远景小控件缺少机制证据时，不能说完成了参考式功能讲解。小字可读、线条锯齿与有限平面着色单独保留；不把示意空间盘称可售设备，也不复用游戏角色、商标、原声或广告功效。

[NotReal / JP Morgan Payments](https://notreal.tv/project/jpmp) 的环形物件抵达选段只支持对象注意与抵达的观察。迁移为物件先落定、固定条后到位时，实际接触位置和时序须同时核；“后发生”不是“前者触发”。纯时间常量比较不独自证明画面接触；若固定条不消费到达状态，就明确是预编排，而非事件门。已有变换与有限残差进入绘制可算真实消费，不能由残差名称推断真实弹簧或有机物理；音轨存在与数值检查仍不代实际听审。

### 静帧材料与陈列只迁移已看见的关系

[Mana / Origami Stories](https://www.mana.tv/work/origami-stories) 可观察连贯折面、纸边与安静背景；[Mana / Pack / unpack](https://www.mana.tv/work/fjallraven-and-jlp) 本次单张照片可观察大小包袋的交叠与投影。项目标题或页面写stop-motion，都不能补出未看过的折叠/包装操作和声音；不要从裁切照片反推完整台阶、相机或光源几何。

- 原创两片恒边长折面可共用折脊并滑动地面端点，让空隙成为主体；这与固定一面、绕固定世界轴折叠的验证不同。面色随时间插值而阴影按方向投影时，不称统一物理照明；程序纸纹、薄边描线和几何长度不证明纸张力学或真实厚度。原创动作是新编排，源静帧只支持材料/构图观察。
- 原创纯静态器物陈列可改变大小与支撑面，核实际底部落在台面投影内，不只靠阴影掩盖悬空。器物彼此不交叠时，层次主要由台座和高度承担，不能说复现源图密集遮挡。统一名义宽高的对照同时改变比例、轮廓和依赖阴影，且不同口沿使实际外框未必等大；不是单变量尺度消融或审美优胜证明。静态产物无时间/音轨可验，不把它归为静音影片或已验动态。

### 转侧见层用厚度和遮挡检验层叠身份

[NotReal Microsoft 365](https://notreal.tv/project/m365-brand-refresh) 的选定Word图标转台片段可见前牌、背层及侧边随旋转错位、遮挡后返回。它是整案的局部组件，不是完整品牌更新。可借旋转改变可见深度的关系，不能复制字母标记、蓝色横带或原图标构造。

- 原创不透明环面可显式建立前后层中心、厚度和内外壁，再旋转、透视投影及按面绘制。侧角分离和背面大层遮住小层共同支持空间关系，不应仅从正面同心轮廓判断，也不笼统降为二维平移。
- 同时把层间距归零、厚度缩小，是深度线索组合消融，不是单变量试验。对照差异只说明这些渲染成分有贡献，不证明观众理解、物理因果或参考材料精度。
- 平均面深排序是有限画家算法，不保证任意相交网格；不透明分面、图解阴影与真实透明/折射分开。原生PNG与当前渲染器可以核一致，编码帧另核压缩误差，不把一个作品的单遍流程套给其他作品。源局部近静音与整案声音署名并存，仍未实际听审。

### 近递姿态让前景大小承担方向，而非只把手横移

[Giant Ant Estrella Damm Padel](https://www.giantant.ca/estrella-damm-padel) 的开发GIF样本有草图/色块姿态以及相对身体放大的近手和球拍；开发阶段切换不是整段广告表演，不能推断完整摄影机、节奏或声音。原创可换成固定场景中把独立道具递近的插画。

- 与既有固定肢长及共同投影去重：相机、身体和背景不动，手与道具共享世界锚点，由深度改变两者大小。保留投影关节中心、移除深度缩放的对照只核渲染贡献；不要把全局放大或较大侧移误当充分的向观众递出。
- 固定臂长数学正确仍可能让肘明显下坠。若修正改为紧凑关键路径与可变段长，必须删除旧定长声称及测试，明确是风格化姿态插值，不是自然骨骼或真实解剖。修复一个难看中间姿态，不等于完整角色表演通过。
- 躯干与背景是二维插画，道具为朝向相机的billboard时，共享锚点和下缘手指交叠只支持托住的视觉联系，不证明手腕旋转、握力、碰撞或受力。没有接收方、眼神与全身预备，就只称递出并停住，不称完整交接；GIF不提供完整广告音轨。

按“材料后显、折面续纹、同钟呼应、转侧见层、近递姿态”进入各自反例。方法是对既有关系的限定，不证明资产调用率提高或新增通用机制。公开正文只保留去素材化判断与公开来源链接，不收入私人标题、影片、帧、代码、报告、提示词或哈希；品牌、游戏、字体、原声音像权利分别核定。数值、抽帧、常速运动、实际听审、用户接受不得合成一个通过标签。

## 材质对比与姿态须分别核显示和行为

沿用异媒介共处、静帧陈列、功能同锚与动作意图边界，只补下列反例。源静帧、开发GIF选帧和页面制作说明不能合成一次完整观看；纯静态程序图与生成栅格均不是静音影片。有声概念片的编码、音轨存在与数值同步也不代常速观看、实际听审或用户接受。

- **控件回执。** [Gunner / Google Home App](https://legacy.gunner.work/googlehome/) 的插画表与GIF选帧支持界面状态和环境语法的对应，页面所述Lottie生产不证明当前应用功能。原创可由同一采样值绘制控件和房间色调，并在接触阶段直接消费原生控件返回的 thumb 放置指针；与只让两者各自读时钟、或仅把回执存起来区分。接近末点、拖动起点和释放起点要分别连续；显示整数可由连续值四舍五入，拖到终值后保持接触也不必立刻释放。sampleMotion/withMotion 的有效区间和实际绘制职责分开，闲置求值不计画面贡献。静态控件仍无真实输入、设备连接或键盘功能；同值调色不是物理照明。
- **静态接触。** [Gunner / Knandu Apparatus](https://legacy.gunner.work/knandu-apparatus/) 的开发样本支持细线肢体与大色块的尺度反差，不提供完整动作顺序。既有 solveTwoLinkIK 的返回关节和端点若进入绘制，可证明静态姿态消费；把中心线端点约束到表面，不等于线宽不越界、自然受力或真正推动。还要检查头身遮住多少肢段，不能由关节可达推断完整开放轮廓。静止脚标与地线相接只是视觉落脚，不证明平衡、摩擦、重量或一段角色表演。
- **粗细异材。** [Gunner / Mesh](https://legacy.gunner.work/mesh-1/) 的角色图与过程GIF选帧支持平涂身体、粗糙地形和局部亮光的反差，不因文件名就认定扫描方法或物理材质。原创可用 transformPoint 实际返回坐标放置人物，地形另由自绘颗粒和面色构成；不是所有可见细节都来自引擎。鞋底与灯底的接触边端点应检查落在对应地形/台面多边形内，而非仅处于相同纵向范围。二维包含关系和装饰阴影不证明真实接触；脸未朝下、手未触纸时，只称停在地图旁，不称已经读懂、握住或导航。
- **冷暖修补。** [BUCK / Woolmark](https://buck.co/work/woolmark) 的环境与物件静图支持室外冷色、室内暖区和材质一致性，不提供修补动作。原创静物可让补片、边针脚、散线和工具共同提示暂停的工作；灯比补片更亮时，不宣称补片独占焦点。提示词要求工具插在针垫中，成图却放在桌上，应记录偏差而非以文字覆盖像素。织物、陶瓷、金属、木纹的生成外观不证明制造尺度、针线连续或布料物理。
- **同柜异材。** [BUCK / Zapier Motion Library](https://buck.co/work/zapier-motion-library) 的材质方体、透视人物和草图/成图静图支持异质表达由统一边界组织；页面描述多支动画不等于已观看全套。原创可让不同概念分别采用泥、纸、织物和画线，同时借重复把手、层边界和柜体保持识别；与同一形状换表面区分。固定抽屉伸出差异不证明抽拉顺序，柜脚阴影不证明导轨、承重或防倾倒。没有输入或状态反馈的家具图不是实际UI。

生成图只记录栅格产物、提示词及已知生产方式；未核原始调用时，提示词自述不升级为独立工具来源证明。没有网格、材质图、绑定或原生调用，就不把三维外观与提示词计为可重复渲染资产或积木消费。现有API实际消费、局部自绘和纯图像生成分开记录，不用调用次数构造利用率。公共正文只收去素材化方法，不收私人作品标题、媒体、源码、提示词或报告身份；参考可见不授予素材重用权。
