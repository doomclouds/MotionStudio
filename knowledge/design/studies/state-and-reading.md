# 状态与阅读：因果、读窗与顺序

只在遇到相应问题时选读。本页保留原研究的来源、观察范围、反例和未验限制，不是新资产登记或本次验证记录。通用制作流程见[参考到组合](../reference-to-composition.md)；资产 API 与状态仍以所属合同为准。

## 状态与叙事：让变化兑现具体关系

以下沿用现有时间坐标、共享投影、身份桥接和接触约束，新增的是适用条件与反例，不登记新积木、真实产品或已接受作品。参考与原创只经过局部抽帧、有限数据检查和独审；早期原创研究为静音，新增界面研究含独立合成声音但未实际听审；均无常速观看验收，不能把模型一致或静帧清楚写成完整节奏、交互或受众验收。

### 移动序列位置，不偷换所选来源

[Kdenlive 编辑手册](https://docs.kdenlive.org/en/cutting_and_assembling/editing.html) 的 Remove Space 动图显示空隙右侧的成对片段向左靠拢；只是局部操作参考，不是整套编辑器验证。原创说明可让关联轨道消费同一片段记录，后续片段一起移位而上游保持不动。

- 所选来源时间应由片段ID、source-in和局部offset派生，序列游标由该片段当前放置位置加offset派生。仅在默认例里让固定数字相等不算真实绑定；改source-in、片段起点及所选ID，确认状态、标签与预览选择真正跟随。
- 分开验证时长不变、下游邻接、空隙与总终点变化、关联轨道共用坐标。相同预览裁图只证明画面保持；若预览是每片段的一张原创插画，就不能称按来源时间解码、视频寻帧或真实播放。
- 固定片段/插画映射不推广成任意元数据编辑器；项目栏和片段缩略图仍可能依赖位置列表。闭隙过程的插值是解释性布局过渡，不是NLE逐渐修改时间的操作实录；“关联声音占位”不含音频、波形或声画同步证据。参考许可按手册实际声明保留，不由方法研究转授所有素材。

### 播放示意中把片内时钟与影片时钟分开

沿用上一节的来源身份与序列坐标原则；这里的细化来自界面重绘后同刻帧修订，不新增播放器或视频解码机制。影片可能先演示录制，再进入编辑和播放界面：影片已经走过很长时间，屏内预览却才播放几秒。先声明时间标签属于影片、序列还是所选片段，再用同一局部时间决定标签与游标；若只是手工相位映射，不能称来自真实播放事件。

- 预览是人物、景物与字版的合成时，缩略图也应保留这份合成身份，不能只用其中一张风景图代替。复用自己渲染的合成画面裁图可避免内容漂移；只重复同一静态裁图，仍不是不同来源时间的缩略帧提取，也不能证明人物连续表演。
- 在所选片段起止、标签进位和工具栏遮挡前后分别核：游标是否仍在当前片段范围内、标签是否相应推进、预览和可见缩略图是否属于同一内容。局部修订时只更换需要修正的状态，未受影响帧的像素相同可作回归证据，不能作整片质量证据。
- 边界反例：用重排后的影片绝对时间推进屏内游标，游标可能落到另一个片段而预览没有切换；只修数字而不清除旧游标，会同时保留两个互相矛盾的播放状态。这些是绘制层的一致性检查，不证明寻帧、暂停/恢复、音轨同步或真实编辑器功能。

### 多语言并排时保留数据关系而非重复同一文字

[BUCK / LinkedIn Year In Review](https://buck.co/work/linkedin-year-in-review) 的同刻抽样可见不同语言的同类年度结果；工作台、状态图和语言控件则承担制作过程的叙述。这里仅提炼画面中的对照关系，不推断原作实现，也不把独立重绘的工作台当作真实工程文件。

- 并排语言版先固定同一指标和数值，再分别检查标题、正文、换行及揭示阶段。只换语言标签而保留同一正文不能表达本地化；只把每列做成不同花纹，也会掩盖它们是同一结果的不同语言版本。较长文本在目标宽度下的换行、溢出与读窗须逐列检查，不能由一个语言版外推其他语言通过。
- “可能路径”的计数动画、画面上展示的卡片数量和实际实现的状态组合是三种量。演示计数到达终值并停留，只证明画面上的数值编排；没有枚举与运行实际状态组合，就不能把数字当作已实现功能数量。样本字体、节奏和终点对齐也不认证组合空间或真实用户数据。
- 若有真实功能目标，另验语言选择返回值、数据绑定与切换后的状态保存；固定片中的控件、表格和状态图只是可见内容。此方法当前依据有限静帧观察、作者修订与源码核对，未做不同内容制作迁移、常速阅读或语言用户测试，保留为方法候选。

### 隔线成为隔墙后，先开放再证明可以通过

[BUCK Get an Airbnb](https://buck.co/work/get-an-airbnb) 抽样可见视频格子、分隔房间及持续人物身份周围的环境重构。原创可从同一个俯视世界转向斜视，让已有高度变得可见；不是墙物理长出，也不同于把两个独立视图合成共同投影。

- 保留地板、隔墙和物件的同一世界坐标与身份，先让隔墙归零并停留，再允许物件跨越旧边界。用物件足迹与有限墙体的实际相交关系检验全部移动状态，并在同样位置保留闭墙高度作正交叠反例；只看墙消失不能证明空间可用。
- 最终物件应完整容纳且彼此留隙，旧地板缝可保留为历史痕迹。永久撤去内部隔墙、让已有物件聚集，与临时开门接纳新物件去重；共同平面和顺序纪律仍是既有做法。
- 统一仿射投影不等于标定相机或物理透视。按地板、墙、影子、主体分层的场景专用排序，在当前路线可用，换视点或靠墙可能失效。滑动不是滚动，画出的接触影不证明重量或物理接地；聚集也不证明实际协作完成。

### 从叙事身份进入界面，不把故事说成产品记录

[BUCK Asana Silos](https://buck.co/work/asana-silos) 局部可见工作区覆盖叙事环境，再进入产品页面；不支持“筒仓真的变成任务卡”。同品牌另一支作品是关联来源，不因品牌同名就当同片重复，也不把有限索引未命中当成全档去重。

- 原创可让角色颜色、脸与职责标签保留，把原平台解释为卡片、角色解释为负责人，再补交接箭头。先共处、再出现依赖关系，比单纯换成UI背景多一层关联；共享背景展开中尚未容纳所有卡片时，不称已经完整合框。
- 数值缓动不代表可见事件渐变。文案由阈值一次显现、完成勾同步硬显、结语另一个阈值切入时，逐帧枚举真实首次出现，不能写成逐项完成或整个时间段渐入。
- 虚构界面应明确标示概念片/非产品录屏，但声明不等于功能正确。箭头与勾号只表达编排；若状态字仍保留ready、没有可见共同交付物，就不能称严谨状态机或完整协作因果闭环。短结语、细小浅色标签仍需常速和小屏复核，不把主张句当作工作成果证据。

以 [NotReal / ServiceNow](https://notreal.tv/project/servicenow) 选段的工作环境与屏内任务为对照时，环境道具只交代语境，任务变化须在屏幕里可见。原创可让同一图案从修订界面延续到桌面纸样，但屏幕文字内移幅度较小时，状态字可能承担主要解释；不能仅凭坐标变化宣称观众已看懂。预编排修订和纸样显现不是实际输入、打印、AI能力或效率证明，像素距离不能冒充印刷尺寸。

### 同页滚动让章节提示消费实际位置

[NotReal / Microsoft Edge](https://notreal.tv/project/microsoft-edge) 选段显示稳定外框与不同食谱章节；局部截图不证明DOM、粘性侧栏或真实输入。编辑层级和滚动本身沿用既有方法，不新登记机制。

- 固定viewport从同一份长文档取裁片，章节提示和位置标记由同一scroll派生，而非各自按时间切换。若依赖有疑问，固定时刻只改变scroll，核裁片和提示一起改变；反事实夹具不是可用导航。
- 说明章节切换采用顶部还是最近章节等约定，检验各停留点内容完整、裁片不越界。移动中有意裁过标题不等于停留点缺字；常速阅读舒适仍须另验。示意位置标记不是浏览器滚动条尺寸算法。
- 未编码渲染帧可核裁片像素相等；编码帧须另核压缩影响，完整解码不证明无损相等。栅格裁切研究不等于网页、键盘/焦点、响应式或真实交互，未常速、未听审，不据此宣称产品可用。

### 动作后果靠连续遮挡和独立读窗兑现

[NotReal / Gogoro Network](https://notreal.tv/project/gogoro) 与 [NotReal / Animography Insane](https://notreal.tv/project/insane) 的短选段分别提供人物与服务道具、细线手势与实色物件的关系；[Mana / Wonderful Life](https://www.mana.tv/work/wonderful-life) 本次只有官方静帧，提供家庭道具与局部暖色环境。前两者抽帧不代常速，后者不能推出原片动作、剪辑或对白；声音署名和页面介绍不代实际听审。

- 角色进入容器/车厢时，同一坐标路径连续仍可能被外层全遮挡，随后内部绘制又突然接上。检查交接窗口的实际编码帧，让外部与内部裁切按同一角色状态衔接，保留门框等合理遮挡；不要求角色永远无遮挡。开口收至零时，主体和附属玻璃/描边尺寸一同核零，负宽绘制可能留下反向细条。动作关系回到[角色接触与可见性](../../../skills/motion-film-director/references/character-performance.md#4-设计接触余势与非等时姿态)，不新造运动机制。
- 手与工具已经握合，可以研究下压、保持、释放和留下痕迹，但不能称演示了拾取或手指闭合。印迹须在工具遮盖范围内，抬起才逐步显露并在工具离开后保留；布尔置位的时刻不等于首次可见时刻。物件放入容器后被前壁/盖子遮住，与直接删除对象分开；持物时共享手点、释放后保持世界状态，仍是编排而非压力传墨、碰撞或真实抓握。
- 归位还须核沿途净空：同一物件先抬离邻物，再移至空位上方、降低、停稳和撤手。检查全部相关状态与关键邻帧，分清名义二维轮廓不相交、最终槽位容纳与实际可见接触；前景边缘遮住底部不等于物件消失。放置完成先于撤手，撤手后物件世界状态保持。IK端点与段长正确不证明解剖抓握或全身碰撞；站定动作不冒称走动。此为既有身份、接触与释放规则的补充，不是新角色机制。
- 结尾结果与解释应各有空间。桌腿、场景底边或阴影不能侵入专用字幕读窗；若只修背景分隔，核修订未改变此前动作，再有针对性复查当前编码。清空等待区、留下痕迹、盒盖关闭各自支持有限后果，不自动证明到家、制造或受众理解。二维插画、合成声未听审、未常速和未用户接受分别保留，不把有声候选称为静音通过。

### 同一肢体跨场景改变意图，接触仍需兑现

[BUCK A Tiffany Holiday](https://buck.co/work/a-tiffany-holiday) 抽样以重复珠宝鸟连接不同情境；不能由孤立帧推断它促成每次人物互动，音乐署名也不是听审。原创可沿用一个角色的特征与手臂画法，在晨起伸展、电车扶稳和晚景轻触中改变目标。

- 先建立场景线索，再解释手的意图。固定脸部特征、衣物和绘制代码支持有限身份连续；常量签名本身不证明感知识别。硬切介绍的新同伴不是已实现入场，三个生活片段也不是连续旅程或match action。
- 手应绑定实际吊环或肩/围巾边锚点，躯干移动时关节仍须可达；固定双段长度与反序重放只检模型。固定脚尖/窄地面条带不能证明整腿像素不变、身体平衡或握力。肩边轻触不等于支撑或拥抱。
- 凳沿有身体而腿直落仍可能读成站立；明确大腿、小腿和支撑面的图形关系比多一个坐姿标签有效，但不是人体力学认证。章节标题会辅助伸展、平衡、亲近的解读，不能据此说无文字也传情。短尾句的静帧可读仍需实际留读验证，来源质感与镜头魅力不由身份保持自动继承。

### 跳过不是尚未就绪，汇合须消费相同状态

[ossia 时序与同步文档](https://ossia.io/score-docs/examples/basics/timemodel-patterns.html) 区分被条件排除的分支与尚未启动的前驱；[脱离主时间线触发](https://ossia.io/score-docs/common-practices/3-out-of-time.html) 也说明横向摆放不自动决定执行。界面截图里的波形、曲线或设备名不能证明声音、设备控制或这些时序已实际运行。

- 有限说明模型可从同一分支表派生参与集、状态字、进度与汇合释放，排除分支不阻挡，仍需执行但未开始的分支继续阻挡。明确完成、排除、未开始与运行，不把传输游标位置当完成。
- 改skip标志、结束时间和分支顺序，检查同一变化传到状态、进度与释放；边界前一个可表示时间与确切边界分别测试。检查仅默认例的最终released，不足以证明按ID对齐的每个分支状态也一致。全部跳过如何处理须明确，不偷偷补语义。
- 固定绝对时钟、已知结束时间和两条轨道只是编排的教学图，不是实时条件执行、取消、重入、未知完成或min/max时长引擎。模型顺序不变性不保证按首元素接线的渲染器可任意重排；固定整数刻度不等于任意小数时长布局。实线是既定依赖，不是观察到的消息流；虚线排除行是标记，不是执行区间。

按“来源与序列、隔墙通行、概念界面、跨景手势、跳过与等待”从本节进入已有方法，再对本次实际输出复验。这里保留的仅为去素材化决策条件与公共来源链接，不包括私人影片、截图、生产源码或评审报告。部分源许可明确、部分未建立开放授权，均不因研究完成而自动取得品牌/字体/声音重用权；模型、编码、观看、听审与用户接受继续分开。

## 尺度与阅读：先兑现关系再分配注意力

本节复用连接先于通行、同形比例、遮罩显现、关系追溯与阅读窗口，只保留新补证和反例，不增加新积木或已接受作品。五项有限静音研究及独审均未常速观看、未听审；状态、原生像素、有损编码、观众阅读和审美验收不是同一道门。

### 微缩世界先完成一件可见的小事

[BUCK Oracle Wordmarks](https://buck.co/work/oracle-wordmarks) 的局部微缩场景支持尺度反差与小动作注意力，不足以补出未观察到的工程完成故事。原创可先让桥完全落平，再让等待的交通主体通行，到达后才给身份文字；这延用先撤障再通行，补充固定视角下结构本身也须读得出。

- 开场桥叶若近乎侧对镜头，状态正确仍可能不知它是什么；改变初始姿态、显露厚度和底面比堆装饰更直接。厚度轴须随桥叶共同旋转，检查实体角点间距，而不只验证顶面长度。中途自然变窄不等于开场必须难辨。
- 大地面与整栋楼不能仅按平均深度排序；逐像素深度可解决当前正交三维场景的穿盖问题，但局部碰撞包围盒、相机零空间和样本检查不认证任意场景。平涂、固定地面色块不是PBR、投射阴影或结构工程。
- 建筑轮廓差异与主体腰线能改善辨识，不能自动补足人物动机或材料层次。最终完整文字的短暂曝光只作时长记录；拟定环境声和动作提示音不是已制作、同步或听审通过的声音。

### 从可见细节取单位，不从邻近凹槽偷换比例

[BUCK Google Pixel 4](https://buck.co/work/google-pixel-4) 的局部侧面控制件与胶囊图形并置，支持硬件细节到图形的呼应，不给出可恢复的原作精确比例或完整发布片节奏。原创可保留同一可见控制件完成特写到整体，再由其中心派生轮廓副本。

- 明确取样的是实际着色轮廓，不是背后尺寸不同的凹槽。先核原生图像中的真实边界，再验证副本全程纵横比与最终线性倍率；故意以旧的错误轮廓作反例。坐标边界倍率不等于像素数量、面积、描边重量或感知大小。
- 副本离开时原控制件仍存在，就称图形抽取，不称零件拆卸或物理飞行；起点重叠也不冒称无碰撞。整体示意仍是二维缩放/平移与平面阴影，不是可用产品、工业测量或三维相机。
- 最终单帧若标签靠近整个设备，应说明单位是控制件而非整机；动画提供的上下文不能代替独立封面识别。它与宏观揭示、形态呼应去重，增量是可声明且核验的单位边界。

### 逐词强调之后，还给完整句子一次机会
