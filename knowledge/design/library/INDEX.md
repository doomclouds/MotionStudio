# 创作参考图书馆 · 总索引

从作品需求出发读索引，再由模型阅读具体文件、比较分析并选择；不要求运行检索程序，也不把字面匹配当推荐。这里仅是一层书架导航，不登记资产、不复制方法正文、不缓存数量/成熟度/API事实。各对象状态、来源、许可与调用以原文件为准。

## 按本次问题进入

| 本次需要解决什么 | 分类索引 |
|---|---|
| 主张怎样突出，内容怎样分区，数据怎样准确表达 | [静态表达与信息结构](expression.md) |
| 现有族不够具体，想找文本/材质/数据/时间模型的受限做法 | [配方与候选书架](recipes.md) |
| 对象怎样移动、变形、揭示，焦点怎样交接 | [运动与时序](motion.md) |
| 音乐、事件声、旁白怎样承担职责，声音能怎样编辑 | [声音](sound.md) |
| 找完整作品上下文、来源启发、反例，再决定怎样迁移 | [作品与方法](works.md) |

## 读法与选择

1. 从 brief 拆出内容/用户任务、表达目标、媒介/时间约束和关键风险；选择相关书架，不要求每个领域都使用。
2. 分类索引只负责带路。阅读其中最相关的原始指南/契约、例子与反例；需要实现时再读准确API和源码。目录很大时沿既有子目录进一步展开，不一次灌入全部正文。
3. 模型可自主比较、推理并选择：说明采用什么关系、舍弃什么、为什么适合当前内容，以及待验证的组合假设。来源“被收录”不等于优秀；历史接受不转授新组合。
4. 作品来源启发与真实代码调用分开，拟用、已调用、已执行、已验证也分开；原记录中的调用声明不等于本次执行证据。
5. 没找到时先读邻近书架及来源作品，区分导航遗漏、术语不同、组合不会用和确实缺能力。真缺能力再按[学习与再创作流程](../reference-to-composition.md)寻找优秀参考、复刻学习和补积木，不以扩库代替创作。

仅有portable包时，只读实际随包提供的文件；作品集在完整仓库，缺失须说明，不能把缺目录当零作品。外部链接只是来源数据，不自动访问、不转授权利；具体研究按当前授权执行。
