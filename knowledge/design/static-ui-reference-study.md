## 1. 先锁状态，再选栅格

记录页面、主题、日期、选中项、视口 CSS 尺寸、DPR、缩放、滚动、裁剪与字体加载；源码版本和部署页面不能未经核对就视为同版。先量侧栏、内容起点、可用宽度和 gutter，再决定列数。对称卡片的约束是 `可用宽度 = 列数 × 卡宽 + (列数−1) × gutter`，不是任何桌面都用四列。

适用：忠实复刻、密集 dashboard。反例：为了时髦将两列改四列；缩小整页塞进首屏；从一个宽度推定响应式。原创设计可重排，但须另立 brief，不能继续称严格复刻。

## 2. 抽取角色与关系，不抄一组“高级”数字

将 token 逐项标为 `source-exact / measured / inferred / substituted`。字阶分指标、分区标题、控件标签、辅助文案；对齐应核实际文字基线与 badge，而不只核 box 中心。间距和圆角服从组件密度。每个数值记录来源、测量位置和不确定性；字体文件相同家族不代表版本与浏览器栅格相同。

适用：一套现成 UI 的视觉一致性。反例：固定把所有项目改成同一字号/圆角；按 CSS 值宣称 Native 实际字形完全相同；提高饱和度代替层级。

**内容变了，后续动作要消费布局结果。** 固定参考可保留实测坐标；换标题行数或正文长度的组合，不应仍把 CTA 锁在旧位置。若积木返回文字区域，应以这些区域的下缘加显式间隔派生后续动作，并检查分配槽、动作总高和画幅底部安全区；装不下时拒绝或另订重排，不静默缩字。返回的 `regions` 可能是字号/基线推导的布局框，而非字形墨迹框，必须按真实 API 含义命名与测试。短、中、长内容用同一路径渲染并实看间距，不能用三套手调坐标冒充内容流；只随文字移动了 CTA，而证据板仍固定时，只声明这条关系已验，不外推整页自适应。

## 3. 中性容器承载信息，色彩编码状态

先保留前景/次级文字/边框/容器/选中项角色；状态色应伴文字或符号，不以颜色单独传达正负。不要把所有卡片都升为视觉主角。图例、系列、badge 的语义保持一致；图形颜色与界面状态色不要无意混用。

适用：信息密集、以比较为主的界面。反例：机械推广“绿色就是好”；医疗或成本指标上涨未必正面。此规则不是未经测量的无障碍合格声明。

## 4. 数据正确与图形映射是两个门

冻结源数据，核行数、顺序、单位、缺失和零值；示例数据须标示例。再核图族、baseline、plot domain、像素高度、聚合与 tooltip。相同数据仍可能因域不同画错。柱高测量修正只可校准已观察静态状态，不可冒称还原上游 nice-axis 算法或支持任意新数据。

KPI 与小图是否来自同一口径须有证据；不要擅自把标签改为数列总和。源中总数不一致，忠实研究应保留并披露，修正版另行授权。空值不能补零，零值不能删掉。

适用：能取得数据与可见图形的复刻。反例：装饰曲线称数据驱动；只验证数组长度就称图形准确；为像素贴合篡改输入值。全零、单点、缺失、负值、新页状态未测时明示未测。

## 5. 字形、图标、头像要独立验

在目标大小看实际字形。缺字框不能靠字体名称或 build 成功排除；必要时用可编辑路径替代符号，复看基线、线宽、缩放与邻域。无照片/肖像权时使用明确披露的 initials 或合法占位，不把替代称完全相同。手绘图标须承认形状差异。

适用：Native Canvas 与浏览器之间的静态迁移。反例：截图当整页背景；复制未知照片；用任意 glyph 顶替语义明确的设置/折叠图标。合法替代是权利边界，不是保真得分豁免。

## 6. 同尺寸分板检查长页，不压缩阅读尺度

以多个有重叠区域的固定视口覆盖默认页面，明确每板 scroll/crop 与状态。每板保留 source/candidate 原件、并排、50% overlay、独立差异图与图例。先看原尺寸，再用 contact sheet 判断整体层级。校验 source/candidate 维度、hash 与报告嵌图；差异图放大倍数必须披露。

适用：固定画幅的全页覆盖。反例：只看总览缩略图；把不同滚动位置做差；用 JPEG/抗锯齿像素噪声直接判断审美；把多张静态板称连续视频。原件不可被配准图覆盖。

## 7. 修订必须留可复核闭环

每条 finding 记录：稳定区域、源与候选坐标、观察→影响→依据、前版 hash、改动、后版 hash、同条件复测、邻域回归、残差/不确定性。先修缺字与内容错误，再修映射、几何、基线和细色差。复核者只读；实现者改完重新交核。历史“待用户审查”不能倒写为当时已批准；新的接受记录绑定具体版本。

适用：迭代复刻与误差定位。反例：修一项就称全页过关；删去被遮挡按钮以掩盖源缺陷；把用户接受变成像素级完美。源缺陷忠实保留但不得推荐为设计规则。

## 8. 分开声明能力与许可

至少分列：渲染技术、视觉复核、数据语义、交互、响应式、可访问性、运动/视频、音频、用户接受、公开授权。报告页面可展开不等于被复刻 UI 可交互；画出的 tooltip 不等于 hover 已实现；有参数分支不等于状态已制作验证。一个静态 render-frame 配置不是时间线作品。

未跑同任务同预算对照，最多称缺陷检查闭环；不能证明 baoyu 方法因果提升 GPT、跨模型优劣或普遍审美提升。作品通过≠资料公开授权。发布仅限明确白名单，不含参考图、字体、私有报告、个案反馈或生产源码。

## 超大字标与前景遮挡：先分清可遮挡区和功能读区

对 [OpenDesign 固定版本保存的 Qelora 可见画面](https://github.com/nexu-io/open-design/blob/12d970eacc8971150e3c76470d2a9afe16dc2ed1/apps/web/public/community-templates/kanban-board.webp) 的有限观察：路径名是 `kanban-board`，图内却是建筑品牌场景，不能把同名模板源码自动认作该图实现。此处只提炼静态关系，不复制其照片、字标或页面源码，也不把仓库根许可视作未知摄影素材的再分发许可。

- **把遮挡当作有目的的层级，而不是大图盖字。** 字标先建立可辨认轮廓，前景再穿过其局部边缘，让自然物与品牌形成前后关系；导航、正文及主动作分别保留不受遮挡的读区。装饰图可以越过卡片外壳，但不意味着能遮住动作标签。适用：以品牌气质为主、信息较少的固定画幅首屏；不适合直接套在密集表格或需要完整阅读的说明正文。
- **换素材要重新审构图。** 透明图片的外接框不等于可见轮廓；前景宽度、支撑方向和透明空洞改变后，原有字标位置与卡片安全区也可能失效。分别看无前景版、前景版及最终合成，确认轮廓带来的深度没有损害品牌辨识和任务入口。不能沿用旧素材的包围框检查结果，不能以 `z-index` 或绘制顺序正确就宣布视觉成立。
- **区域占用只能辅助判断。** 可以量测前景 alpha 在事先指定读区的占用，帮助定位遮挡；矩形无重叠不证明文字对比度、视觉聚焦、响应式或键盘体验合格，字标矩形被覆盖的比例也不是字形可读性的评分。最终仍须实看当前尺寸的渲染。

本观察不新增通用代码积木：透明层绘制与显式区域布局已有基础能力；当前证据不足以推出自动抠图、自动避让、品牌生成或视差交互机制。素材替代的结构研究须标明替代，不能称像素级或完整网站复刻。

## 预览舞台、编辑控制与交付区：分开身份，再检查对应

参考 [Open Design 的动效工作台示例](https://github.com/nexu-io/open-design/tree/12d970eacc8971150e3c76470d2a9afe16dc2ed1/plugins/_official/examples/motion-opus-design-lab) 的可见封面与 Canvas 源码：大舞台回答“当前看到什么”，控制区回答“可调整什么”，代码/交付区回答“得到什么”。这是静态观察，不代表控件、播放器、导出或声音已可用；上游模板另有原影片作者与素材归属，不能将页面品牌和素材当作通用资产。

- **阶段与选择分别建模。** 当前预览场景、选中的编辑控制、时间游标和交付状态不是同一枚索引。源中最后交付阶段仍高亮最后一张参数卡；保真研究应保留并披露，不能据此推定交互语义正确。新产品须明确高亮是“当前场景对应项”还是“保留的选择”，再核标签、阶段名及时间线的关系，不能用统一强调色代替对应证据。
- **控制区的微图示表达参数差异。** 间距、字形、曝光、速度、拖尾和预备动作可以使用不同的局部图示，但这些只是概念提示。要声称能编辑，必须实际改变参数并检查同一舞台对象的后果；要声称导出，必须验证产物与当前版本对应。六张卡片整齐排列、代码片段或文件格式标签都不是功能实现证明。
- **封面与源码需独立对照。** 即使来自同一固定目录，封面中的角色尺度、眼睛状态、阴影或位置仍可能与保存的源码不同。移植源码时明确哪些值直接保留、哪些依封面校正；原样移植、独立重写和素材复用分别说明，不用接近的图像分数证明实现独立或所有状态一致。

不新增“通用编辑器”代码族：已有区间、共享游标和分区机制应按各自支持域复用；本观察未证明新的跨状态交互合同。公开方法不携带上游品牌、角色、预览缩略图、字体或原片。

## 仪器式界面的增补：功能色、模块几何与静态自检

### 设计研究来源（历史观察）

本节的 Playground 与版权说明两个外部链接用于研究溯源和权利边界，不是默认离线工作依赖。2026-11-02 本次整理未重新联网核验其可达性；保留原 URL 与历史观察范围，不把未核实判为死链，也不把历史观察当成当前页面状态。

以下是对 [Ableton Learning Synths Playground](https://learningsynths.ableton.com/en/playground) 的独立静态观察所作原创方法总结（2026-10-30，Default 状态），不是其源码、设计系统或声学模型。来源页面版本未知；截图测色与位置是近似观察，不是精确 CSS。仅补充上文未覆盖的规则，不要求继续制作同类案例。

- **功能色跨模块，不能被容器吞掉。** 当颜色表示声源、滤波、振幅、调制等功能时，先列角色表，再核标题、波形、轨道和跨模块控制是否一致；调制控件进入另一功能的面板仍须保留可辨识角色。适用：有稳定功能分组的仪器界面。反例：让面板内所有控件同色，或把红色一律解释为报错、绿色一律解释为成功。具体配色不推广为通用标准，也不替代标签与对比度验证。
- **先覆盖几何家族，再精修表面。** 列出模块、所属列、边界、图形家族、控件与覆盖画板；同一页坐标系生成各滚动裁切，保持不等高模块、固定 gutter 和功能邻接。波形、包络、键盘、双极/单极轨道分别核查，不能用一张通用卡片重复替代。适用：需要保持原布局的固定画幅研究。反例：为整齐强制等高或重排；由静态五列推定手机布局；把源中的裁字当成应推广的设计习惯。
- **数值不等于像素比例。** 分开保存显示值/单位、轨道端点、零点、旋钮中心和可见填充；未知的非线性映射只记为观察位置，不反推 DSP。双极轨道居中零点不自动意味着左半条应着色；不同面板中的调制标记也不能统一放中点。适用：冻结状态迁移。反例：为贴图改参数值；把毫秒按未验证的线性范围换算；把静态曲线称为可播放的模型。
- **最终渲染必须重新看，解析成功不够。** 字重/字体字符串变化后检查目标渲染器的实际字号、字形和邻近布局；非标准字重在某个宿主发生异常，不代表所有 Canvas 都不支持它。检查多语言缺字，量测旋钮环心与轨道，不只核文字值；保持同条件原图与候选，量测阈值只作局部诊断。反例：把进程退出成功、字体 cmap 完整或某组坐标达标当作整页视觉通过；修完一处沿用旧版验收。

## 椭圆开口的前后遮挡：口沿不是整件内容的裁切框

适用：静态插画中“物件从容器露出”的深度关系，不是产品 UI 功能或已验证的运动机制。先确定后侧口沿、插入物、前侧外壳三个层级；插入物允许高于口沿，仅被前侧外壳的覆盖区域挡住。把整件物件裁入椭圆会错误删除露出的部分；仅调整一个完整椭圆的绘制顺序也不能同时表达前后关系。

- **共享边界，分开角色。** 后侧内壁/口沿先画，插入物居中，前侧外壳最后画；前侧轮廓顶部应与口沿下半弧来自同一几何边界，避免分别近似导致亮缝。需要独立取得“已遮挡内容层”时，复用现有 `sampleRasterMatte` 的 alpha 反向遮罩，再以 `drawRasterSnapshot` 合成；单张不透明静帧可直接按层绘制，不因研究个案新增同义遮罩组件。
- **测试使用实际那份 mask。** 保存参与运算的不可变快照；重涂半透明抗锯齿边缘会改变 alpha，不能拿重涂后的画布冒充原 mask。检查完全可见、完全遮挡及边缘覆盖，不能只检查最终图“看起来有容器”。覆盖测试验证的是中间层输入 alpha 关系，不验证最终 RGB，也不证明造型自然或审美优秀。已经反向遮罩的主体再叠加同一抗锯齿前沿时，边缘可能发生二次衰减；不要据此声称像素级正确，需要精确边缘时另测最终合成。
- **换内容验证通用性，限定结论。** 中性椭圆与矩形分别验证露出/遮挡，并检查不同开口扁率；验证仅覆盖已测布局。物件尺寸、口沿扁率和位置改变可能让遮挡消失，需要重新构图，不能从一个默认场景推出自动布局、三维深度、人物生成或动画能力。

研究溯源：[OpenDesign 固定版本示例](https://github.com/nexu-io/open-design/tree/12d970eacc8971150e3c76470d2a9afe16dc2ed1/plugins/_official/examples/motion-mind-clarity-journey) 标注外部创作者来源，原设计权利未核实。这里只保留以无品牌基础几何验证的原创方法，不附参考图、可识别角色轮廓、字体、复刻场景或私有产物；仓库许可与署名均不代替原设计授权。本次为 Native Canvas 静态输出，不是浏览器截图，未验证运动、音频、交互或响应式。

## 密集弧形索引：裁切改变可见性，不重编号对象

来源：Open Design [`motion-claude-agent-lab`](https://github.com/nexu-io/open-design/tree/12d970eacc8971150e3c76470d2a9afe16dc2ed1/plugins/_official/examples/motion-claude-agent-lab) 的 720×900 封面与 Canvas 模板结构研究。模板标示 Apache-2.0；其中原片角色/署名裁切的授权未确认，不随方法迁移。私人复现为来源派生的 Native Canvas 静帧，**封面时间未知且索引、连线与角色位置仍有明显残差**，不算完整动效复刻或视觉验收通过。

- **先确定对象，再投影与裁切。** 弧带行、外侧轨道、选中连线和注释必须引用同一对象 ID；不要对裁切后的可见行重新编号，再用序号绑定轨道。增减显示密度和改变观察窗时，原有对象的对应关系应保持。对真实数据界面，还须单独定义排序、过滤、缺失对象及选中项出窗后的策略；装饰构图不自动提供这些能力。
- **将路径采样与排版分开。** 多个符号沿曲线路径排列可复用现有 [`geometry.polyline-trail`](../../engine/motion-elements/docs/guides/paths-and-contours.md) 的 `compilePolyline` / `samplePath`，由调用方提供折线及进度；无需因为画面有弧线而新增同义“轨道引擎”。这只是局部折线弧长采样，不提供图布局、平滑曲线、碰撞规避或屏幕等距保证。
- **密度服务于主线，不代替事实。** 低对比网络可以建立背景密度，但主线须有可追踪起终点、对象名和选中状态。微型矩阵、流量线和诊断面板如果只是程序纹理，应明示装饰或模拟；不能凭拟真外观声称系统真的在执行、检查通过或业务数据一致。

私人中性夹具实际调用上述路径 API，以 12 行、18 行及更窄观察窗三种静态条件核对 ID、连线端点、唯一选择、有限坐标与既有对象几何稳定性（14 项断言）。这只是已有机制的有限复用验证，不新增积木计数；不覆盖任意图拓扑、滚动交互、响应式、连续动画或审美验收。原图、来源派生代码与对照图均不收入公开源码。

## 手工纸感：纸边、色层与局部纹理分开验证

研究来源：[OpenDesign Visual Lesson 固定版本](https://github.com/nexu-io/open-design/tree/12d970eacc8971150e3c76470d2a9afe16dc2ed1/plugins/_official/examples/motion-visual-lesson) 的封面与 Canvas 源码。模板标注受外部创作者作品启发；模板许可不等于原角色、构图或品牌的再发布授权。这里只保留原创方法归纳，不携带参考图、来源派生代码、字体或私有复刻产物。

- **纸边不是全局噪点。** 把纸基底的浅色粗边与较内侧的色层分开；先按色层轮廓裁切，再叠加方向性笔触与稀疏纤维。让不同纸片的笔触方向随对象变化，而不是在整帧覆盖同一张噪点。过宽白边会变成贴纸描边，密集高对比纤维会妨碍文字，应在最终输出尺寸另看。
- **纹理绑定对象，种子绑定身份。** 在对象局部坐标一次生成并缓存纸片，随后整片平移、旋转或缩放；不要每次绘制重新随机，或把纸片平移却让笔触留在屏幕坐标。已有 Canvas 局部变换和离屏画布已能完成这项关系，不另登记同义纹理引擎；真正连续运动与缩放采样品质仍须另验。
- **轮廓模型要有明确支持域。** 椭圆的径向扰动可用于有限中性纸片试验，不是任意轮廓的可靠外扩。用质心决定法线朝向，在凹形、细颈或自交形状上可能翻转、露缝或相交；未验证时不要推广为通用撕纸算法。保持基底与色层共享几何参数，避免独立随机后失配。
- **与现有表面积木分工。** [`design.material-surfaces.v1`](../../engine/design-elements/docs/material-surfaces.md) 的 paper 提供信息表面与硬偏移影，不声称提供纤维轮廓或水粉笔触。手工插画可在私有场景使用局部纸片，但不应为模仿一张封面给所有 UI 卡片加毛边；需要进入公共积木时另补轮廓合同、状态保持、输入拒绝与重组测试。

私人无品牌椭圆夹具通过 6 项有界断言：同种子像素一致、换种子变化、外侧透明、中心不透明、白边可见、整数平移后局部像素一致；另实看三种静态姿态的纹理附着。旋转/缩放没有像素等价断言，不支持任意多边形或动画质量结论。来源派生 Native 静帧取源码 `reducedAt=6.8` 对照封面，构图对应但文字与纹理采样仍有可见残差；未观看或验证原 20 秒动画、声音、手持接触连续性、浏览器、交互或响应式，不新增已验收作品或积木计数。

## 正负形过渡：互补覆盖不等于无缝镶嵌

研究来源：[OpenDesign Sky and Water 固定版本](https://github.com/nexu-io/open-design/tree/12d970eacc8971150e3c76470d2a9afe16dc2ed1/plugins/_official/examples/motion-sky-water-tessellation) 的封面与 Canvas 模板。模板标注创作者 @akella；原鸟鱼图形权利未确认。这里只保留原创方法归纳，不携带原图、鸟路径、鱼纹理、来源派生场景或私人证据。私人 Native 静帧为来源派生，不是独立绘制；原片未观看，源码时长不能当成动效已验证。

- **先分开轮廓、明暗极性与纹理密度。** 建立少量明确的细节等级，让同一空间过渡中轮廓仍可辨认，再决定何处从细线版画退到剪影、从深色主体转成浅色负形。不同造型的相邻排列或叠盖只是视觉过渡，不能仅凭外观声称数学镶嵌、无缝重复或自动轮廓变形。原素材内的黑底、裁切残片和邻近对象应单独记录，不能误记为通用纹理能力。
- **互补关系必须共享同一覆盖图。** 复用现有 [`sampleRasterMatte`](../../engine/motion-elements/docs/raster-effects.md) 的 alpha 正向/反向结果；对不透明输入逐像素检验两份输出 alpha 之和，而非分别画两个近似轮廓。连同孔洞、完全覆盖、完全空白和抗锯齿边缘一起检查。对于半透明输入和舍入行为需另立条件，不由不透明夹具外推。
- **覆盖互补不代表 source-over 无缝。** 两份抗锯齿 alpha 直接依次叠加仍可能产生透明缺口；若目标是两种不透明颜色的连续分界，可在一个不透明底面上按同一覆盖率混色，并另测最终 RGBA。覆盖测试不替代颜色空间、纹理采样或视觉验收，也不证明任何形状都能铺满平面。

私人中性正弦边界夹具在横竖两种画幅及有/无孔洞共四种静态条件下，验证现有 matte 对不透明输入的逐像素 alpha 互补、完整内外区域与边缘存在，并按 source-over 公式计算出边缘 alpha 缺额（未执行合成器实测）。它是已有机制的有界复用，不新增基础积木或已验收作品计数；未验证动态循环、运动连续性、浏览器、交互、响应式或审美提升。

## 金属感的二维近似：深度轮廓、高光与背景密度分工

研究来源：[OpenDesign motion-future 固定版本](https://github.com/nexu-io/open-design/tree/12d970eacc8971150e3c76470d2a9afe16dc2ed1/plugins/_official/examples/motion-future) 的封面与模板。模板说明改编外部 62 秒原作；原视频未访问，原作品权利未核实。源主体使用三维挤出字，本段只总结独立基础几何的 Native Canvas 静态试验，不复制原字形、字体轮廓、构图或品牌，不是原作完整复刻。

- **先辨认厚度，再讨论金属。** 少量固定方向的轮廓偏移叠层可以表达有限投影厚度；前面再用轮廓内的亮—暗—亮色带建立金属感。分别保留“无厚度”和“无背景网点”对照，避免把背景冲击力误判成物件造型成立。偏移叠层不是倒角几何、透视、环境反射或 PBR；转向、强斜视角与侧面明暗必须另行建模和验证。
- **高光不能填掉孔洞。** 用同一前面覆盖图裁切色带，包含内孔与抗锯齿边缘；核输出 alpha 与该覆盖图一致，而不是仅看不透明背景中的最终图。此检查验证裁切，不证明色带符合真实光照。前后面接缝、投影方向与狭窄凹口仍须检查实际合成图。
- **字形构造轮廓不等于可见外缘。** 后续中性文字试验发现，直接给重叠字形路径描边会出现三角/矩形内部拼缝；字体填充看似正确不代表 `strokeText` 可当倒角。金属正面不需轮廓时移除描边；需空心字时可在独立图层描边后以同位置完整填充覆盖作 `destination-out`，保留可见边缘，并实看孔洞及抗锯齿残留。该修正不同于逐条忠实保留参考自身的拼缝，不证明真实 bevel。
- **网点负责外围密度，HUD 负责次级读序。** 用椭圆距离组织疏密时，保留主物阅读窗口，弱化微型注记与边界，不能让每个层都同样明亮。装饰索引不代表真实诊断或交互；信息文字应避开高密度点区，另在最终尺寸核对。已有 Canvas 蒙版、局部变换、表面与 halftone 候选承担各自范围，不因一张封面新增同义积木；当前 paper/opaque/glass 表面契约也不能被称为金属渲染器。

私人中性环、门洞与六边形夹具验证三份前面覆盖图的逐像素 alpha 保持、环孔透明、同条件像素确定性，以及移除厚度/网点后的像素变化。结果限于这三种静态几何；反例差异不等于审美提升。未验证三维光照、动画、声音、浏览器、交互、响应式或用户接受，不新增基础积木和已验收作品计数。公开方法不携带参考图、来源派生代码、字体、原视频或私有证据。

## 品牌提案与编辑器证据：同屏不等于同一状态

研究来源：[OpenDesign TixFox 固定版本](https://github.com/nexu-io/open-design/tree/5a0c47777975ddb91d09c1c16b423a3ef74bf572/plugins/_official/examples/motion-tixfox-ticket-promo) 的完整封面与 Canvas 模板。封面标示 15 秒；按模板场景起点 13.45 秒，对应局部 1.55 秒，仍是未发布编辑状态，而非发布成功。元数据标示 Apache-2.0 并另署名外部原片作者；这不自动授予角色、品牌、媒体或原片的公开权。参考图、来源派生代码、字体与媒体只用于私人研究，不随此方法入库。

- **主张区与证据区各有工作。** 大字表达作者提案，编辑器展示有限的内容结构；不要为了品牌冲击把编辑器压成不可读装饰，也不要把左侧承诺误当成右侧已验证的产品结果。先锁完整画幅、两区比例与主要内容，再看描边、偏移硬影和局部色块。保持文字标签，不能只靠颜色区分内容类别。
- **动作标签不代表动作完成。** 草稿字段可以完整而仍未发布；静态按钮上的动词不能充当成功回执。中性组合应明确示例数据和冻结状态；移植成真实产品时还须定义确认、失败、重复提交与恢复，不能由这张静帧推定交互可用。也不能将源封面位置外推为其余影片已看过。
- **已有组件承担组合，不为一张提案新增引擎。** [`color-sections`](../../engine/design-elements/docs/color-sections.md) 返回两个区域，调用方据其实际边界派生标题与预览；[`typographic-focus`](../../engine/design-elements/docs/typographic-focus.md) 负责有界标题与正文，保留其显式字数/行数和溢出拒绝；[`material-surfaces`](../../engine/design-elements/docs/material-surfaces.md) 的 paper 负责信息面与硬偏移影。预览字段、图形和类别由宿主绘制，不把这些组件称为活动编辑器、品牌生成器或排版求解器。paper 的影轮廓与圆角面不同，也不是源面板的像素级替代。
- **字体身份正确仍要看真实字重。** 本次 Native 初始变量字体渲染偏细，固定默认宽度与目标字重后更接近封面；应保留前后依据和实际输出检查，不用修改文案或缩放截图掩盖字体差异。全帧误差会被大片纯色稀释，不能仅以均值宣布忠实或优秀。

私人两份无品牌静态组合实际调用上述三个既有组件，变更内容、配色和区域比例；12 项断言覆盖重复像素确定性、移除部分色彩/硬影后的输出变化与同模型保持、标题不跨区、卡片与内容边界。这个消融同时改变多项视觉因素，不证明其中某一项导致审美提升；其余手绘字段/装饰、长文本、任意尺寸与交互不在覆盖范围。来源派生 15 秒 Native 静帧仍有字体抗锯齿、网点采样和 JPEG 差异，未验浏览器、动画、声音、响应式或用户接受；不新增基础族、正式配方或已验收作品计数。

## 嵌套画板与角色指针：绑定对象，不绑定装饰坐标

研究来源：[OpenDesign Claude Design Team 固定版本](https://github.com/nexu-io/open-design/tree/5a0c47777975ddb91d09c1c16b423a3ef74bf572/plugins/_official/examples/motion-claude-design-team) 的完整封面与 Canvas 模板。元数据标示 Apache-2.0，但 credits 对 @motion_so 原作明确限定内部复刻评测；这里只保留中性方法，不携带原角色 PNG、品牌、字体、媒体、来源派生代码或私人证据。只看过静帧，未观看原片。

- **热点、角色与对象需要共享身份及变换链。** 先从稳定对象 ID 的局部点，经画板与父级变换得到热点，再把同一点交给角色标签布局；不要分别给指针和标签增加漂移。原模板的标签只是独立坐标与漂移，不具有对象 ID 绑定、多人协同或真实任务完成系统；这些关系是中性宿主需要补足的消费逻辑。
- **内容裁切与标签可见性分别决定。** 内容在画板内裁切，标签可放在画板外的覆盖层，但其目标已被裁掉时应按明确规则隐藏或改为离屏提示，不能保留指向空白的角色。此夹具仅按热点是否在轴对齐画板内判定，不支持旋转裁切、多层遮挡或对象部分可见比例。标签和引导线的遮挡也必须分别检查。
- **优先消费已有几何与有限标签布局。** 复用 [`anchored-labels`](../../engine/motion-elements/docs/anchored-labels.md) 的候选、保护框与 `unplaced` 输出，父子坐标由既有矩阵组合；布局器不测字、不路由引导线、不自动提供身份/裁切/状态管理。没有位置时不得回退到任意遮字坐标，更不能把未放置当完成。状态由宿主明确的示例条件派生，不为此新增同义原语。
- **封面状态不能由一个时间文字反推。** 此封面的 `00:15` 是内嵌预览文案；固定源码在 palette 完成阈值之后会放大徽章，而封面仍为小徽章。保留未修改源码样本与明确修改的封面状态重建，两者不能混为“找到精确原片帧”；重建还存在字体、透明层、阴影及采样残差。

## 阶梯字形与曝光：先辨空间副本，再谈时间采样

- 参考：[Motion Designer Showreel 固定源码](https://github.com/nexu-io/open-design/tree/5a0c47777975ddb91d09c1c16b423a3ef74bf572/plugins/_official/examples/motion-showreel)。完整封面和来源派生 Native Canvas 静态研究；Apache 模板元数据不转授署名原作者 @stephanlivera 的原画、品牌或音乐权利。引用资产、字体、派生场景与私人证据不随方法公开，未观看原视频。
- 先保留外层画幅：640×488 封面内为 640×360 作品，上下各 64px 深色留边。HUD 的 12 秒 19 帧按 60fps 解释后，未改场景逻辑的采样与阶梯主体状态相符；这不证明原视频逐帧一致。Native 字体、细小 HUD、边缘采样与 JPEG 仍有残差，全图低均值不能代替字形评审。
- **整词宽度与逐字间距不是同一参数。** 先测字形 advance、累加 tracking、确定整词居中，再施加整体横向尺度与每字偏移。源码先按整词自然宽度决定缩放，逐字绘制另加负 tracking，因此目标宽度不等于最终墨迹边界；不能以改字间距掩盖字体身份或宽度不符。
- **空间副本不是历史帧。** 来源每字绘制六层 alpha 0.14 的副本，按当前 blur 向量的负向等距偏移，远层先绘，最后覆盖当前不透明字形；此阶段向量为竖直，阶梯来自逐字延迟与 wave，不是每层斜移。副本方向不能据此称为真实运动的反方向，更不能把 source-over 叠层等同相同权重的时间积分。
- 已有 [`temporal-exposure`](../../engine/motion-elements/docs/foundations/raster.temporal-exposure.md) 按显式历史帧、归一化权重和预乘 alpha 混合，与来源做法不同。中性组合实际消费该模块，宿主提供可随机访问的逐字轨迹，再覆当前字形保住实心锚点；没有额外当前层时归一化曝光可能降低单帧字形不重叠区域的不透明度。既有模块仍为 experimental，不能据复用自动升级成熟度。
- 私人 SHIFT、MOMENT 两种中性文字组合通过 11 项断言：随机访问确定性、不透明当前字形保持、变化限于曝光覆盖域、所设历史位置方向、实际采样帧身份、透明起点不重归一化，以及与 source-over alpha 不等价。轨迹和字体由宿主提供，不是新增排版求解器；有限静态测试不证明任意长词、连续运动可读性、响应式、浏览器、音频、审美或用户接受，不增加基础积木、正式配方或已验收作品计数。

## 全幅字卡：字形边界、句点与注释的关系

- 参考：[Kinetic Motion Designer 固定源码](https://github.com/nexu-io/open-design/tree/5a0c47777975ddb91d09c1c16b423a3ef74bf572/plugins/_official/examples/motion-kinetic-motion-designer)。实看完整 1920×1080 封面，保留来源派生 Native Canvas 静帧；模板 Apache 标示不转授 @himanshutwtxs 原作、品牌或音乐，Anton / Caveat 的 OFL 单独核对。相关媒体、字体、派生代码与私有证据不进入公共方法，未观看原视频。
- 两行窄体大字建立主焦点，强调色句点同时成为手写邀请的指向对象，细底尺退为辅助层。源码把标题按整词 advance 分配逐字宽度，再独立缩放横纵轴；指定字号或目标宽度不等于实际墨迹框，不能把句点位置只绑定字数。中性变体改为实测墨迹边界、等比缩放与显式句点间隔；过长内容拒绝，不无限压窄。
- 源码 HUD 明确按 30fps 取整，封面 `14:05` 只限定约 14.1667–14.2 秒的显示区间；直接用浮点 `14+5/30` 会因余数精度显示 `14:04`。保留该反例与 14.16、14.18 秒样本；14.18 秒主体构型和 HUD 相符，不证明原片精确帧。Caveat 变量字体另取 700 静态实例供 Native 宿主，字形边缘、背景采样与 JPEG 仍有残差。
- **注释布局与引导线分工。** 中性组合实际调用 [`anchored-labels`](../../engine/motion-elements/docs/anchored-labels.md)，宿主提供实测文字框、句点锚点及主体保护框；失败保留 `unplaced`，不任意盖字。模块不测字、不生成或避障引导线，弯线端点和安全间隔仍由宿主负责；来源本身使用固定注释坐标，不具有该自适应能力。
- **装饰底尺不冒充场景数据。** 来源六个菱形位置硬编码，七场景真实边界并不全部对应，游标才按总时长比例计算。忠实私有复刻保留差异；中性底尺从同一时长列表累加边界并派生唯一游标，不把装饰刻度称为编辑器或真实关键帧。
- 两种中性文字组合通过 14 项有限断言，覆盖像素确定性、句点/墨迹间隔、标签避开主体与底尺、阶段位置、游标、全部候选失败、超长标题和非法时间拒绝。未验连续运动、引导线通用避障、浏览器、响应式、音频、无障碍或用户接受；既有布局模块仍为 experimental，不增加基础积木、正式配方或已验收作品计数。

## 编辑首屏：删除线、替代主张与混排边界

- 参考：[Magazine Poster 固定源码](https://github.com/nexu-io/open-design/tree/5a0c47777975ddb91d09c1c16b423a3ef74bf572/plugins/_official/examples/magazine-poster)。只研究官方截图中可见的作品首屏：点纸底、四行大标题、说明与双栏开头；编辑器外壳不属于海报，底部引文被裁断，不能把源码存在的其余四节及页脚称为已看或已复刻。源码 MIT 标示不转授宿主字体；来源图、派生场景及私人证据不入公共库。
- **字体声明不等于字体已加载。** HTML 的 Playfair Display / Iowan / Georgia fallback 列表没有附加载资源，不能据此认定截图实际用字。Native 重建采用独立许可的 Noto Serif 与 DejaVu Mono 替代，保留字形、字重、字宽和断行残差，不把近似字体或局部字号校准冒充原字体、像素级保真或浏览器截图。
- 删除线承担被否定的旧主张，橙色斜体承担替代方向；普通正文说明其条件，双栏才展开证据。换文案时重读逻辑：误删否定词会反转意思，不能只把删除线当装饰。暖底与低对比点纹退为底层，细横线负责分区，不增加同权焦点。
- 混排先按真实宿主字体逐段测量 advance 与墨迹边界，再分配相邻字段、删除线与强调区；斜体出锋不能仅按字符串长度估算。参考重建保留可见换行，中性变体溢出拒绝，不无限压窄文字来保住旧坐标。
- 两种中性编辑卡实际复用 [`material-surfaces`](../../engine/design-elements/docs/material-surfaces.md) 的平面纸张和内容槽；点纹、混排字段及双栏在宿主局部绘制。`typographic-focus` 不负责同行混合字体与部分删除线，不为追求调用数量拆坏标题，也不新增同义原语。
- 17 项有限断言覆盖两组像素确定性、标题墨迹包含、等宽双栏与间距、旧主张/新主张顺序，以及超长标题、说明、栏标题、栏正文和错误行列数拒绝；原生首屏尺寸单列验证。静态语义检查不证明审美或用户接受；未验完整网页、浏览器、响应式、键盘交互、无障碍、视频或声音，不增加积木、正式配方或已验收作品计数。

## 票券凹口与序列排版：假孔、真裁空和换行不是同一件事

来源观察：Open Design 固定树 `5a0c47777975ddb91d09c1c16b423a3ef74bf572` 的 [Tom Modern components](https://github.com/nexu-io/open-design/blob/5a0c47777975ddb91d09c1c16b423a3ef74bf572/design-systems/tom-modern/components.html) 与官方 PNG 的下半完整 Token Card / Code Window。上方有拼接裁切，研究不代表连续整站；原代码 MIT（Tom-Opencart），字体另适用 OFL，截图/品牌未随库分发。Native 静态移植是源码辅助研究，不是浏览器回归或独立原创复刻。

- **凹口先核承托面。** 用固定背景色圆形盖住卡边，只在该底色上近似孔洞；移到异色、纹理或透明叠层即暴露假孔。中性条纹承托面研究比较了背景色覆盖与局部 even-odd 裁空，确认真裁空保留孔下已有像素。真实实现需将切口限制于卡片自身遮罩，不能在整个合成画布上擦除承托面。
- **序列是分组内容，不是连续标题。** 按实际字体测量每组、分隔符、字距、间隙及内边距，再决定逐组换行和穿孔线位置；行数增加应带动卡高及页脚，不覆盖后续内容。源图末组换行是真实可见状态，忠实研究不得悄悄缩字修成一行；中性变体可另订规则。变暗的字符仍可读，不是安全脱敏，演示使用明确虚构值。
- **高光和语法色分工。** 票券高光只营造物件层次，不能降低关键序列辨识；代码窗用较弱表面高光，把语法色留给阅读。静态截图不能证明 sheen 动画的轨迹、持续时间或可用性；源码动画声明也不能替代观看运动。
- **优先组合而非注册新族。** 研究中实际复用了 [material-surfaces](../../engine/design-elements/docs/material-surfaces.md) 的承托容器与 [typographic-focus](../../engine/design-elements/docs/typographic-focus.md) 的中性说明层级。单个凹口不需要几何标识组的整格合同；局部路径裁切即可。现有标题族不能自动替代同一行双色混排，原样复刻单独测量。没有新增组件、作品接受或视频证明；Native 阴影、光带与字形仍须对照目标宿主，不宣称 CSS 像素等效。

## 不等宽海报场：面积节奏与底锚说明分开验证

- 参考：[Maya Rowan 官方隔离预览](https://open-design.ai/showcase-artifacts/maya-rowan-personal-brand/0d6ceb3a716b20b3)。实看完整官方长图及 live 首屏，研究范围仅为 Selected work 完整段；私人 Native 复刻、原创内容变体和等宽对照不等于整站实现。原人像、品牌、截图及来源派生代码不分发，官网页脚许可不自动覆盖媒体；本次用独立 OFL 字体替代，字形、基线与水印位置仍有残差。
- **不等宽是编辑节奏，不是面积数据。** 同行高度和窄 gutter 保持秩序，较宽左列形成主质量，末尾横跨两列收束序列；不能把宽度解释为项目价值或数量。等宽对照削弱该非对称关系，但需要同权比较的数据卡可能更适合等宽。大号淡序号退作索引背景，不应压过标题。
- **底锚说明必须与标题实测占区相交检查。** 固定卡高、紧行距和底部定位独立成立，不代表组合安全；换成长标题、更多正文或另一字体后可能碰撞。忠实研究保留源例的紧间距及 Native 残差，原创组合按实测标题下缘、说明上缘和显式最小间隔验收；不以偷偷缩字、删文或压窄替代溢出处理。需动态扩高或重排时另验，不把本次固定画幅拒绝逻辑说成自适应布局。
- 实际复用 [material-surfaces](../../engine/design-elements/docs/material-surfaces.md) 的零阴影、直角纸面；紧字距、分行及淡序号由宿主局部绘制，不为海报感制造同义组件。技术检查区分原例已知间距失败与原创内容安全；未验本地浏览器、交互、响应式、无障碍、动画或用户接受，0 新族、正式配方及已接受作品。

## 行程工作台：筛选范围、三种时间与缺失估计

- **过滤改变当前视图，不擅自改变集合。** 明确筛选针对备选库、地图、行程中的哪些区；原站本次观察中搜索无结果仍保留已排地点。空态需说明是“无匹配”，不是“计划为空”。移除行程成员也不等于删除保存的地点；中性模型用稳定 ID 派生三视图，在过滤、移除与移动后核身份和计数，扩展阅读见[跨区身份方法（固定公开源码）](https://github.com/doomclouds/MotionStudio/blob/0bdd114e84a2693cc4defb789acaeccb4113f8b8/skills/ui-design-director/references/task-identity-state.md)（可选方法引用，非运行依赖；本段身份与计数检查不需联网），不额外发明检索机制。

- 中性完成、移除、空筛选静态变体及纯状态模型做了有限确定性、边界、重复移除、非法 ID/时段和缺段估计检查；去材质对照保持内容模型不变。Native 静帧、原站点击与自写模型测试是三种不同证据，不能相互冒充。本次未实现可点击中性前端、拖拽、刷新持久化、移动端、键盘/焦点或无障碍认证，也未获得用户审美接受；不增加基础积木、正式配方或已验收作品计数。

## 多视图指标：共用身份、量纲和时间窗，不共用猜测

研究来源：[OpenDesign Life System](https://open-design.ai/showcase/personal-dashboard-design/) 的同屏仪表盘。图库 detail 是同屏裁图，不是交互状态；健康数字仅为来源示意，不作为测量结果或建议。原图、品牌和解剖图许可未单独确认，不随本库提供。

- **对象标注、趋势与汇总先锁定同一口径。** 相同指标在侧栏、空间标注和总览中应消费同一 ID 与值；周期序列另记时间窗、采样与分母。只有口径确实相同，才要求末个样本与当前快照相等；不能把周期平均、最后值和综合分数默认互换。不同指标同为 0–100 也不代表可相加或互为解释。
- **图像与连线不是数据证据。** 空间主物建立读图锚点，细线承担标签关联；装饰网络不证明真实坐标、因果或医学关系。绿色可标识系列，不能未经领域依据变成“健康/安全”。示意、未连接和时间窗说明应可见，不照抄参考的 live、隐私保证或状态结论。
- **先复用有限模型，再补消费层检查。** [`metric-strip`](../../engine/design-elements/recipes/candidates/metric-strip/README.md) 可承担整数计数/显式分母的汇总布局，单位小数、趋势和空间标注仍由宿主实现，不扩大该候选合同。私人两组原创设备数据检查了同 ID 对应、最后样本口径、0/100 边界、实际条形像素与字宽；这只支持限定 Native Canvas 静态消费，不证明健康模型、真实遥测、浏览器、交互、响应式或用户接受，不新增积木计数。

## 餐饮品牌到预约：图片必须证明文案，原型不能承诺席位

- 参考：[Ember & Pepper 官方预览](https://open-design.ai/showcase-artifacts/ember-pepper-sol/1db5b3a02d47181f)。实看完整长页和打开后的日期/时间/人数对话框，未提交原站表单。原摄影、品牌与字体的独立授权未建立；截图、原素材、私有候选与验证记录不随方法分发。
- **品牌叙事不是同一张 hero 无限复用。** 原站以深红食物首屏建立热烈感，奶油底编号菜单支持挑选，暗底空间章承担聚餐想象，访问章收束行动。迁移的是这些职责与色彩节奏，不是餐名、地址或商标。无真实营业事实时直接标示虚构，不把样例电话、地图与营业时间当真实服务。
- **语义正确比图片漂亮优先。** 原站牛肉条目使用泛食物图，空间章节用炸鸡和汉堡照片配餐厅空间说明；宽松 alt 文本不能修复像素与主张的失配。逐张核对“可见对象—标题—说明—替代文本”，没有合适照片就不展示该证据，不用同色系图库图蒙混。局部原创食材素材只承担食物背景，标题、导航、表单仍由代码生成；整屏图不能冒充 UI。
- **预约意向、可用席位与确认成功分开。** 日期、时间与人数的选择不证明后台有位；无服务端的研究应把行动写成预览计划，并明确没有查库存、没有预约。成功态只能复述实际完成的本地动作，不能把模拟确认号或时间当真实预订。真实产品另验营业日期、时区、人数约束、失败恢复与服务端结果。
- 原站打开对话框与候选行为验证分开。Native 两状态研究实际复用 [`typographic-focus`](../../engine/design-elements/docs/typographic-focus.md) 的菜单标题与 [`material-surfaces`](../../engine/design-elements/docs/material-surfaces.md) 的不透明弹窗面板；混字体 hero、矮按钮和字段使用局部绘制，不硬塞族合同。纯输入/静态边界检查不是浏览器测试；焦点、Escape、原生日期控件、手机滚动、提交结果均须在目标浏览器另验。不增加基础族、正式配方或已验收作品计数。


## 学习回顾：从可解释证据到下一次行动

来源：实看 [Dear Data 官方项目页](https://www.dear-data.com/theproject) 中周36/42/52的图像及读图键（Giorgia Lupi、Stefanie Posavec），以及 [Bullet Journal 月度日志](https://bulletjournal.com/blogs/faq/monthly-log) 的日期页/任务页（Ryder Carroll）；观察日期2026-11-03。前者让个体记录可解读，后者把时间和待办分工，均不证明学习效果。同时实看仓库[城市周报](../../portfolio/works/editorial-weekly-study/DESIGN-RETENTION.md)与[茶馆七夜](../../portfolio/works/tea-conversation-map/DESIGN-RETENTION.md)的完整封面并阅读保留卡：前者提供主张到证据的编辑顺序，后者提供读图语法及口径不一致的反例；两者原有 PARTIAL 边界不因迁移而提升。相关原则在一件原创、演示数据的固定画幅学习回顾中实际组合、渲染，并经独立静态图审修订；原图、字体、作品与私人证据不随本方法提供，研究访问不转授素材许可。

- **先组织判断，再选择皮肤。** 主张说明本次回顾要解决什么，趋势/分项提供证据，行动区指向需要处理的同一对象。不要把所有指标做成同等抢眼的卡片，也不要把一句鼓励当作数据结论。适合需要“看完后决定下一步”的回顾；纯监控、探索性分析或没有足够证据的场景不应强行生成行动建议。
- **让跨区关系可核，而非只用同色暗示。** 分项中的对象名称、数值和优先状态应与解释、下一步任务对应；行动区说明依据与具体动作，不遮挡数据本身。颜色可辅助，但文字身份不可省略。这里只证明静态对应成立，不证明建议有效、用户会执行或按钮可操作。
- **在读数旁交代范围。** 最新一次、周期平均与累计不可互换；精选任务不是全部任务；“下周一”跨周后要补日期。计数测验的百分比还须符合题数分母，不能为好看的曲线造不可发生的得分。检查源数值、图形量程与可见标签三个层面；仅在报告里解释不能修复画面误读。其他领域应换成自己的单位、采样和舍入规则，不照搬测验语义。
- **纸本细节是可选表达，不是跨风格结论。** 暖纸、细方格、衬线标题和少量彩签适合记录感；本次近实色图表底避免背景方格与坐标网格相争，彩签仅承载下一步和日程。深色技术台、严肃业务表或密集监控无需套这些材质。跨风格保留的是证据层级、可解释编码和对象一致的行动链，而非米白、黄色或固定三列。
- **用同内容删减版检查材料的职责。** 本次保留去方格、彩签底色/影的对照，两版均能读出数据与行动，彩签版只增强行动入口辨识和手记语气。此为有限静态观察，不是盲测、因果证明或审美优胜。若删去材质后关系消失，应先改内容与层级，不继续加胶带/纹理。原尺寸读字与整体缩图看层级分开，小字偏细不能因气质一致免检。
- **复用服从合同。** 本次真实调用 [material-surfaces](../../engine/design-elements/docs/material-surfaces.md) 绘制两张纸签；图表、量程和任务关系由宿主实现。[metric-strip](../../engine/design-elements/recipes/candidates/metric-strip/README.md) 不支持时长和百分比，故未强套。字体注册须检查结果，绘制使用同一注册别名，再核码位和实际画面，避免系统同名兜底使复现表面成功。

本节补充前述数据口径与修订合同，不新增族、配方或已验收作品。当前证据仅覆盖固定画幅、固定演示数据、有限删减对照和独立图审缺陷修订；用户审美、阅读效率、长内容、移动响应式、真实交互、可访问性认证及跨风格迁移尚未验证。下一次迁移应先换内容与视觉语言，再核上述关系是否仍成立，不能沿用本次图审作新作品接受。


### 跨内容迁移观察：行动身份与图像身份分别核对

在上述学习回顾之后，另两件原创、虚构内容的固定画幅试作分别采用运动周回顾与单片策展影院语言。这里仅保留去素材化观察；私人源码、图像、审稿记录与用户反馈不随库提供，也不将其登记为正式作品或公共回归测试。

- **可计算摘要与作者判断分开。** 周回顾的总量、变化率、记录数和超出示意范围的条目数可从同一数据源计算；解释与下一步仍是作者草稿。把部分数字改为计算，不能声称日期、对象名称及解释全文已动态绑定。变更数据时逐项检查标题、图表、证据日期与行动对象，尤其补全“下一次”的具体日期/类型。示意范围不构成健康判断，负荷增加也不自动代表进步。
- **失败保护是构图约束，不是内容删减许可。** 本轮周回顾实际触发 [decision-support 候选](../../engine/design-elements/recipes/candidates/decision-support/README.md) 的建议与限制重叠拒绝；修订缩短作者文案，而非缩小字、隐藏反解释或移除失败检查。该观察支持限定静态合同，不证明推荐正确或用户会执行。新内容仍须重新测量，不能复用旧通过记录。
- **非数据页面也要保持对象身份。** 单片影院的标题、片长、说明和主行动应指向同一虚构影片；图旁第二个诗性标题可能被读成另一部影片。探索入口若复用同一缩略画面，会失去不同栏目身份。修订可统一主片名称、分别创作符合栏目内容的图像，而不是将所有区域改成同色卡片。图像能承担氛围和识别，但不能证明影片、服务或权益真实存在。
- **消融应分清表达层。** 同内容影院稿去掉插画后，文案层级与行动仍可读，但海岸故事及不同栏目识别变弱；这与前述学习回顾去材质的观察不是同一问题。分别问图像是否承担叙事/身份、材质是否辅助读序，而非用“删了仍可读”判定所有视觉都无价值。两者仅为有限作者观察，无盲测、转化率或通用审美结论。

这些迁移保留了对象—依据—行动关系，但不是跨领域有效性的完整验证。自主首版与独立审稿后修订必须分开；固定数据、静态字宽、局部色值和重复渲染不覆盖真实交互、移动端、无障碍认证、医学或用户接受。字体显式注册、别名一致及检查返回仍沿用前节合同，不重复创造新能力。
